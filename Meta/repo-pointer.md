# 长期记忆库指针（通用 AI 入口）

本用户的长期个人记忆库是 GitHub 仓库 **`jadecoltrane/memory`**（Markdown + Git + Obsidian）。该库的 `CLAUDE.md` 是**所有 AI 共用**的主规则,文件名不限制使用者。

- **需要个人上下文时**：用当前 AI 已授权的 GitHub 连接器/API 或本地 checkout 访问仓库,先读取最新 `CLAUDE.md` 与 `Meta/index.md`,再按需加载相关文件;与个人无关的普通问题不必加载。
- **自动记忆**：按 `CLAUDE.md` 和 `Meta/RESOLVER.md` 主动维护符合条件的 `Profile/`;对值得长期保存的 `Notes/` 内容主动询问一次,获得明确同意才写。用户直接说「记下来」「收藏这条」等则按规则执行,不用重复询问。
- **写入**：优先读取最新目标文件,按仓库分类、验证、索引及并发安全要求提交到 `main`,并明确反馈文件和结果。「记下来」指本 Git 仓库,不是任一 AI 产品自身的记忆功能。
- **工具限制**：不要假设存在 `add_repo`、命令行或 Python;没有仓库写权限时不得假称成功,应告知并提供可手动保存的内容。
