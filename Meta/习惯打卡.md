# 习惯打卡

工作台首页「✅ 每日习惯」那张卡的数据源。**存成纯 markdown 而不是插件的数据库或
localStorage**:换设备不丢、进 git 有历史、AI 直接读得懂(记忆库的数据层原则)。

- 想加/删/改习惯,直接改下面「习惯」区,工作台上的清单跟着变。
- 「记录」区每天一行:`- 日期 | 当天勾掉的习惯,逗号分隔`。当天一个都没勾就没有这一行。
- 连续天数(卡片右边的 🔥)是现算的:从今天往回数,断一天就停。**今天还没勾不算断**
  ——不然每天早上打开工作台看到的都是 0,那就没人愿意接着记了。
