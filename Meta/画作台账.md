# 每日画作台账

工作台横幅 🖼 每日画作用过的每一幅,一幅一行。**机器读的文件,格式不能改**:

```
- 日期 | 画家 | 画名 | 图片直链
```

**为什么要有这个文件**:原来的查重靠 `git log -- Home.md | grep painting-title`,
而 `git log -- <路径>` 不跨改名。2026-08-16 把 `工作台.md` 改名成 `Home.md` 之后,
这条命令只看得见改名后的十天,7 月用过的全部失效——查重静默空跑,六天里放进来
四幅重复的(夜游者/吻/维纳斯的诞生/朱迪斯),没有任何报错。台账是纯文本,
改名、换目录、换执行器都不影响。

**查重靠 `Meta/scripts/painting_log.py`**,三重比对缺一不可:URL 相同、画名相同、
画家相同、或画名相似度 ≥ 0.75,命中任意一条就算重复。**画家那一条不是冗余**——
实测《三位一体圣像》和《三圣像》是同一幅画的两个译名,字面相似度为零,只有画家拦得住。

⚠️ **还拦不住的一种**:同一个画家有两个不同中文译名(「老彼得·勃鲁盖尔」vs
「老彼得·布吕赫尔」),画家那一条也会漏。台账里 LLM 时代写下的名字已按 Commons
文件名回对过一批,但两边用的是不同扫描件时对不上。**根治要在池和台账里存画家的
Wikidata QID**(QID 不随译名变),还没做。

下面这批是从 git 历史(含改名前的 `工作台.md`)一次性回填的。日期取当期 frontmatter 的 `generated`(不是提交时间,提交时间是 UTC、比北京日期早一天);同一天换过两幅画的按两行记,**回填按「画名+URL」去重而不是按日期**——按日期去重会静默丢掉当天被换掉的那一幅,而 2026-07-17 被丢掉的那幅正是后来重复出现的《夜游者》。
