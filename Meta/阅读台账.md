# 每日一读台账

工作台 📖 今日一读 出过的每一篇,一天一行。**机器读的文件,格式不能改**:

```
- 日期 | 体裁 | 素材 | 主旨
```

- **体裁**:六个之一 —— `对撞` / `核查` / `复核` / `串线` / `反例` / `旧信`。定义写在 `Meta/scripts/reading_log.py` 和 `Meta/WORKBENCH.md`,是**闭集**:当天临时起一个新体裁 `--check` 会拦(旧提问台账的《轴表》允许当期加轴,结果加轴成了绕开查重最省事的路;体裁这一栏不重蹈)。
- **素材**:笔记或概念页的仓库路径(不带 `.md`)。一篇用到几个就用 ` + ` 并列写全,冷却期按每一个单独算;路径写错 `--check` 会当场报(卡片里的双链跟着断,而工作台不进 lint,断了没人管)。纯外部素材写 `外部`、日记出的写 `Diary`——这两类不占冷却期(所有相关笔记都在冷却期时得有路可走)。
- **主旨**:一句话说清这一篇讲的是什么,不抄原文长句(字面查重比的是这一栏)。

选材前跑 `python3 Meta/scripts/reading_log.py`(体裁冷热 + 今天建议的体裁 + 禁用素材),出稿后跑 `--check`。读写规矩在 `Meta/WORKBENCH.md` 的 📖 那节。

**前身是每天两道提问**(台账留在 `Meta/问题台账.md`,只作历史)。停掉的原因在那份文件顶上写了。
