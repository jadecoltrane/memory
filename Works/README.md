# Works/ — 成品与草稿(不是笔记)

**这个目录不进索引、不进图谱、不被 lint 检查、不参与 GC 整理。** 不需要 `tier:`、不需要 frontmatter、不受「单个文件夹 12 篇」上限约束。

## 为什么和 Notes/ 平级,而不是 Notes/ 底下的一个文件夹

`Notes/` 装的是**想通的东西**——一篇一条结论,靠双链和概念页连成图谱,判据在 `Meta/RESOLVER.md`。稿子不是这个东西:它有版本、有发布状态、会被反复改写,一篇长文里可能同时用到七八条笔记。硬塞进 `Notes/` 会同时污染两边——图谱里多出一堆连不上的节点,稿子又被 frontmatter 和链接上限捆住。

## 它补的缺口

**这个库只有入口没有出口。**

- `Archive/` 补的是**退出**的出口——不想要的东西怎么离开
- `Works/` 补的是**产出**的出口——想通的东西怎么变成发出去的东西

`Meta/GC.md` 第 5b 步会跑 `publish_candidates.py`,报一句「可发候选 N 篇」。在这个目录存在之前,那个数字报完就没有下文了。

## 什么进来

小红书草稿和成文、长文、任何打算发出去的东西。写到一半的也放,**草稿不需要理由**。

## 组织方式

先平铺,同一类第二篇再建子文件夹(和 `Notes/` 一样的懒加载)。按平台还是按状态分,等真的堆起来了再看,别提前设计。

## `Works/选题/` —— 每周五推来的选题卡

`weekly-writing-pick.yml` 每周五北京时间 19:00 从 `publish_candidates.py` 的候选池里挑一条,写成一张卡放这里,同时开一个 issue 通知你。卡片只给起点(冲突在哪、可以从哪句开头、来源路径、两三个角度),**不代写**。

卡片的**来源路径放在 frontmatter 的 `sources:` 里,不在正文**——你开写时正文多半会被整段删掉重写,搁正文里的路径会跟着没了,那几条笔记就永远回不到「在写」。frontmatter 是唯一不会被顺手删掉的地方。

- **不想写就删掉那个文件**,下周照常,删除不需要理由。
- **真要写,在 Obsidian 里把它拖出 `Works/选题/`**(拖到 `Works/` 上就行,不用敲 git 命令——文件栏里拖一下,vault backup 会当成重命名提交)。这一下移动就是状态切换:卡片里的来源路径开始被 `publish_candidates.py` 认账,那几条笔记从候选池挪进「✍️ 在写」。**正文随便删光重写,文件名随便改**,留着 frontmatter 就行。

**为什么非要这一步移动**:那个脚本把「`Works/` 里引用了某篇笔记」当成「这篇在写」。机器人每周推一条,如果卡片就算数,候选池会被机器人自己推空——一年后池子干干净净,而你一个字都没写。所以脚本排除这个目录,进不进「在写」由你那一下 `git mv` 说了算。

## 和笔记的关系

作品里引用笔记用**纯文本路径**(`Notes/练习/写作/小红书写作定位-半知识型与从冲突开始而非从观点开始.md`),**不做双链**——照 `Profile/` 的先例。成品不该出现在思考的图谱里,否则图谱会被"我写过什么"淹没,而它要显示的是"我想过什么"。

**这条纯文本路径不只是引用,它就是状态标记。** `publish_candidates.py` 扫 `Works/**/*.md`(除了 `Works/选题/`,理由见上一节)的**全文**,把出现的 `Notes/xxx.md`、`Concepts/xxx.md` 认成这篇稿子的来源——**写在 frontmatter 还是正文里都算**,它不看小标题,只看有没有这个路径,那几条笔记就从「可发候选」挪进「✍️ 在写」,GC 不再重复提醒它们。所以**开写时顺手写下来源路径**,不是为了归档好看,是为了候选池自己会收缩。没标来源的稿子会被单独列一行,不算错。**从选题卡开写的不用管这一步**——卡片里「来源」那几行已经是路径了,拖出来就跟着走。反过来,从零开的稿子懒得写也不会坏:那几条笔记继续留在候选池,以后还可能被再推一次,代价只是数字虚高,不丢东西。

**发出去之后也只在稿子里标**:把 frontmatter 里那行 `published:` 填成 `published: 渠道 日期`(`已发:` 也认;选题卡里这个字段是空着预留好的,留空不算已发),`publish_candidates.py --sync` 会把它回写进这篇稿子所有来源笔记的 frontmatter,那几条就彻底离开候选池——不用一条条去笔记里手改。反过来,笔记那侧也可以写 `draft: Works/xxx.md`,脚本两边都认。三种状态和标法见 `Meta/RESOLVER.md`。
