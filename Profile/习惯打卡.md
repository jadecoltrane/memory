# 习惯打卡

工作台首页「✅ 每日习惯」那张卡的数据源。**存成纯 markdown 而不是插件的数据库或
localStorage**:换设备不丢、进 git 有历史、AI 直接读得懂(记忆库的数据层原则)。

放在 `Profile/` 是因为它记的是「用户在练什么、练成了什么」,属于画像;但它是**数据文件
(`type: data`)不是画像页**——不吃画像那套检查(updated 过期、GC 去重合并、正文瘦身),
豁免规则写在 `Meta/GC.md` 和两个脚本里。

- 想加/删/改习惯,直接改下面「习惯」区,工作台上的清单跟着变。
- **频率**,默认每天,两种写法:
  - **间隔型**`- 名称 | 每2天`:两天一次,N 随便填。
  - **星期型**`- 有氧运动 | 周二周四`:只在这几天做。`周二、周四`、`周2,4`、`周一到周五`
    都认(区间会展开);`周日` 和 `周天` 一样。
  - 轮空那天卡片上标「今天轮空」、整行压淡,也不算进当天的 `x / y`——但想提前做照样能勾。
- 「记录」区每天一行:`- 日期 | 当天勾掉的习惯,逗号分隔`。当天一个都没勾就没有这一行。
- 🔥 是现算的连续次数:每天型按天数,每 N 天型和星期型按次数。断的判据:间隔型看
  **最后一次打卡离今天有没有超过 N 天**,星期型看**有没有漏掉某个应做日**(不该做的日子
  不影响)。三种都遵守同一条:**"今天还没勾"不算断**,不然每天早上打开看到的都是 0,
  那就没人愿意接着记了。
- **练成了点卡片上那个 🎓**:习惯从「习惯」区移进「已练成」,连同起止日期、累计打卡天数、
  最长连续天数一起留档。**打卡记录一条都不删**——练成之后清单腾出位置换新的,但历史还在。
- **「记录」区只增不减,一年约 365 行**(≈40 KB)。Obsidian 和工作台不在乎——打一次勾本来
  就是整文件重写,几千行照样是毫秒级;真正会被撑爆的是**把整篇读进上下文的 AI**。所以修的是
  读法不是存法:开工时只读「习惯」「已练成」两段,要看流水再往下翻(规则在 `CLAUDE.md`)。
- **攒够两个自然年再做年度切分**:把前年及更早的整段 `- 日期 | …` 剪进
  `Profile/习惯打卡历史/<年>.md`(同样 `type: data`),主文件永远只留当年和去年——跨年的连续
  天数还算得对,又不会一直长。⚠️ **剪之前必须先把每个习惯的「首次打卡日 / 累计天数 / 最长连续
  天数」写进上面这段正文**:🎓 的留档统计是从「记录」区现算的,记录一被剪走就**静默少算**,
  不报错、不提示,事后无法从留档反推。

⚠️ 下面三个 `##` 区是工作台整段重写的,正文只写在第一个 `##` 之前,写在段与段之间会被冲掉。
