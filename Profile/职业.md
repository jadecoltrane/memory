# 职业

## 基本盘

- **当前状态**:上海,UX 设计师(车企 / HMI 方向),月薪 18k,工作年限 2 年+。
- **教育背景**:本科成都信息工程大学·数字媒体技术;硕士都柏林大学(UCD)·人机交互(HCI)。
- **工作经历**:三段共约 24 个月;后两段均为车企 UX,做增删查改类需求,缺少完整主导项目。痛点是作品集内容薄弱、工作周期偏短存在稳定性疑虑。
- **核心优势**:HCI 硕士背景在国内 UX 圈属稀缺加分项;有真实车企 UX / 智能座舱项目经验;有一定研究方法基础。

## 手上有什么

- **车企经手模块**:控制中心、Dock、主框架、蓝牙电话、浏览器,均为系统侧 HMI,未做过 AI/语音功能。其中**控制中心做过改版迭代并主导功能排序**,有设计稿、有用户反馈,界面可完全复现;竞品布局对比做过但浅。
- **GAS 规范适配**:参与前期合规决策(以 GAS 7.0 为基线、must 项全改 / should 项基本保留的分级处理),主框架与开机引导的适配由本人落地。是出海车型、已通过认证。GAS/AAOS 是出海 HMI 岗位的硬技能关键词。
- **主动补车机技术底层**:为把 HMI 设计判断落到系统实现层面,自学 View 渲染层级/Z 轴、CAN 总线广播与优先级仲裁、网关跨域隔离机制。

## 方向:四条并排,还没定哪条是真的

**A:冲 AI 交互、跳大厂。** 明确想转 **AI 交互设计师**,短期窗口 2-3 个月完成作品集跳槽,目标岗位智能座舱 UX / HMI,目标薪资 22-28k。投递面在车企之外加了大模型公司(字节/月之暗面/MiniMax/阶跃)、新势力(理想/蔚来/小鹏)、互联网大厂座舱团队。

**B:务实保饭碗、攒钱回成都。** 对设计"不是多喜欢但也不讨厌",**务实而非热爱驱动**;明确排除考公(唯一好处是稳定,但不喜欢体制工作本身);核心恐惧是**怕被裁、要稳定**;财务现状是毕业两年在一线、几乎没存款、"一直在消费",家条件一般无兜底。路径定为**先继续做设计保饭碗 → 攒够存款和一个能带走的设计成果 → 回成都(前提是能在成都找到好工作)**,否掉了"裸辞做自媒体/独立设计师"的冲动版本,接受"边打工边私下做设计"的搭桥路径。对"这些目标什么年龄能实现"高度焦虑。

**C:出海——去欧洲工作。** 起点是看到一个她评价很低的熟人"真如他所说的"去了欧洲工作,反应是强烈的不平,原话**"这世界欠我太多了""我想拿回属于我的一切"**。⚠️ 这条和 A、B 都没调和过,但**手上的牌比另外两条硬**:UCD 的 HCI 硕士是现成的欧洲学历,GAS/AAOS 与出海车型认证经验正好是欧洲车企和中国车企欧洲分部共用的关键词。她自评**"直接出去肯定不现实"**(在国内待久了);可行版本是梯子而非一跳:先在上海进外企/出海团队,再看内部调动。

**D:不做设计、不打工,自由职业 + 满世界跑。** 原话"不想做设计 不想打工 想做自由职业 能满世界跑"。对设计的态度已从"不是多喜欢但也不讨厌"变成明确不想做。⚠️ 和 B 正面冲突:B 的核心恐惧是怕被裁、要稳定,而自由职业是收入最不稳的形态;B 还否掉过"裸辞做自媒体/独立设计师"。⚠️ 和 Profile/兴趣爱好.md 的旅行偏好(度假式、愿多花钱换舒适、不想受累)也对不上低预算游牧。"不打工"拆开后是三条原话:**不想被老板吩咐、不喜欢规章制度和形式主义、不喜欢替别人做事**。第三条意味着接单型自由职业(甲方吩咐)也不对口,对口的是**产品型**(做自己想做的东西,市场决定买不买)。卖什么还没定。

⚠️ A、B、C、D 是四个不同方向,都不删、并排保留。

- **存款目标 200 万、35 岁前**,主业设计之外打算靠自媒体和投资一起达到。⚠️ 和 B 里"否掉裸辞做自媒体"没完全对齐——现在这个自媒体不一定是裸辞版本,但真投入精力可能和"私下接设计单"抢时间。投资部分的风险偏好、品类、金额都还没提过。自媒体这条腿有底子:写作定位已经定了(Notes/练习/写作/小红书写作定位-半知识型与从冲突开始而非从观点开始.md)。
- **长期目标未定**:是否长期留在车企 UX 赛道,还是转用研 / 产品 / 服务设计,尚未确定。

**阵容一大三小**:②Agent(主力,车载语音助手重设计为 LLM 驱动的座舱 Agent,取证用公开素材)+ ①控制中心改版 + ④GAS 规范适配 + ⑤Smart 车机节日彩蛋,整本 40-50 页,九周计划。案例③(AI 信任访谈研究)已取消——**她明确不做任何形式的访谈**。

- **案例④的口径**:团队自查流程、本人参与决策与复核。她曾想写成"是我做的",最终没这么写——面试穿帮风险。AI 辅助环节因保密边界整体移出正文,面试被问可如实简答。
- **案例⑤的反思金句**:"交互设计师的价值是定义系统如何做决定。"
- 灯光事件那条证据用**匿名化**口径,正文不点名品牌。

**这是她自认的唯一"核心盘",也是最大焦虑源。** 三分钟热度模式"导致在工作或核心生活上一直拿不出成果,感到焦虑",作品集被她点名为那件必须出成果的事。⚠️ 但对策上有个没解决的冲突:一边是**完成度优先**(先用 2 小时拼出简陋但完整、随时能投的 V1.0,再把"改作品集"降级成有兴致才做的迭代,避坑"先做网站/设计模板"),一边是上面那个 40-50 页、九周计划的定稿阵容——两种节奏,没调和。

**她自己说的动机和风险**:冲作品集主要是被现实逼的——外包边缘工作、长期接不到核心任务,导致对作品集本身没信心,伴随"能不能应聘上好工作"的恐惧;做完当下焦虑会缓解但不会消失(她自认这不是重点);**明确担心长期这样"一直一直做作品集"会打消自己对设计本身的兴趣**。
