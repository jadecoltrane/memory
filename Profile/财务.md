# 财务

## 现状

- 上海,到手约 ¥15,600/月
- 三个月生活费 ¥20,000,月必需约 ¥6,700,**可支配 ¥8,900/月**
- 毕业两年,几乎没存款,家里没有兜底
- 存款目标 200 万、35 岁前

## 额度(已定)

**按到手倒推,不按税前。**

| | 月 | 年 |
| --- | --- | --- |
| 必需 | ¥6,700 | ¥80,400 |
| 应急金 | ¥5,900 | ¥70,800 |
| 想要(全部) | ¥3,000 | ¥36,000 |

**应急金目标 ¥40,000(六个月),先冲 ¥20,000 这个里程碑。** 没有家庭兜底的人,应急金就是兜底本身,排在所有「想要」之前。

**建满之前「想要」不涨,增量全给应急金**——可支配从 ¥7,300 涨到 ¥8,900 的那 ¥1,600 不分给消费。按 ¥5,900/月:**¥20,000 里程碑约 3.4 个月,¥40,000 约 6.8 个月。**

**建满 ¥40,000 之后**重切:可支配按 6:4 → 储蓄/投资 ¥5,340、想要 ¥3,560。

「想要」¥36,000 内部:

| 分项 | 年额度 |
| --- | --- |
| 秋冬外套 | ¥7,000 |
| 日常衣服 | ¥9,000 |
| 电子产品 | ¥5,000 |
| 小奖励 | ¥3,000 |
| 时间赎回 | ¥2,000 |
| **奢侈品** | **¥10,000** |

**时间赎回**是从「小奖励」里划出来的一格,买的是时间不是东西。**按「最不想干的事」排序花,不按小时定价**——先列一张最讨厌的事的清单,额度从最上面一条开始花,不讨厌的时间不用买回来。作用和其余几格一样——**把每次临场的「值不值」换成一次性的额度设定**。

## 涨薪后怎么换算

不要拿税前乘比例,三步走:

1. 税前换到手(上海 30k 税前 ≈ 到手 22k)
2. 到手 − 必需 = 可支配
3. 可支配按 6:4 分给储蓄和「想要」;「想要」里约 28% 给奢侈品

⚠️ **真正吃掉涨薪的是必需支出跟着涨。** 房租从 ¥4,000 换到 ¥7,000 这一步,比额度表本身影响大。

## 奢侈品愿望清单

清单总额约 ¥200,000。按 ¥10,000–20,000/年 的额度是十几年,**所以它是愿望池不是购物清单,不需要清空**——每年从里面捞一两件,池子同时在进新的、掉旧的。

## 花钱时的自我约束

- **对亲友在钱上"算得明明白白"**,自评偏抠。原话:**"我经常为了一点小钱,或者是就是算得明明白白的,跟朋友跟亲戚跟家人也是就是个钱上面我比较抠"**。
- **会为一笔小额损失付出不成比例的代价去挽回**,且动机不是缺钱——月饼赠品因自己选错没拿到,花两小时走路去取回来、全程不额外花钱,当下自述"很别扭",并明确否认是没钱:**"也不是说没有这个钱"**。⚠️ "别扭"这个读数说明中间夹着自罚成分,不是单纯的拿回属于自己的东西;但只有这一次样本。
  - ⚠️ **和 Notes/思考/关系与处世/请客买不到关系-落差感要拆成四份,以及筛人的动作是麻烦对方而不是喂对方 正面撞上,两条并列不调和**:那篇处理的是她**不算账、对没有回应的人单向请客吃了很多亏**,给出的规则是先定额度、把赠与和借款分开;这条记的是她对亲友算得太细。现有材料判不了"抠"是那次教训的过度矫正,还是两件事根本不在同一场域(大额单向付出 vs 日常小额)。

## 200 万那笔的缺口

即使月薪到 30k、年储蓄 ¥108,000,到 35 岁大约 ¥105–110 万,**离目标差一半**。省钱补不上这个口子,杠杆在收入端和副业端。
