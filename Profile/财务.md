# 财务

我希望我的钱最终服务于:

安全感 + 选择权 + 喜欢的生活。

- 上海,毕业两年
- **财务自由目标:本金 = 年开销 ÷ 3.5%(≈ 年开销 × 28.6)**。常说的 4% 取用法则(× 25)是按美国历史数据、30 年左右的退休期测的,提前退休要撑五六十年,所以取 3.5%;想更稳取 3%(× 33)。按上海当前必需 ¥12.2 万/年 ≈ **350 万**(3% 约 410 万)。⚠️ 和应急金一样**记公式不记数字**:开销或城市一变就重算——同一套公式放成都,目标会小很多

⚠️ **房租 32.5% 已经在常用的 30% 警戒线上沿。** 必需占到手快到三分之二,这是所有额度算不开的根源——不是「想要」花多了。

## 计划(已定方向,未执行)

**两件都在收入/必需这一端,比调额度表有效得多:**

- **换工作**——收入端。省钱补不上自由本金那个口子(见末节),这是唯一真正的杠杆
- **换一个便宜点的房子**——必需端。**目标房租 ¥4,400 以内**

**换城市(杭州)**:到手保持 ¥16,000,必需估 ≈¥8,000(房租 ≈¥3,300 为估计,待查实)。应急金约 8 个月建满,之后「想要」升到 ≈¥3,200/月。时间线见末节「自由路线」。

## 额度(已定)

**按到手倒推,不按税前。**

### 应急金:记公式,不记数字

**应急金目标 = 月必需 × 6。必需一变就重算。**

⚠️ **这里不许写死一个数字。** 必需一涨,写死的那个数就会悄悄退化成"只够三个多月"——不报错、不断链,也没人会为了一个看起来正常的数去复核。公式会跟着必需自己走,数字不会。

按当前必需 ¥10,200:

| 档 | 金额 |
| --- | --- |
| 里程碑(三个月) | **¥30,600** |
| 目标(六个月) | **¥61,200** |

没有家庭兜底的人,应急金就是兜底本身,**排在所有「想要」之前**。

### 分配

| | 月 | 年 |
| --- | --- | --- |
| 必需 | ¥10,200 | ¥122,400 |
| **储蓄(应急金)** | **¥3,800** | ¥45,600 |
| **想要(全部)** | **¥2,000** | **¥24,000** |

**建满之前「想要」不涨,增量全给储蓄**——涨薪、换房省下来的都不进额度表。

按 ¥3,800/月:**¥30,600 里程碑约 8.1 个月,¥61,200 约 16.1 个月。** 储蓄率 23.8%。

> 压到 ¥1,500(储蓄 ¥4,300)的话:六个月档只快 2 个月,多存 ¥6,000/年,但破掉的概率高得多。**一个破掉的预算等于零,不等于更省。** ¥2,000 是让"「我喜欢」是正当理由"这条还能成立的最低线。

**建满 ¥61,200 之后**重切:可支配按 6:4 分给储蓄/投资和「想要」。

### 「想要」¥24,000 内部

| 分项 | 年额度 | 说明 |
| --- | --- | --- |
| **体验** | **¥6,000** | 远行、没做过的事、看展演出。**弹性格**,见下 |
| 日常衣服 | ¥5,000 | 形象道具属于表层,**买便宜好换的** |
| 秋冬外套 | ¥3,000 | 按服役逻辑定价,不按"耐用保值"的量级 |
| **家居 / 小奖励** | **¥4,000** | ≈¥333/月。百元级日用小物落这格 |
| 电子产品 | ¥2,000 | |
| 时间赎回 | ¥2,000 | **缩表时最不该动的一格**,见下 |
| 奢侈品 | ¥2,000 | 节奏放慢,愿望池照留 |

- **体验单独占一格**;钱从奢侈品(-3,000)、日常衣服(-2,000)、电子(-1,000)挪来,总额不变。不和日常「出去玩」(生活费里 ¥1,200/月)混:那格管周末吃喝玩,这格管远行和新体验。**弹性规则**:物价管「什么时候花」(淡季、工作日、提前订),账户和收入管「今年能花多少」——应急金建满后,好年份体验格先加,紧年份体验格先收,储蓄格不动
- **家居单独占一格**,不和衣服挤。百元级的日用小物有地方落,就不必每次临场算账
- **时间赎回**买的是时间不是东西,**按「最不想干的事」排序花,不按小时定价**——先列一张最讨厌的事的清单,额度从最上面一条开始花,不讨厌的时间不用买回来。它是唯一不受形象轮换影响的一格
- 每一格的作用都一样:**把每次临场的「值不值」换成一次性的额度设定**。绕过它重新手算,等于这张表白建了
- ⚠️ **额度是按年的,一件大单品落地就把那一格当年基本用光。** 所以顺序是:先看这一格今年还剩多少,再看东西喜不喜欢——反过来的话,额度表只会在事后充当愧疚的计算器,起不到它该起的作用

- **吃:¥3,000 保底**(健康饮食那套采购是有成本的,见 Notes/个人/身体/三餐怎么排-外卖只求不踩三个坑周末只补铁和蛋白.md)

## 执行:每月照做的顺序

额度表只管「分多少」,这一节管「先后」。**顺序比比例重要**:

1. **发薪当天先转 ¥3,800 进一个单独的货币基金账户,名字就叫「应急金」**——先存后花,剩下的才是能花的钱。不和日常账户混放,否则它会被悄悄花掉
2. **保险先配**:百万医疗 + 意外险,一年几百块,从储蓄格出。没有家庭兜底,一场大病就能把几年的积蓄清零,应急金挡不住
3. **「想要」¥2,000/月用完就停**,不从下个月借
4. **手上闲置的东西卖掉,钱进应急金**,不进「想要」
5. **应急金建满六个月档之后**:储蓄那格改为每月定投宽基指数,不碰杠杆、不碰看不懂的产品

## 涨薪或换工作后怎么换算

不要拿税前乘比例,三步走:

1. 税前换到手(上海 30k 税前 ≈ 到手 22k)
2. 到手 − 必需 = 可支配
3. 可支配按 6:4 分给储蓄和「想要」

**换工作 + 换房同时落地**(到手 ¥22,000、房租 ¥4,400)的样子:

| | |

| 必需 | ¥9,400 |
| 可支配 | ¥12,600 |
| 储蓄/投资(6) | **¥7,560/月 · ¥90,720/年** |

⚠️ **真正吃掉涨薪的是必需支出跟着涨。** 换工作之后如果房租跟着跳到 ¥7,000,这张表立刻退回原点——**换房要在涨薪之前或同时办,不能之后**。

## 奢侈品愿望清单

清单总额约 ¥200,000。按 ¥5,000/年 的额度是几十年,**所以它是愿望池不是购物清单,不需要清空**——每年从里面捞一件,池子同时在进新的、掉旧的。

## 买东西的规矩

- **奢侈品额度只花在包和素金首饰上。** 墨镜、围巾、卡包、皮带这类配饰小件不买大牌——它们是品牌的入门款:溢价率最高、logo 最重(品牌一过气最先显旧)、二手只剩三成左右,一件一两千、几件就是一件大单品的钱。配饰按好看和适合买
- **买贵的先看二手**:二手已经折过价,再卖时亏得少
- **页面出现倒计时、「最后 X 天」「超级爆款」「明星同款」→ 先停,加购物车放三天。** 大多数东西不会真的买不到
- **晚上 21:00 之后不下单 ¥500 以上的东西**,也不做退/卖的决定
- **下单前过三问**:①这一格今年还剩多少(先看额度,再看喜不喜欢)②没人认得出牌子,我还要不要 ③我会经常用它吗
- **购物车只留两三件**,多了定期清。挂着的每一件都是一次诱惑
- **没用过、还在退货期内,先退,不先卖**——退是全款,卖只剩三到五成

## 半自由:中间站

两种,都比 350 万早得多:

- **滑行点**:本金够多,之后一分不存、只靠复利也能在 60 岁长到 350 万。从那一刻起只需赚当下的开销,工作可以换成钱少、没人吩咐的。按实际年化 4%~5%,35 岁的滑行点约 **105~130 万**;每月存 ¥7,560 约 9~11 年到,¥3,800 约 15~19 年
- **部分覆盖**:投资收入覆盖一部分开销,剩下的靠自己做的事赚。例:150 万 × 3.5% ≈ 5.3 万/年 ≈ 4,400/月,其余自己挣
- ⚠️ 不坐班就要自己交灵活就业社保和医保,要算进开销

## 自由路线:方法和时间

**两种自由**:半自由 = 投资收入(本金 × 3.5%)+ 自己产品的收入 ≥ 每月开销,可以不打工但产品得一直有收入;完全自由 = 只靠投资覆盖开销。**开销要算上「想要」**,只盖必需会低估。

共同假设:26 岁起、到手 ¥16,000 且不涨、可支配按 6:4 存、实际年化 4%~5%、产品收入第二年起。只是估算,不是承诺。

**按住房开销分三档**:

| 情形 | 每月开销(必需 / 含想要) | 只靠工资 | 加产品 ¥3,000/月 |
| --- | --- | --- | --- |
| 留在上海 | ¥10,200 / ¥12,200 | 约 59~63 岁(只盖必需) | 半自由约 46~47 岁 / 约 49~51 岁 |
| 杭州自己租房 | ¥8,000 / ¥10,000 | 约 51~53 岁(只盖必需) | 半自由约 40 岁 / 约 43~44 岁 |
| 住房开销为零 | ¥4,700 / ¥6,700 | 约 40~41 岁 / 约 44~45 岁 | 半自由约 31 岁 / 约 35 岁;完全自由约 37 岁 / 约 41 岁 |

**杭州自己租房 + 不同产品收入**(「投资 3.5% + 产品 ≥ 必需」即可离开打工):¥1,000/月 ≈ 47 岁,¥3,000 ≈ 40 岁,¥5,000 ≈ 34 岁,¥8,000 且稳定 ≈ 第二年。产品收入不稳,靠它离开打工前现金垫子要比 6 个月更厚。

**杠杆排序**:住房开销 > 产品收入 > 涨薪 > 省「想要」。到手涨到 ¥20,000(杭州租房)约提前 5~6 年;产品每月 ¥3,000 约提前 12 年。

**买房的影响**(杭州、首付 30%、30 年贷 3.1%):月供在还清前都算进开销,自由基本被拉到还清那天——房价 100 万约推迟 5 年,150 万推到 60 岁上下,300 万约等于退休;加产品 ¥3,000 各提前 10 年左右。房价越接近年收入 5~6 倍以内,推迟越少。**早买不等于划算**:持有一年的成本(利息 + 首付的机会成本 + 物业维修)约为房价的 4%,同样房子的房租约 1.8%,差约 2.3%;房价年涨幅低于约 2.3% 时,每早买一年就多花房价的约 2.3%。早买只在「城市十年内不变 + 有把握涨得比这快 + 月供不超收入三到四成、应急金不动」同时成立时才划算。

**应急金始终按含房租的必需算**(住房安排一变就要自己租)。投资和应急金放在自己名下。
