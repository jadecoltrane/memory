# 拍照好看的变量在条件不在脸上——四个可控项,以及风格是一致性不是单张精致

**这篇是操作手册,按需翻**:一 归因 → 二 四个可控变量 → **三 构图通则** → 四 人像位置姿态 → **五 B 类生活方式照** → **六 C 类人文纪实** → 七 风格是一致性 → 八 参照系。

## 一、"这张照片里我很丑",第一个念头指向错了地方

同一个人在不同拍摄条件下的差异,**大于**不同人在同一条件下的差异。逆光、低机位、转头中途拍出来的脸,和侧光、眼平、静止时拍出来的脸,可以像两个人;而两个不同的人在同一套好条件下拍,差别反而没那么大。

所以看到一张不满意的照片,把它读成一条关于脸的信息,是 [[Concepts/归因方向|归因]] 指错了地方——这次指错的方向不是朝人,是**朝内**:变量明明在相机那一侧,却被记在被拍的人账上。

**可验证**:同一天、同一张脸、同一个发型,换四组条件各拍一张——背对太阳 vs 侧光,居中全身 vs 三分之一膝上景,杂乱背景 vs 单一色块,正对镜头 vs 侧身走动。四张摆在一起,差别有多少落在脸上,自己就看得出来。

这条判据还有个副作用:**照片会给出互相矛盾的答案,而手不会。** 同一个头发,在逆光背面照里像稀的,在室内均匀光下像正常的——所以凡是能用手摸、能用尺量的问题(发尾厚薄、长度),就别拿照片当证据。

## 二、四个可控变量,按影响排序

**1. 光的方向。** 最大的一项。人背对光源时,人是暗的、背景是过曝的——明暗关系反了,该亮的暗、该退后的在发光,直接造成"糊""闷""没质感"。
- **判据:照片里的脸是不是比背景亮。** 不是就换个方向站。
- 最好的光:日出后一小时 / 日落前一小时,或阴天、均匀树荫。光从侧面或斜前方来。

**2. 背景的整洁度。** 满画面杂乱枝叶、没有一处是整的,眼睛没有落脚点。好照片几乎都有一大片**单一色块**:一堵墙、一片天、一张桌面、一片水。
- **判据:这张的背景是不是一个整块?**

**3. 色彩的数量与饱和。** 高饱和的亮色最难驾驭,尤其当背景也是同色系高饱和时——人从背景里跳不出来,反而糊进去。
- 全身 **2–3 个色**,其中一个是中性色(白/米/灰/藏青/黑)。
- 同色系深浅搭比撞色更"贵"。
- 面料同理:速干、化纤反光显廉价;棉、麻、针织显质感。**这跟价格无关**,便宜的棉也比贵的速干"贵"。

**4. 照片属于哪个类别。** 这一条最容易被忽略,但它决定前三条怎么用。**旅行纪念照**和**生活方式照**的规则几乎相反:前者要正面、居中、全身、笑、有地标;后者要侧身、偏置、局部、不看镜头、背景可以什么都不是。
- 按 A 类拍得越标准,在 B 类的尺子下就越"土"。**那不是审美失败,是类别错位。**
- **还有第三类:人文纪实(C)。** 它和前两类的差别更大——**主角不是人**,规则见第六节。

## 三、构图通则:本质是减法

**构图不是"还能加什么",是"哪个东西可以不要"。** 一张不好看的照片,九成不是缺了什么,是多了什么——多出来的垃圾桶、电线、路人、半个招牌。**先减,再谈构图法则。**

### 三条骨架线

- **三分法**:手机设置里打开**网格线**,主体放在竖线上或四个交点上,不居中。这是最省事的一条,打开网格就自动有了
- **引导线**:路、栏杆、走廊、台阶、桥、电线——**把眼睛送进画面深处**。找到一条线,顺着它站
- **三层深度**:前景 / 中景 / 背景。照片是二维的,层次是唯一的深度来源。前景可以是虚的(花、叶、栏杆、人的肩膀)

### 三条修辞

- **框中框**:透过门洞、窗、树枝、拱券去拍。**遮挡制造"偷看"的视角**,观众从旁观者变成在场者(C 类最常用的一条,见第六节)
- **重复与打破**:重复的窗、柱、砖、伞本身就是构图;**重复里有一个不同的,那个就是主体**
- **对称与破对称**:完全对称庄严但呆板;**对称里放一个不对称元素**(一个人、一辆车、一扇开着的窗)就活了

### 三条底线

- **地平线必须平。** 歪一度整张就廉价,而这是最常见也最容易避免的错误——网格线同时解决它
- **离近一点。** 站太远是最普遍的毛病。"如果你的照片不够好,是因为你离得不够近"[摄影界流传的说法,未联网核查]
- **天地比例别对半。** 天空多 = 开阔;地面多 = 厚重;**一半一半最平庸**。选一边

## 四、人在画面里的位置和姿态(A / B 类)

- **景别**:膝上景(大腿中部以上)或半身。全身远景是纪念照的景别。
- **位置**:左或右三分之一,不居中;让人朝着画面空的那一侧看或走。
- **机位**:拍全身要低于腰往上(显腿长),拍脸要与眼平或略高(低角度会压缩下颌到颈的线)。**这两条方向相反,别混用。**
- **姿态**:身体侧 45°、重心压在一条腿上、另一条放松。这一条解决大部分僵硬。
- **手要有事做**:抓包带、拨头发、拿水瓶、整理袖子。空着的手最僵,刻意摆造型的手第二僵。
- **张开双臂正对镜头、双脚平行站立**是纪念照的强编码,也是最没有线条的站姿。

## 五、B 类:生活方式照——核心是"看起来没在拍"

打卡照的毛病是**努力的痕迹**。这一类的全部难度在于:**摆拍,但看不出摆拍**。

### 五条做法

1. **拍动作的中间帧,不拍完成态**——走路中、端杯子中、回头中、翻页中。**连拍,选中间那几张**。完成态(站定、举杯、看镜头笑)就是摆拍的样子
2. **留一点"正在进行"的证据**——杯沿的口红印、翻开的书、拉开的椅子、随手放下的包。**全部整齐 = 摆出来的;有一处没收拾 = 真实**
3. **手是这一类最好用的主角**——握杯、翻书、拎袋子、按电梯。⚠️ **手部照不需要脸、不需要当天状态好、不需要别人帮拍**,一个人能拍的题材里回报最高
4. **窗边光是万能的**——室内靠窗、光从侧面来、背景是一堵墙。晚上用暖光源 + 低亮度,**别开顶灯**
5. **留白**——这一类里最贵的是**空**。别把画面填满,俯拍桌面(flatlay)和 45 度角都靠留白撑

### 题材清单(不用等特别的日子)

早餐 · 咖啡或茶 · 今日穿搭(挂着拍,不必上身) · 书+手 · 窗外天气 · 植物 · 开箱 · 运动后 · 夜里的台灯

### "精致"的真实来源是完成度,不是价格

指甲、杯子干净、桌面没有纸巾团、**包不塌**——这几样比任何拍摄技巧都更决定一张照片精不精致。同一条规则在衣服上的说法是"淡雅路线对完成度极度敏感"(Profile/穿搭偏好)。

### ⚠️ 最难的不是单张,是"有东西可拍"

技巧解决不了"我的日常没什么好拍的"。真正的做法是**反过来**:

> 不是先有生活再拍,而是**为了拍,稍微布置一下生活**——买一束花、把桌子收干净、周末换一家咖啡馆。

**这不是造假:花是真的买了,桌子是真的干净了。** 拍照在这儿是个杠杆,撬的是日常本身。

另外:**集中拍、分散发**。一次出门拍够两周的量,比"每天都要有内容"轻松得多。

⚠️ 这一类最贴近第八节说的"被编辑过的世界"——整套方法就是在优化外部读数。那条张力照旧并列,见文末。

## 六、C 类:人文纪实——主角不是人,是地方

前面所有规则都围绕"人在画面里怎么好看"。C 类不一样,人经常只是画面里的一个元素,甚至不出现。

| | A 纪念照 | B 生活方式照 | **C 人文纪实** |
| --- | --- | --- | --- |
| 主角 | 人 | 人(装作不经意) | **地方** |
| 人占画面 | 大 | 中 | **很小,或者没有** |
| 回答什么 | 我来过 | 我过得好 | **这儿有什么** |
| 要的东西 | 完整、清晰、可识别 | 氛围、松弛 | **信息缺口、时间痕迹** |

**打卡照拍的是"我在这儿",人文照拍的是"这儿有什么"。**

### 最有用的一条:换一个问题

站在一个地方,**别问"怎么把我拍进去",问这两句**:

> **这里最旧的东西是什么?**
> **这里正在发生什么?**

这个切换比任何参数都管用——它把眼睛从"找背景板"切到"找内容"。

### 五个技巧,按见效快慢排

1. **前景遮挡(最快见效)**——透过门洞、窗框、树枝、铁艺栏杆、门帘拍。**遮挡制造"偷看"的视角**,观众从旁观者变成在场者
2. **拍局部,不拍全景**——全景 = 信息完整 = 没有想象空间。拍整栋楼没意思,拍一扇雕花窗、一个门牌号、一段爬藤有意思。**信息缺口是观众参与的入口**
3. **找时间的痕迹**——斑驳墙皮、磨亮的门把手、褪色旧招牌、踩凹的石阶。**故事感 = 可见的时间**。⚠️ 反过来:**修缮一新的东西最难拍出故事**,因为它没有时间
4. **构好图,然后等一个人经过**——这条最出片。空景 + 一个路过的人 = 故事:**建筑提供"一直存在",人提供"正在发生"**,两者叠加才有时间感。方法是先构图先对焦,然后站着等
5. **找反差**——把两个不该同框的东西放进一张:洋楼底下的早点摊、老建筑里的新招牌

### 一个人出门怎么出镜

**背影、影子、局部**(手、鞋、包在场景里)——**不必每张都有脸**,C 类本来就不靠脸。想要正经人像就找路上认识的人帮拍,不用背三脚架。

### 后期不变

第七节那套原样沿用(提亮阴影、降饱和、统一色温、存成预设)。**人文感只多加一点颗粒**,其余一个字不改。

## 七、风格是一致性,不是单张的精致

这是和"拍好一张照片"完全不同的第二件事。

**后期比拍摄更决定风格。** 核心是四个字:低饱和 + 褪色。

| 参数 | 方向 | 作用 |
|---|---|---|
| 阴影 / 黑色色阶 | **提亮** ↑ | 黑不是纯黑——这是褪色感的核心,最出效果 |
| 饱和度 | 降 −10~−20 | |
| 自然饱和度 | 保留或略提 | 只提低饱和部分,不会让已经艳的更艳 |
| 对比度 | 略降 | |
| 高光 | 略降 | 避免死白 |
| 色温 | 统一偏冷或偏暖,选一个 | 中性色温最没风格 |

**但参数本身不是重点,这一条才是:把它存成预设,所有照片套同一个。** 一张一张分别调,调出来的是一堆各自好看的照片,不是风格——风格的定义就是 [[Concepts/一致性|一致性]]。

同一条规则在衣柜层的表达是"极简 + 一致性"——几件衣服、极少首饰、同一个廓形重复一辈子(见 Notes/个人/我要什么/撒娇不是不会-是被锁在了亲密场景里,以及千金感的真实成分)。**衣柜和相册是同一条规则的两个出口。**

**一组照片里,人像只该占三分之一。** 剩下的是桌面、食物、窗外、书、手部特写、背影、街边细节。这些空镜是给人像做呼吸的,全是正脸照的一组看起来就是自拍集。空镜还有个现实好处:不需要别人帮忙、不需要摆姿势、不挑当天状态。

**一组里要有景别变化**:远景 → 中景 → 特写。全是同一个距离会闷。

**三个手机细节**:别用数码变焦(损画质,而画质就是质感的一部分);人像模式的虚化在头发边缘最容易穿帮,宁可让人离背景远一点靠真实距离虚化;拍原片时别开美颜和相机自带滤镜——**风格要在后期加,烧进原片就救不回来了**。

## 八、参照系是被选过的样本

拿来对照的那些照片,是从几百张里选出来的一张,而且场地本来就是为了拍照挑的。选材标准只有一条:**能不能拍、好不好看**。下午茶能拍,图书馆坐四小时不能拍——所以它在结构上必然精致,不是因为那个人过得更好。这个机制叫「被编辑过的世界」,完整版见 Notes/个人/我要什么/撒娇不是不会-是被锁在了亲密场景里,以及千金感的真实成分。

认出这一点不改变上面任何一条技术建议,照做仍然有效。它只改变一件事:**照做之后也会有"选出来的那几张";到那时候,记得被比的那个人也只有那几张。**

## 张力(并列,不调和)

另一条判断是:气质不产生即时读数,所以别拿"有没有人夸我"当表现分,该换的是仪表盘而不是努力去够那个读数(Notes/思考/关系与处世/换仪表-气质不产生即时读数,所以别拿有没有人夸我当表现分)。

而上面整套方法在做的,正是把外部读数优化得更好看。

两条并列。一种可能的调和是"技术是工具,用不用、为谁用是另一回事",但那只是一种可能,没有定论。
