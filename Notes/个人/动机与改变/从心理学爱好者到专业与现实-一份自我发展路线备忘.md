# 起点:自评"过得不好"+发现自己太爱心理学、不现实

两个问题:"这么爱心理学哲学,能不能走职业道路/怎么变专业",以及"除了这个,我在社会上还缺什么"。用户自己点出了关键:太喜欢往心理/哲学方向钻,聊"怎么在社会上混得更好"时主动要求跳出心理学框架——这个自我觉察本身,和 Profile/行为准则 里"当下自评过得不好"是同一条线上的下一步。

# 一、想在心理学爱好上"变专业",落点在哪

结论不是转行,是把这个爱好嵌进已有的 HCI/UX 背景里(职业方向见 Profile/职业)。

## 四档分层,和现在的位置

| 档 | 能做什么 |
|---|---|
| 1 消费者 | 读科普、看视频,能复述结论 |
| **2 业余分析者** | 能把框架套到自己和别人身上,能**感觉到**哪些说法不对劲 |
| 3 能读一手文献 | 看得懂 method 和 results,知道效应量、样本量、复制性意味着什么 |
| 4 能做研究/临床 | 有督导、有真实个案或真实数据 |

**当前在 2 的上沿。** 支撑这个定位的正反两面都具体:

- **正面**:会质疑一个结论背后的推理而不是照收;能当场校正对方给的框架并且校正是对的;能把一个框架带到下一轮继续用。
- **反面**:遗传度这类误读是典型的"读了科普没读方法论"——不是知识量不够,是**训练类型**不对;而且面对任何一条标着"未核实"的说法,目前没有能力自己去核。

**实测锚点**(`claim_audit.py`,**截至 2026-09-10**,120 篇):**AI 转述 85 篇 70%,外部一手只有 5 篇 4%**;引用状主张 139 条,只有 61 条写了未核实,47 条在核心层。⚠️ 这组数会随新笔记变化,引用前重跑。**知识结构里二手占绝对多数,而且没有验它的工具**——这才是当前的真天花板,不是想得不够深。

## 2 到 3 之间那道门槛不是"读更多",是方法论

两档的区别不在知道多少理论,在**能不能独立判断一个说法可不可信**。方法论素养的特点是入门成本比想象低、回报断崖式——它把人从"信别人的判断"变成"自己判断"。

**"方法论"不是一个模糊的褒义词,它有具体内容,五块:**

**A. 研究设计的层级——决定一个说法配得上多强的动词。** 从弱到强:个案报告 → 横断面相关 → 纵向追踪 → 准实验 → RCT → 元分析/系统综述。核心一句:**横断面研究只能支持"A 和 B 有关",支持不了"A 导致 B"。**(库内已有一次实例:`Concepts/膳食纤维` 里 American Gut Project 那条标着"横断面相关性研究,因果方向未完全确定"。)

**B. 统计上要会读的四个东西(不用会算)。**
1. **效应量**(Cohen's d、r、OR)——有多大,不是有没有。**d < 0.3 的东西在个人层面基本感觉不到**
2. **置信区间**——比 p 值有用得多:CI 很宽 = 其实不知道;CI 跨过 0 = 效应可能根本不存在
3. **p 值是什么、不是什么**——`p<0.05` 不等于"有 95% 的概率是真的",这是被误解最广的一个
4. **样本量与统计效力**——**小样本 + 显著结果 = 效应量几乎必然被高估**,这一句就解释了为什么大量"惊人发现"复制不了

**C. 让结果不可信的几个常见机制。** p-hacking / 研究者自由度(分析路径上几十个可选项,不预注册排除不掉)、发表偏倚(阴性结果不发表 → 文献系统性高估效应)、HARKing(看完数据再编假设)、WEIRD 问题(大量结论来自西方大学本科生样本)、复制危机(上面那个 36%)。**认得这五个,能筛掉大部分垃圾。**

**D. 从群体推到个人那道坎——⚠️ 这块最该先补,优先于 A 和 B。** 因为现在的主要用法就是把心理学结论往自己身上套。**遗传度那个误读正属于这一类:群体统计量 ≠ 个体属性。** 同类的还有**生态谬误**(群体层面的相关不能直接推到个体),以及**平均效应掩盖个体差异**(一个 d=0.4 的干预,可能有 30% 的人完全无效甚至更差)。

**E. 怎么实际去查(操作层)。** Google Scholar / PubMed 搜原文 → **先看有没有元分析**(比任何单篇都重要)→ Retraction Watch 查有没有被撤稿。

### 最小可用集:四个问题

上面五块不用一次学完。**核一条主张时,只问四个问题:**

> 1. **这是什么设计?**(相关 / 实验 / 元分析)
> 2. **样本多大、是谁?**
> 3. **效应量多少?**
> 4. **有没有人复制过?**

**会问这四个问题,就已经在往第 3 档迈了。**

### 怎么开始

**入口不用新建:`claim_audit.py` 那个队列一直有上百条待核,每周核一条。** 但核的方式要换——不是查"这个说法对不对",是拿上面那四个问题去问它。一年 50 次真实的文献判断练习,嵌在已有流程里。

**要读书的话,方向是"研究方法 / 统计直觉",不是"心理学概论"。** Stanovich 的 *How to Think Straight About Psychology*(中译《与"众"不同的心理学》)就是专门干这件事的。

### 书单,按优先级(⚠️ 书名、作者、内容评价均凭记忆,未联网核查)

**第一优先——方法论(自己列为第一位的那条技能缺口):**

- Stanovich《与"众"不同的心理学》——如上
- **Stuart Ritchie《Science Fictions》**——复制危机、p-hacking、发表偏倚
- **Ben Goldacre《Bad Science》**——手把手拆一个健康/心理学宣称

> 这一格读完,库里那七成「AI 转述」的处理能力直接换一档。

**第二优先——认识论(把这些内容串起来的那根线):**

- **Julia Galef《The Scout Mindset》**——实质上就是"当先验用、不当真理用"的通俗版
- **Nate Silver《The Signal and the Noise》**——贝叶斯思维入门
- **波普尔《猜想与反驳》**——可证伪性的源头
- **Kahneman《思考,快与慢》**——⚠️ 书里部分研究(尤其启动效应那几章)在复制危机中没能通过,作者本人后来公开承认过。**正因如此它是极好的练习材料**

**第三优先——能直接动到日子的那一格(CBT):**

- **David Burns《伯恩斯新情绪疗法》(Feeling Good)**
- **《Mind Over Mood》**——工作手册式,有练习表

> 前两格改的是判断力,**这一格改的是日子**。

**关于高敏那本**:Elaine Aron《The Highly Sensitive Person》——⚠️ **构念提出者本人写的通俗书,流行度远高于证据强度**。但正因如此它是最好的练习对象:一边读一边跑上面那四个问题。**读一本已知有争议的书,比读一本以为可靠的书学得多。**

⚠️ **顺序是先补验证工具再补内容**,理由就是本节开头那句:2 到 3 档的门槛不是读更多。**别从人格心理学教材开始。**

**还有一条附带的判据:能分辨"听起来专业"和"证据扎实"的差别,本身就是专业度的一部分。** 学术腔会让一句话显得更可信,但那份可信是修辞造成的,不是证据造成的;标注对抗不了语气。**一个听起来很有分量的判断,分量可能全在措辞上——遇到就直接问"这个数字多大、你怎么知道的"。**

## 一个被低估的现成资产

**HCI 硕士本来就含研究方法训练**——用户研究、实验设计、读实验论文。这套方法是通用的,不因为它挂在"设计"名下就不算心理学素养。**离第 3 档比自评的近,缺的是把那套训练调过来用在这个领域上,不是从零学。**

## 第三层仍然成立:能产出,不只是能理解

把心理学框架显式用在作品集上,写清楚"为什么用这个框架、它哪里可能不适用"——这是从爱好者到专业者的分界线。

## 3 到 4 之间那道门槛:提出一个构念,和选一个题

起点是问"我这个四格拆法(幅度/阈值/恢复/解释)加上操作化定义、量表、信效度检验,是不是就能发论文了"。**答案:那三样是必要不充分,而且都不是最难的一关。**

### 最难的是增量效度——而且那四格没有一格是空地

审稿人拿到新构念,第一个问题永远是:**控制了已有构念之后,你这个还能多解释多少方差?**

| 格子 | 已经占着这块地的构念(和量表) |
| :--- | :--- |
| 幅度 | 情绪反应性 / 神经质;Affect Intensity Measure |
| 阈值 | 感觉加工敏感性;HSP 量表的"低感觉阈限"因子 |
| 恢复速度 | 情绪恢复 / affective chronometry;反刍(RRS) |
| 解释 | 认知重评(ERQ);归因风格(ASQ);评价理论 |

一旦区分效度不过关,结论就是:**测的是已有的东西,只是换了个名字。** 这个毛病有专名——**jangle fallacy**(用不同名字称呼同一个东西),及其导致的**构念增殖**,是人格心理学被批评了几十年的老问题。**加量表不解决它,加量表恰恰是暴露它的方式。**

### 真东西不在四个成分,在那个乘法结构

> **痛苦 ≈ 幅度 × 时长 × 解释**

**这是可证伪的**,而且预测和加法模型不同:**幅度高但恢复快的人,应该比幅度中等但恢复慢的人痛苦更少**(一个交互项)。

**关键:检验它不需要造新量表,现成量表就够。** 要的不是"提出一个新构念",是"**检验一个关系**"——后者门槛低一个数量级,而且不挑战任何人的地盘。

### 那三样各自的真实难度,和想象相反

- **操作化定义**:看着最简单,实际最难。难的不是写定义,是**让它可被区分**——"恢复速度"和 RRS 相关 .75 的话,测的就是反刍。
- **量表**:是工序不是聪明。写题 → 专家评审 → 预试 → 题目分析 → EFA → 独立样本 CFA → 交叉验证,要**几百人、两个独立样本**。钱和时间的问题。
- **信效度**:四关难度差极大。信度容易;聚合效度容易;**区分效度会卡死;增量效度是生死关**(控制大五 + 现有量表后还能不能预测)。

### ⚠️ 一个更致命的方法学问题:自评测不开"幅度"和"解释"

幅度是**生理参数**,而自评问到的是"你对自己反应的记忆和评价"——**那正好是第四格**。用同一个方法测两个理论上要区分的东西,即**共同方法偏差**。

真要测幅度需要**生理指标**(HRV、皮电、皮质醇)或**经验取样(ESM/日记法)**,后者才测得出"时长"。两条都不是问卷星能做的。**反过来说,这恰好是这个想法唯一真正原创的落点。**

### 现实层

**渠道**:投稿要机构挂靠和伦理审查批件,独立研究者极难(不是歧视,是审稿人会问数据怎么收的)。**时间**:量表编制 + 验证从设计到发表,**两到四年是常态**。

**三个版本按成本排:**
1. **低成本(几周,自己能做)**:不造量表,用现成的(AIM / RRS / ERQ / GAD-7),只检验那一个交互假设,便利样本几百人。产出一份带数据的分析报告或长文——**已经比绝大多数自媒体心理内容硬**。
2. **中成本**:找一个能带的人。**UCD 的导师、同学、学院是真实入口**,合作 + 挂靠一次性解决伦理、渠道、方法把关三件事。
3. **高成本**:读博。那是换人生路线,不是做一个项目。

### 研究者实际怎么选题——浪漫版本是错的

**不是"想到一个好问题",绝大多数选题是从一个已有的位置里长出来的:**

1. **捡别人论文的 Limitations / Future Directions**——最大的公开矿藏,而且自带合法性:同行自己写的,审稿人不能说这问题不重要
2. **捡文献里两篇打架的地方** → 找调节变量("A 在什么条件下成立"),最标准也最安全的一类
3. **从导师/实验室已有的数据和项目里长**——现实中最常见。**不是自由选题,是在已有基础设施(数据、被试池、设备、伦理批件)上找能做的事**
4. **方法迁移**:一个领域成熟的方法搬到还没用过它的领域,低风险高产出(HCI 背景在这里是真优势)
5. **量表有问题** → 心理测量学方向
6. **直接复制 + 扩展一个经典发现**——复制危机之后这是可发表的
7. **真从生活经验来的**:少,但往往是好论文的来源。⚠️ **前提是先被翻译成文献里的一个空白**——说得清"现有理论对这个说了什么、缺了什么"才算选题,这一步就是文献综述,没有捷径

> **选题不是"找一个好问题",是找一个 重要性 × 可行性 × 空白 三者同时满足的缺口。**
> 外行只看第一个。而"痛苦 = 幅度 × 时长 × 解释"正是典型:重要性有,空白存疑,**可行性很差**(要 ESM 或生理指标)。

⚠️ **还有一半诚实的答案:选题被"能不能发"倒推。** 要发表、要毕业、要评职称,所以系统性偏向低风险、有现成数据、两年内能出结果的题。不是道德问题,是激励结构。

### 最小可执行动作:文献综述式选题练习

**今天就能做,而且它就是上面「证据评估能力」那条技能的实战:**

1. 挑一个具体问题(如"恢复速度和反应强度对痛苦有没有交互")
2. Google Scholar 搜 3–5 组关键词
3. 找 2–3 篇近五年的**综述**,顺参考文献往回滚
4. **专门读每篇的 Limitations 和 Future Directions**
5. 记下:谁做过、结论是什么、他们自己说缺什么
6. 再问:我的想法还剩什么是新的?

**两个结局都算赢:发现已经有人做过 → 省下两年,这是最常见也最有价值的结果;发现真有缺口 → 有了一个真选题。**

⚠️ **本节全部外部内容(jangle fallacy、构念增殖、增量效度、共同方法偏差、量表编制的样本量经验法则、选题机制)均凭训练知识,未联网核查。** 真要往这个方向走,每一条都得自己查原文——而这本身就是第一节那四个问题的第一次实战。四格拆法本身的身份声明见 Notes/个人/动机与改变/天生的倾向是偏置不是剧本-遗传度的误读与倾向的三层拆法 第七节:那是本库自己的工作模型,不是标准分类。

# 二、现实技能清单(除心理学之外,该涉猎的)

按优先级排,不是心理学范畴,是纯实操:

1. **证据评估能力(批判性阅读)**——最值得优先补的元技能。笔记库里大量 `verified: false`/GC 复核发现"有争议或部分不准"的内容,目前全靠事后 AI 复核纠错,没有当场判断的本能。这条还和边界感缺失是同一个漏洞的两面:对"听起来有条理的说法"缺乏当场质疑,既让人被 PUA/双标钻空子,也让人无差别采信 AI 生成的科普内容。
2. **系统的人际沟通技巧**:非暴力沟通(NVC,观察-感受-需要-请求)或主张性训练(assertiveness training)——现在立边界靠事后找 AI 要话术(同事双标事件即是),练一套自己内化的表达框架能省掉这一步。
3. **法律与合同常识**:劳动合同条款(竞业限制、试用期、离职交接)、租房合同责任条款、基本维权渠道(劳动仲裁、裁判文书网查证)。
4. **谈判技巧**(当技术学,不套心理动机):BATNA、锚定、议题拆分——跳槽谈薪、租房议价能直接用。
5. **背调/信息甄别方法**:天眼查/企查查看股权诉讼、裁判文书网查官司、领英/脉脉核实履历——判断机会/合作方靠不靠谱,靠查证不靠直觉。
6. **具体的人情世故操作手册**:随礼标准、饭局敬酒顺序、维系关系的联系节奏——当成可背的操作规范,不需要先理解"为什么"。
7. **基础经济/时事常识**:看懂新闻背后对自己生活/行业的实际影响。

财务/职业本身已有 Profile/职业 单独跟踪,这里不重复。

**截至 2026-08-29,这份清单一项都还没碰。** 她给的理由不是没兴趣或忘了,是当下的活跃目标是作品集,这份清单被明确排到"以后",用户自己的原话是"现在还没到时候",拒绝把这段搁置直接解释成回避。清单当时列出来时是真心觉得该补,但没有约定任何复查时间点——排到"以后"和真的被遗忘之间,唯一能事后分辨的标志是作品集告一段落后这份清单会不会被主动想起来重新打开,而不是现在有没有在做。

# 四、一个待决的元问题:该让 AI 记,还是自己记

她问过"记好还是我自己记好",没有定论,留一句判断供以后参考:**客观事实/画像类信息(profile 层)AI 记录更省心、更不容易漏;但需要巩固理解、训练"输出"能力的内容(尤其是概念定义、深度反思),用户自己先写(哪怕写得糙)、AI 再帮着结构化和建链接,可能比全程由 AI 代写更有效**——理由是"输出能力靠什么练出来"这个问题本身:如果连记忆都全部外包给 AI,等于持续在做被讨论为问题的那件事(什么都先问 AI、不自己先产出)。这条判断没有和她核实过,只是原样列出。
