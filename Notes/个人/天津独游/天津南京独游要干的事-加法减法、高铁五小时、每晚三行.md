# 天津南京独游要干的事

10/02–10/06,5 天 4 晚,今年给自己定的一件事:一个人出门。


## 这趟要什么

**不累;景点少而深;带着对这座城的理解去看;玩得像本地人,不去网红打卡店;带回能讲出口的故事,和一两样有自己痕迹的东西。**

下面每一条都用这几个标准去量。这几样其实是同一件事:点少了才有空隙,有空隙才碰得到本地人和故事。


## 二、加法(几乎不占时间)

- **相声坐前排**,点一壶茶,**跟着观众喊「嘿」、叫好、鼓掌**。天津相声的规矩是观众也算演出的一部分,只看不出声,等于只看了一半。
- **10/03 晚上别直接进房间**,在旅舍公共区待一小时。国庆的女生青旅坐满了独自出门的人,开口一句就够:「你今天去哪儿了」「明天有什么推荐吗」。
- **天津之眼摩天轮**:10/02 晚上海河散步那段就在它脚下,上去 20 分钟。它是骑在桥上的摩天轮。
- **多跟人说话**。天津人是全国最好聊的之一,有四个现成的对象:
  - 出租车司机;
  - 早点摊老板,进门问一句「**您这儿最地道的是哪个**」;
  - 还住在五大道里的老居民;
  - 海河边钓鱼、游泳的大爷。
- **10/02 一起吃饭的朋友如果是天津人,就让对方挑馆子**。这是变成「本地人」最直接的一张门票。

## 三、三件「一个人做会有点不好意思」的事

一个人坐高铁、一个人住店都没难度。有难度的是这三件,它们才是「一个人出门」的实际内容:

1. **一个人进桂园这样的老馆子,正经点一桌菜**,不是只点一碗面。
2. **一个人坐到相声园子第一排。**
3. **主动跟陌生人说第一句话。**

**做成一件就够**,不用三件都做。

## 五、高铁上的时间

这趟有三段高铁:

| 段 | 时长 | 做什么 |
|---|---|---|
| 虹桥 → 天津西 | 5 小时 42 分钟 | 读书,最长的一段 |
| 天津南 → 南京南 | 3 小时 46 分钟 | 补写前一晚的三行,然后睡一觉,别再塞任务 |
| 南京 → 上海 | 约 2 小时 | 想想这趟要讲的那个故事 |

**第一段读地图,不读隧道。** 目的不是成为专家,是让五大道那些洋楼从「好看」变成「可读」。这个分法出自 Notes/思考/认知/挖洞式对话学习的三个缺陷和两个锚-书当地图对话当隧道。

**地图只有一句话:天津是北京的门厅。** 想进北京的先从这儿过,被赶出北京的就在这儿住下等着回去。从元朝的码头,到溥仪从静园出走,完整的故事串在 [[Notes/个人/天津独游/天津是北京的门厅-想进京的从这儿过,被赶出京的在这儿等|天津是北京的门厅]] 里,出发前读那一篇就够了。

那篇没讲到、这趟会碰到的两个人:

- **李叔同 / 故居**:天津富商之子。他是中国最早用五线谱作曲、最早开人体写生课的人之一,话剧先驱。《送别》(「长亭外,古道边」)是他写的。1918 年出家,成了弘一法师。一句话概括:**极致入世,然后极致出世**。
- **梁启超 / 饮冰室**:「饮冰」出自《庄子》「今吾朝受命而夕饮冰,我其内热与」,意思是心里焦灼到要喝冰水才压得住。**「饮冰室主人」这个号,本身就是一个中年人的自况。**

**带一本书:冯骥才《俗世奇人》。**

- 短篇集,每篇两三页,一段高铁刚好读完。
- 写的是清末民初天津卫的市井奇人,里面有《泥人张》一篇,正好对上古文化街。
- 读完再去听相声、逛古文化街,看到的东西性质完全不同。
- 想深一点的备选:溥仪《我的前半生》**只读天津那几章**,配张园和静园;《梁启超家书》,配饮冰室,好读。

**路上听两段马三立**:《逗你玩》《买猴》。到了茶馆才知道笑点在哪、什么时候该喊。第二节说的「跟着出声」,前提是听得懂。

## 六、拍什么照

这趟拍两类,规则正好相反:

- **拍地方**:人文纪实,主角是地方不是人。打卡照拍的是「我在这儿」,这类拍的是「这儿有什么」。
- **拍自己**:穿搭照,要 ins 感、要潮,但不一定露脸。

两类的通用方法都在 Notes/个人/日常/拍照好看的变量在条件不在脸上-四个可控项,以及风格是一致性不是单张精致.md:人文纪实在第六节(换一个问题、前景遮挡、拍局部、找时间痕迹、等人经过、找反差),生活方式照在第五节(拍动作的中间帧、连拍挑中间几张)。这里只写这趟用得上的。

### 拍地方:点位表

| 地方 | 拍什么 |
| --- | --- |
| **早点摊**(连去三天) | 蒸汽、手、炉火。**最有生活感的题材,而且有三次机会** |
| **相声茶馆** | **拍台下,不拍台上**:观众的背影、茶碗、光束里的烟 |
| **五大道** | 院门、门牌号、铁艺栏杆、爬藤 |
| **静园** | 室内窗格投在地上的影子 |
| **意风区** | 意式洋楼加上底下的市井。**天津最有张力的反差就在这儿** |
| **古文化街** | 颜色浓(红、金),拍局部:泥人的脸、幡子、屋檐一角 |
| **西开教堂** | 早上的侧光打在立面上 |
| **海河 / 天津之眼** | **蓝调时刻**:日落后 20–30 分钟,天还有颜色,灯已经亮了,比全黑好看得多。天津这几天大约 18:00 日落(未核)。10/02 那天 18:00 在吃饭、19:30 天已全黑;**10/04 傍晚 18:20 去码头的路上,正好赶上** |
| **狮子林桥** | 桥上的狮子当前景,海河当背景 |
| **明孝陵** | 石象路两边的石兽和树 |

⚠️ **翻新过的景点最难出片**:修缮一新的东西没有时间痕迹,而故事感就是看得见的时间。那几处按打卡拍完就走,别耗着。

### 拍自己:有 ins 感的穿搭照

**潮感主要来自拍法、廓形和配件,不太靠衣服颜色**,所以淡色衣服完全拍得出来。这一条是推论;如果心里的「潮」本来就要更大胆的颜色,以自己想要的为准。

**一个人怎么拍到自己:**

| 办法 | 怎么做 | 适合拍什么 |
|---|---|---|
| **录视频再截图** | 手机架好,开 4K 录像,自然地走一遍、回一次头、整理一下头发,回去逐帧挑。**一个人出门最好用的一招**:拍到的永远是动作的中间状态,不像摆拍 | 走路、回头、街景里的全身 |
| **定时加连拍** | 定时 10 秒加连拍,一次出十几张 | 坐着、靠着、站定的全身 |
| **小三脚架加蓝牙遥控** | 几十块钱,能夹在栏杆上;按遥控时手藏进袖子或背后 | 各种场景 |
| **就地取材** | 手机靠在早点摊桌上、窗台上、扶手上 | 半身、局部 |
| **找人帮拍** | 旅舍认识的人。和第二节「多跟人说话」是同一件事 | 想要正经人像时 |

**五种有 ins 感的拍法:**

1. **0.5 倍超广角,机位放低往上拍。** 手机放到膝盖高度、镜头朝上,能拉长腿,也把洋楼和天空拉进画面。别离镜头太近,不然脸和手会变形。
2. **镜子和反光。** 酒店电梯、汤泉的镜子、店铺橱窗、高铁车窗都行。手机挡住半张脸,隐私感也就有了。
3. **夜里开闪光灯直接拍。** 人亮、背景暗,有胶片和杂志的感觉。浅色衣服在闪光下最出效果。
4. **只拍局部。** 鞋踩在老地砖上,包放在早点摊桌上,手里拿着车票或煎饼果子。不露脸,也最有生活感。
5. **故意拍出反差。** 一身精致的穿搭,站进早点摊、老胡同这种市井环境。精致的人出现在不精致的地方本身就潮,比站在网红墙前拍高级。

**不露脸的几种办法**:戴墨镜、侧脸看向别处、头发挡一半、构图从下巴往下切、只拍背影或影子。

**按行程挑的机位:**

| 什么时候     | 在哪      | 拍什么                |
| -------- | ------- | ------------------ |
| 10/02 去程 | 高铁      | 靠窗的侧光加车窗反光,第一张「出发」 |
| 10/02 晚  | 海河、天津之眼 | 闪光灯直打的夜景人像         |
| 10/03 早上 | 早点摊     | 精致穿搭配煎饼果子,反差照      |
| 10/03 白天 | 五大道     | 铁门、红砖墙前走路,用录视频截图   |
| 10/04 傍晚 | 去码头的路上  | 蓝调时刻的半身或背影         |
| 10/04 晚  | 汤泉      | 镜子自拍               |
| 10/05 早上 | 西开教堂    | 0.5 倍低机位往上拍,把立面拉进来 |
| 10/06    | 明孝陵石象路  | 走路的背影              |

国庆人多,有两个办法避开路人:靠近拍,用局部把人群切掉;或者低机位往上拍,让天空当背景。

### 发出去:做成一组照片合集

一次发九张左右,杂着放:

- 两三张有自己的穿搭照;
- 剩下的是早点、车票、泥人、窗外、影子、一张糊掉的夜景。

这正好对上那篇拍照笔记里「人像只占三分之一」那条。全程用 4:5 的画幅,套同一个滤镜预设,拍原片时别开美颜。

## 七、打猎清单

[[Notes/个人/我要什么/我想要的东西|愿望清单]]里有一条:「摆着我从各个地方**打猎**回来的小玩意,处处是我自己的痕迹」。落到这趟就是:**别买印着地名的标准纪念品,那些最后会进抽屉。**

这趟没有专门买东西的时段,有两个空当可以用:

- **10/02 下午逛古文化街时**;
- **10/04 傍晚**:18:20 到码头,19:40 才开船,中间这一个多小时就在古文化街。

南京那天排得满,想买的在天津买齐。

按优先级:

1. **泥人张**的小泥人。古文化街有的店能自己上手捏一个。
2. **杨柳青年画**,买小幅的,能裱。
3. 旧货摊上一件**没有名字**的小东西。

## 八、像本地人:吃什么、怎么挑

**看位置挑店。** 开在景区或步行街里的分店,主要做游客生意,比如金街、意风区、五大道店、古文化街。

- **天津早点**:别去名店,去旅舍附近、门口有老人拎着塑料袋排队的那家。点嘎巴菜、老豆腐、煎饼果子,煎饼要夹果篦儿。
- **南京**:两顿都排了南京大牌档。它在本地人眼里基本是游客店,同一家连锁吃两次也浪费名额。换一顿去老字号小馆,吃鸭血粉丝汤、皮肚面、锅贴。

## 九、南京那一天半

南京是这趟历史线的另一头:

- 中华民国在这里成立;
- 孙中山葬在这里;
- 抗战结束时,中国战区的日军投降仪式在这里举行。

所以 10/06 上午在钟山那一片,音乐台、明孝陵、中山陵,看的都是同一条线的结尾。

10/05 下午到了以后只排了玄武湖和晚饭,节奏是对的,别再往里加。

## 十、每晚三行

故事不是没发生,是回来就忘了:当晚记下的和三天后回想的,细节量差一个数量级。

睡前写三行,不写日记:

1. 今天**最意外**的一件事;
2. 遇到的**一个人**,他说了什么;
3. 一个**具体细节**:一个价格、一种气味、一句原话。

**门槛低到在旅舍大厅、汤泉休息区就能写完**,而这是半年后还能讲出这趟的全部依据。回来直接进 `Diary/`,那里不需要 tier 和 frontmatter。
