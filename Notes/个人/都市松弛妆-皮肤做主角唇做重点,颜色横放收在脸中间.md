# 都市松弛妆

**主张:皮肤做主角,唇做那一处重点,眼睛安静但有神;所有颜色横着放、收在脸中间。**相关:[[Notes/个人/日常/拍照好看的变量在条件不在脸上-四个可控项,以及风格是一致性不是单张精致]]

## 为什么是这个分配

想要的形象是都市感、略松弛、有造型、chill,性子淡,不张扬。穿法是黑色廓形外套 + 牛仔裤 + 小靴子 + 一只彩色包——中性的底,一处跳色。妆照搬这个结构:**水光皮肤是底,唇是那只彩色包。**

**不让眼睛当主角**:不喜欢画眼线(戴着不舒服),双眼皮窄、上了眼妆基本看不出,眉眼间距又近——在眼睛上用力,成本高、回报低。雀斑、平眉、柔和五官这些条件,天然适合"没怎么化但气色很好"的底子。

化完从远处看一眼:第一眼落在好皮肤和嘴上,就对了。

## 三条从脸型推出来的原则

面部条件:脸大、远看偏阔;额头高、下巴长、中庭偏长、人中略长;颧骨略高、两侧脸颊大、轮廓不清晰;嘴小、上唇薄、唇干瘪;眉眼间距近、眼间距略宽、山根低;吊梢眼、双眼皮窄。

1. **颜色横着放、收在脸中间**:脸又长又宽,横向的腮红和平眉能缩短长度,往中间收则不把脸撑宽
2. **内光外雾**:光会让面积显大。水光只留在脸中间,脸侧和下颌哑光,水光肌和轮廓感同时成立
3. **眼睛不靠线,靠睫毛根阴影 + 睫毛翘度**

## 皮肤:薄、润、分色处理暗沉、保留雀斑

风格重点是**"干净"而不是"无瑕"**。完全遮平的底妆会变厚、显假、显脸平,而且一整片均匀肤色让留白多的脸更大更平。**把"脏"的地方提亮,把"特色"留下来。**

- **妆前保湿做足**:水乳之后等几分钟吸收,水润是通透感的基础
- **底妆要薄**:气垫或轻薄粉底液,只在脸中间拍开往外带,脸边缘几乎不上;也可以混一点面霜。正在长痘、有闭口时,质地清爽不闷比光泽度更要紧
- **分色遮瑕**:

| 位置 | 状况 | 处理 |
|---|---|---|
| 眼下 | 紫红色黑眼圈 + 青色血管 | 桃色/杏色校色遮瑕,只点在发暗那一条,薄 |
| 眼周一圈 | 橘红色 | 偏黄的肤色遮瑕或眼部打底薄压,**别再用桃色**(会更红)。顺便给窄双眼皮里的眼影打了底 |
| 嘴角 | 发黄 | 偏粉调遮瑕点一点,同时把嘴角往上提 |
| 额头 | 发黄 | 粉底带过即可;介意再局部用淡紫色妆前 |
| 泪沟 | 凹陷 | 遮瑕最多比肤色亮半号,太白会发灰;指腹压薄,不堆,不用带闪的提亮 |
| 脸颊、鼻子 | 雀斑、略泛红 | **雀斑不遮**,气垫带过若隐若现即可;泛红交给腮红接住 |
| 痘、痘印 | — | 点涂 |

- **只定额头、鼻子和脸外圈**,脸颊中间保留光泽
- **最后喷一点定妆喷雾**,粉感消失,看起来更像真皮肤

## 腮红:横向、收在脸中间

- **位置**:苹果肌偏内,横向椭圆,上缘离下睫毛约一指,外侧不超过眼尾垂直线;最后轻扫过鼻梁把两边连起来——配雀斑就是晒过太阳的感觉
- **不要斜向上拉向太阳穴**:斜向上会把中庭拉长
- **颜色**:干枯玫瑰、玫瑰豆沙、肉桂奶茶这类低饱和、偏玫瑰的中间色
- **质地**:膏状或液体,底妆后用手指拍,血色像从皮肤里透出来;同一支顺便点唇,一物两用

## 修容与高光:缩短长度,补出轮廓

- **发际线**:横向一窄条阴影,缩额头
- **下巴尖**:底部横扫阴影,缩下巴。**下巴不打高光**——会更长
- **脸侧**:从耳下往嘴角方向扫,到眼尾垂直线就停,下颌线带一下补轮廓;偏灰的浅棕,不要偏橘
- **鼻子**:山根低,鼻影只从眉头扫到内眼角,不拉长鼻影(会拉长中庭);山根点一个小亮点,鼻尖可以点一点;鼻翼两侧一点点阴影收鼻头。量一定要少,最怕画成"两条线"
- **颧骨外侧不打亮**:会更宽

## 眉毛:从"凶"到"温柔有精神"

眉毛和眼珠偏青黑,头发暖棕偏黄——眉毛单独压着一块深色,是显凶、显重的来源。

- **染眉膏用灰棕或摩卡**,夹在发色和眼珠颜色之间;太橘会和青黑的眼睛打架
- **梳法**:眉头向上梳,眉中向上再向后,用螺旋刷带一下
- **形状平直**,眉尾水平、略拉长,不上挑——压住吊梢眼的上扬,也横向缩短脸
- **眉眼间距近**:眉下缘不补,可以修掉杂毛;要补只补上缘
- **眼距略宽**:眉头可以略往内起,梳虚

## 眼睛:一个哑光大地色 + 睫毛

### 眼影代替眼线

1. **眼皮打底**:即上面压橘红那一步
2. **铺色**:睁着眼找位置,灰棕/奶咖哑光色铺到睁眼时能露出来的高度;别往上晕太多,眉眼间距本来就近。眼皮上不用大颗粒闪,窄双眼皮会卡、会显肿
3. **按压睫毛根**:小平刷蘸深棕色,一点点按进上睫毛根的空隙——看不出线条的眼线,戴着也不难受
4. **眼尾平收,不上挑**:顺着下眼睑延长方向往外带 2–3 毫米,接近水平或略往下
5. **下眼尾**:外侧三分之一扫同一个棕色,和上眼尾松松连起来,柔化吊梢的锋利感
    - 日常清透:上下眼尾之间留一点小空隙不连,眼睛更开阔
    - 氛围感:上下眼尾晕在一起,中间小三角也扫一点,边缘全部晕开,看不出线
6. **内眼角**:点一点同色往前带一点,缩眼距;不要用很亮的内眼角提亮(会显眼距更宽)

### 睫毛:重点是"翘",不是"浓"

睫毛容易被眼皮压着下垂,挡住眼睛、像半睁。夹翘是性价比最高的一步。

- **分段夹**:根部停几秒,再中段、尖端各一下,弧度自然
- **防水打底或防水睫毛膏**定型,细软的睫毛才撑得住
- **薄刷、根根分明**,一两层,不要苍蝇腿
- **重点刷中间到内侧**,让眼睛上下打开;眼尾睫毛不再往上拉(吊梢眼会更吊)
- **颜色深棕**,比纯黑柔和
- **下睫毛**:外侧轻刷一点
- 不需要浓密假睫毛或夸张嫁接;想更浓就选自然款小簇,只贴眼尾

### 卧蚕:可选,只用哑光

眼尾上挑加平眉会偏利落偏冷,卧蚕能让眼睛像在笑。但眼下有紫红色黑眼圈和泪沟,带闪的卧蚕会把它们放大、显浮肿——要画只用哑光浅肤色提亮,下面浅棕轻轻一条阴影晕开;不画也完全成立。

## 唇:全脸唯一可以有颜色的地方

- **最先涂润唇**:化妆一开始就涂,上唇色前擦掉——唇干瘪靠这一步
- **唇线笔(裸玫瑰色)改形**:上唇唇峰和唇中往外画出约 1 毫米,上唇变饱满、人中显短;嘴角略往外往上延,嘴不显小。放松时嘴角略往下,配合嘴角下方点一点遮瑕提亮,表情会柔和
- **质地**:唇釉、唇油或有色润唇,要光泽;哑光会把干纹放大
- **颜色**:日常玫瑰豆沙;更都市选红棕、砖红偏棕、浆果豆沙——和黑色外套最搭
- **边缘微晕**:唇线笔定好形,唇釉填中间,边缘用指腹晕一下,比清晰满唇低调,不张扬

## 颜色总原则

中性肤色(底色偏黄白、脸颊带一点粉),五官偏青黑,头发暖棕偏黄 → 选**中间调、略带灰**的颜色:玫瑰棕、摩卡、肉桂、豆沙。

- **避开纯橘**:放大眼周的橘红和额头、嘴角的黄
- **避开冷的荧光粉**:和暖黄的发色打架
- 自测色调:自然光下看手腕血管,偏绿暖、偏蓝紫冷、两种都有是中性

## 两个版本

**5 分钟上班版**:
1. 桃色遮瑕(眼下)+ 薄气垫
2. 膏状腮红拍脸颊、扫鼻梁
3. 染眉膏
4. 夹睫毛 + 睫毛膏
5. 有色润唇或唇釉

**完整版**:在上面基础上加分区遮瑕、修容(发际线、下巴、脸侧)、眼影(含睫毛根)、唇线笔。

每类产品留一样就够,一物多用优先。

## 发色和发型

发色是不用漂的暖棕(栗棕、焦糖棕、暖茶棕一带),柔和、和雀斑呼应。**避免**太冷的灰色、亚麻色(显皮肤黄)和漂得很浅的颜色。

**发型**:发根烫 + 八字刘海 + 层次剪 + 发尾微卷。脸侧层次和八字刘海对脸宽、额头高的修饰,效果比化妆更明显。不追求完全平整,但也不是什么都不管。

## 不靠化妆的部分

- **睡眠**:眼下暗沉最大的变量,作息改善比任何遮瑕都有效
- **表情**:放松额头、带一点笑意
- **体态**:头不往前探,下巴微收,下颌线会更清楚
