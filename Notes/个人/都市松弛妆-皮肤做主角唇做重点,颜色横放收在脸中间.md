# 都市松弛妆

**主张:皮肤做主角,唇做那一处重点,眼睛安静但有神;所有颜色横着放、收在脸中间。**相关:[[Notes/个人/日常/拍照好看的变量在条件不在脸上-四个可控项,以及风格是一致性不是单张精致]]

## 为什么是这个分配

想要的形象是都市感、略松弛、有造型、chill,性子淡,不张扬。穿法是黑色廓形外套 + 牛仔裤 + 小靴子 + 一只彩色包——中性的底,一处跳色。妆照搬这个结构:**水光皮肤是底,唇是那只彩色包。**

**不让眼睛当主角**:不喜欢画眼线("感觉画眼线特别不舒服,最多画一点点"),双眼皮窄、上了眼妆基本看不出,眉眼间距又近——在眼睛上用力,成本高、回报低。雀斑、平眉、柔和五官这些条件,天然适合"没怎么化但气色很好"的底子。

化完从远处看一眼:第一眼落在好皮肤和嘴上,就对了。

## 这张脸的条件

**五官**:脸大、远看偏阔;额头高、发际线高、下巴长、中庭偏长但鼻子不长、人中略长;颧骨略高、两侧脸颊大、轮廓不清晰;嘴小、上唇薄、唇干瘪;眉眼间距近、眼间距略宽、山根低、鼻头偏圆;杏仁眼、眼尾微微上扬;双眼皮窄,上了眼妆基本看不出。

**颜色**:中性肤色、底色偏黄白;眉毛和眼珠偏青黑;头发发尾暖棕偏黄,发根偏黑但不算特别黑。

**皮肤**:额头和嘴角发黄;眼周一圈橘红色黑眼圈,眼下紫红色黑眼圈加青色血管;泪沟明显;法令纹较重;**面中天生泛红**——苹果肌偏内一大块;鼻子、脸颊、额头有雀斑;额头有闭口、会长痘。

素颜照上核对得到的:额头高、眉眼间距近、山根低、嘴小上唇薄、杏仁眼微扬、面中泛红、雀斑。**下巴、中庭、人中的长度从俯拍照里判断不了**——俯拍会放大额头、压短下半张脸,要站着、手机平举到鼻子高度再对一次。

## 三条从脸型推出来的原则

1. **颜色横着放、收在脸中间**:脸又长又宽,横向的红和平眉能缩短长度,往中间收则不把脸撑宽
2. **四边压暗、光放在红区上方**:光会让面积显大。光泽只放在眼下三角和颧骨顶端靠内,脸侧、下颌、颧骨外侧哑光;面中的红区保持柔光,太亮会像晒红或发热
3. **眼睛不靠线,靠睫毛根阴影 + 睫毛翘度**

## 皮肤:薄、润、分色处理暗沉、保留雀斑

风格重点是**"干净"而不是"无瑕"**。完全遮平的底妆会变厚、显假、显脸平,而且一整片均匀肤色让留白多的脸更大更平。**把"脏"的地方提亮,把"特色"留下来。**

- **妆前保湿做足**:水乳之后等几分钟吸收,水润是通透感的基础;脸颊会起皮,这一步省不得
- **底妆要薄**:偏黄调的气垫或轻薄粉底液,只在脸中间**按压**开、往外带,不来回推;脸边缘几乎不上。正在长痘、有闭口时,质地清爽不闷比光泽度更要紧
- **分色遮瑕**:

| 位置 | 状况 | 处理 |
|---|---|---|
| 眼下 | 紫红色黑眼圈 + 青色血管 | 桃色/杏色校色,只点在发紫发青的那一块,再盖一层偏黄的肤色遮瑕,薄 |
| 眼周一圈 | 橘红色 | 偏黄的肤色遮瑕或眼部打底薄压,**别再用桃色**(橘上加橘更红)。顺便给窄双眼皮里的眼影打了底 |
| 嘴角 | 发黄 | 桃色或偏粉调遮瑕点一点,嘴角下方往上提亮,嘴角显得上扬 |
| 额头 | 发黄 | 粉底带过即可;介意再局部用一点淡粉色隔离。淡紫色上在黄调皮肤上容易发灰 |
| 泪沟 | 凹陷 | 只沿凹陷那条线点,最多比肤色亮半号,太白会发灰;指腹压薄,不堆,不用带闪的提亮 |
| 面中 | 天生泛红 | 见下一节,**不遮掉** |
| 雀斑 | — | **不遮**,气垫带过若隐若现即可 |
| 痘、痘印 | — | 点涂 |

- **只定额头、鼻子、法令纹两侧以外的脸外圈**,脸中间保留光泽
- **最后喷一点定妆喷雾**,粉感消失,看起来更像真皮肤

## 面中的红:当腮红用,压淡、修边,不遮掉再重画

红的位置在苹果肌偏内,正好是这张脸放腮红的位置——把视线往中间收,不把脸撑宽。所以不用绿色校色全遮再重新上腮红:那样底妆变厚,水光变粉感,雀斑一起被盖掉,起皮处还卡粉,步骤也多两步。

1. **整块薄压一层**:偏黄调粉底在红区按压,红淡掉三分之一左右、还透得出来。太浓就在最红的中心再按一次,不换更厚的产品
2. **修上边,和黑眼圈断开**:红一路连到眼下,会和眼下的紫红接成一片,整个眼下都暗。眼下遮瑕往下多带一点,在红区上缘晕开,留出一条干净的过渡带——最影响精神状态的一步
3. **修下边,收成横向椭圆**:红往下拖到鼻翼以下、靠近法令纹,会拉长中庭、显没精神。下缘多按一点粉底,让红大致停在鼻翼高度
4. **压完再决定要不要腮红**:内侧还剩自然的粉就不加;压得太淡,在苹果肌内侧靠上点一点很淡的杏色或玫瑰豆沙,外侧不超过眼尾垂直线。**不要斜向上拉向太阳穴**——斜向上会把中庭拉长

站远看一眼:读起来是"气色好",不是"一大块红",就对了。

## 法令纹:别往纹里填,处理纹上端那块阴影

法令纹看起来深,主要是纹路顶端靠鼻翼那一小块三角凹陷的阴影,和纹外侧鼓起来的那块肉投下的影子。

- **不往纹路里填遮瑕或粉底**:填进去会卡在纹里,反而画出一条线
- **只在纹路上端、靠鼻翼的小三角点一点**比肤色亮半号的遮瑕,往外拍开
- **纹路本身底妆最薄,不扫散粉**;化完笑一下,用指腹把卡进纹里的粉按掉
- **纹外侧鼓起来的那块不放光泽**:亮了它更鼓,纹显得更深
- 面中红区的下缘停在鼻翼高度,也是为了不把颜色拖进法令纹

## 修容与高光:缩短长度,补出轮廓

偏灰的浅棕修容,不要偏橘,一把刷子扫完:

- **发际线**:横向一窄条阴影,缩额头
- **下巴尖**:底部横扫阴影,缩下巴。**下巴不打高光**——会更长
- **脸侧**:从耳前往下颌角扫,到眼尾垂直线就停,下颌线带一下补轮廓
- **鼻子**:山根低,用眼影里的浅棕在两侧内眼角到山根之间扫一小段,顺便拉近眼距;**不拉长鼻影、鼻梁不画长高光**(都会拉长中庭),最多在山根点一个小亮点;鼻翼两侧一点点阴影收鼻头。量一定要少,最怕画成"两条线"
- **颧骨外侧不打亮**:会更宽

## 眉毛:眉毛是戴眼镜时最重要的一笔

眉毛青黑,和暖棕的头发、偏黄白的皮肤对比很强,眉毛单独压着一块深色,是显凶、显重的来源。

- **颜色取发根和发尾之间**:灰棕色眉笔补空缺,配**自然棕或摩卡**的染眉膏。发根本身不算特别黑,不需要很浅的染眉膏,也不要偏橘(会和青黑的眼睛打架)
- **梳法**:眉头向上梳虚,眉中向上再向后,螺旋刷带一下
- **形状平直**,眉尾水平、略拉长,不上挑——横向缩短脸;中庭偏长,眉毛往上抬会更长
- **眉眼间距近**:眉下缘不补、不修高,只清杂毛;要补只补上缘
- **眼距略宽**:眉头可以略往内起,梳虚
- 眉毛露在镜框上面,优先级比眼妆高

## 眼睛:一个哑光大地色 + 睫毛

杏仁眼、眼尾微微上扬本身是好看的眼型,不需要往下压,只需要让它完整、有神。

### 眼影代替眼线

1. **眼皮打底**:即上面压橘红那一步
2. **铺色**:浅奶咖/灰棕哑光色,睁着眼找位置,铺到双眼皮那条线附近、睁眼能露出来的高度;别往上铺到眉毛,眉眼间距近,铺满会显肿显压。不用大颗粒闪,窄双眼皮会卡
3. **按压睫毛根**:小平刷蘸深棕色,一点点按进上睫毛根的空隙——看不出线条的眼线,戴着也不难受
4. **眼尾平收**:顺着眼型往外带 1–2 毫米,接近水平
5. **下眼尾**:外侧三分之一用**浅棕**轻扫一下,让眼睛完整;不用深棕、不往下晕,压多了反而没精神
6. **内眼角**:点一点同色往前带一点,缩眼距;不用很亮的内眼角提亮(会显眼距更宽)

### 睫毛:重点是"翘",不是"浓"

睫毛容易被眼皮压着下垂,挡住眼睛、像半睁。夹翘是性价比最高的一步。

- **分段夹**:根部停几秒,再中段、尖端各一下,弧度自然
- **防水打底或防水睫毛膏**定型,细软的睫毛才撑得住
- **整排均匀刷**,薄刷、根根分明,一两层,不要苍蝇腿
- **颜色深棕**,比纯黑柔和
- **下睫毛**:外侧轻刷一点
- 不需要浓密假睫毛或夸张嫁接;想更浓就选自然款小簇,只贴眼尾

### 卧蚕:默认不画

眼下有紫红色黑眼圈和泪沟,卧蚕下面那条阴影线会把暗沉画得更明显,带闪的还显浮肿。真要画只用哑光浅肤色提亮,阴影线极浅。

## 唇:全脸唯一可以有颜色的地方

- **最先涂润唇**:化妆一开始就涂,上唇色前擦掉浮在表面的——唇干瘪靠这一步
- **唇线笔(接近唇色的裸玫瑰)改形**:上唇唇峰和唇中往外画出 0.5–1 毫米,上唇变饱满、人中显短;嘴角两端略往外延,嘴不显小;然后晕开。配合嘴角下方的提亮,表情会柔和
- **质地**:薄涂再叠一层透明唇釉或唇油,要光泽;水光唇让薄唇显饱满,哑光会把干纹放大
- **颜色**:跟着面中的粉红走——**玫瑰豆沙、玫瑰棕、奶茶棕粉**;更都市选红棕偏玫瑰、浆果豆沙,和黑色外套搭。**先别用偏橘的**,会和面中的粉红打架
- **边缘微晕**:唇线笔定好形,唇釉填中间,边缘用指腹晕一下,比清晰满唇低调

## 颜色总原则

中性肤色、底色偏黄白、面中天生粉红,五官偏青黑,头发暖棕 → 选**中间调、略带灰、偏玫瑰**的颜色:玫瑰棕、摩卡、豆沙、灰棕。

- **避开纯橘**:放大眼周的橘红和额头、嘴角的黄,也和面中的粉红打架
- **避开冷的荧光粉**:和暖黄的发色打架
- 自测色调:自然光下看手腕血管,偏绿暖、偏蓝紫冷、两种都有是中性

## 戴框架眼镜时

- **近视镜片让眼睛看起来小一点**,度数不高影响轻,但隔着镜片眼妆会被减弱——**夹睫毛和按压睫毛根值得做,眼皮上的浅色眼影可以省**
- **鼻托压的位置底妆会掉**:那里只拍一点点,最后用散粉按一下
- **眼下遮瑕隔着镜片更显眼**(镜片放大质感):量更少,宁可薄
- 眉毛露在镜框上方,是戴眼镜时脸上最显眼的线条,优先画好
- 细银框椭圆眼镜本身就在都市松弛那一路上

## 两个版本

**5 分钟上班版**:
1. 眼下遮瑕(桃色校色 + 肤色遮瑕)+ 偏黄调气垫按压面中红区
2. 染眉膏(眉毛稀的地方先用眉笔补)
3. 夹睫毛 + 按压睫毛根 + 睫毛膏
4. 润唇 + 唇釉

**完整版**:在上面基础上加分区遮瑕(眼周、嘴角、额头、法令纹上端)、红区修边、修容(发际线、下巴、脸侧)、唇线笔;腮红只在红压得太淡时补。

## 最少要买的东西

偏黄调光泽气垫、偏黄肤色遮瑕、桃色校色、灰棕修容、一盘有浅棕和深棕的哑光眼影、灰棕眉笔、自然棕染眉膏、深棕防水睫毛膏、裸玫瑰唇线笔、玫瑰豆沙唇釉;杏色膏状腮红可选。

**一盘眼影管四处**:眼皮、睫毛根、下眼尾、山根两侧的鼻影。每类留一样,用空一样再补一样。

## 发色和发型

发色是不用漂的暖棕(栗棕、焦糖棕、暖茶棕一带),柔和、和雀斑呼应。发根长出来的偏黑那段不算特别黑,眉毛用灰棕就能同时接上发根和发尾。**避免**太冷的灰色、亚麻色(显皮肤黄)和漂得很浅的颜色。

**发型**:发根烫 + 八字刘海 + 层次剪 + 发尾微卷。脸侧层次和八字刘海对脸宽、额头高的修饰,效果比化妆更明显。不追求完全平整,但也不是什么都不管。

## 不靠化妆的部分

- **睡眠**:眼下暗沉最大的变量,作息改善比任何遮瑕都有效
- **皮肤屏障**:面中的红如果会刺痛、发烫或一直跟着起皮,在护肤上处理比靠化妆遮有效
- **表情**:放松额头、带一点笑意
- **体态**:头不往前探,下巴微收,下颌线会更清楚
