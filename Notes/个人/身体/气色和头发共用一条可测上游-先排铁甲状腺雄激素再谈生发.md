# 气色和头发共用一条可测上游——先排能测的三项,再谈能做的

## 一、在这个组合上,它们不是两件事

"气色差"和"头发少而细"在一般人身上可能是两条线。但在**二十多岁 + 多囊 + 重度出油长痘 + 长期熬夜 + 手脚常年冰凉(夏天也凉) + 晨起迷糊**这个组合上,两者的上游高度重合,而且**重合的那一段是能抽血测出来的**。

这决定了顺序:**先排能测的,再谈能做的**。在化验单出来之前,所有生发和养气色的动作都是在猜。

## 二、要排的四项

| 查什么 | 为什么它同时管两头 |
| --- | --- |
| **血清铁蛋白**(不是只看血红蛋白) | 铁蛋白低于 30 ng/mL 就可能出现弥漫性掉发 + 面色发白发黄 + 怕冷,而**血红蛋白可以完全正常**。只查血常规会漏掉 |
| **甲状腺 TSH + FT4** | 甲减的典型样子就是皮肤干、蜡黄、头发变细变软脱落、怕冷、晨起醒不透 |
| **雄激素**(总睾酮/游离睾酮/SHBG/DHEA-S) | 多囊的高雄是**一手推出油和痘、一手推女性型脱发**的同一个开关,见 [[Concepts/雄激素]] |
| 25-羟基维生素 D | 与脱发的关联证据较弱,但顺带一起抽,成本为零 |

[事实层,全部为模型回忆,**未联网核查**]

⚠️ **抽血前 2–3 天停掉含生物素(biotin)的美容补剂。** 大剂量生物素会干扰甲状腺功能和肌钙蛋白的化验结果,查出来的数是假的——而"吃生物素养头发"的人正好最可能同时去查甲功。

这四项与 [[Notes/个人/身体/皮肤怎么管-目标先归口,用品先减后加,医美排在痘控住之后|皮肤那篇]]第二节的清单是同一张单子,不用多抽一次血。

## 三、"压力性气血不足"这个解释不能当结论用

"头发少而细、手脚发凉,是思虑过度把气血耗在脑子上、末梢和头发被断供"——这是流传很广的一种解释。它不能当结论用,理由不是中西之争:

1. **它不可证伪。** 无论化验结果是什么它都成立,所以它不提供任何下一步动作。
2. **它把能查出原因的信号解释掉了。** 手脚冰凉 + 头发变细 + 晨起迷糊,这三条在外部知识里第一个要排的是甲减和缺铁,第二个是高雄。
3. **它导出的处方做不到。** 结论落到"少想点、别熬夜"上,而那恰恰是当事人现在最做不到的那件事。

压力确实能造成休止期脱发,但在诊断顺序上那是**排除法之后**的结论,不是第一个结论。

## 四、掉发先分型,两种解法互不通用

| | 休止期脱发 | 女性型(雄激素性)脱发 |
| --- | --- | --- |
| 怎么掉 | 整头均匀、量大 | 发缝变宽、头顶透,量可能不大 |
| **发丝粗细** | **不变** | **越长越细越软**(毛囊微小化) |
| 诱因 | 2–3 个月前的节食、大病、应激、停药 | 雄激素驱动,无明确时点 |
| 会不会自己好 | 诱因去掉能长回来 | **不会**,拖越久越不可逆 |

**"细"这个字是分型的关键**——自述"特别少特别细"时,要认真对待第二种。

**自己怎么初判**:比**头顶发缝**和**枕后发缝**的宽度。枕后的毛囊不受雄激素影响,是天然对照区;两处差别明显就偏向雄激素性。每月同光线同角度拍一张,比主观感觉可靠得多。

## 五、有证据的,和该省下的钱

**值得做的**(均需皮科/妇科面诊开,不自行用药):

- **外用米诺地尔**(女性 2% 或 5%)——非处方里唯一有硬证据的生发外用。起效 4–6 个月,停用回退。开始 2–8 周有一波**脱落期**掉得更多,那是进入新生长周期的正常现象,**多数人在这里放弃**
- **螺内酯**——抗雄,对多囊女性**同时管痘、油、头发**,是这个组合里的一石三鸟
- **含抗雄孕激素的短效口服避孕药**——另一条路径

**明确不值得的**:

- **生物素/防脱保健品**:不缺就无效,还污染化验结果(见第二节)
- **何首乌**:有明确的肝损伤病例报告和监管提示,风险收益比不划算
- **防脱洗发水**:在头皮停留几十秒,能做的主要是控制脂溢性皮炎(含酮康唑的洗剂有一点证据),不是生发
- **紧扎、接发、频繁热工具**:牵引性脱发**可以是永久的**,发际线退了长不回来

## 六、"乌黑"是光泽问题,不是色素问题

**头发的黑色素含量由遗传和年龄决定,没有可靠的外用或口服手段能让头发变黑。**

所以二十多岁没有白发时,"想要乌黑"实际上不是颜色需求,是**光泽需求**——头发看起来黑不黑,取决于毛鳞片平不平整、能不能镜面反射。毛躁的黑发看起来灰扑扑,平整的同一根头发看起来就是乌黑。

这和"油皮要的不是控干,是控平"(Notes/个人/身体/皮肤怎么管-目标先归口,用品先减后加,医美排在痘控住之后)是同一个逻辑:**以为在追一个成分指标,其实在追一个表面平整度指标。**

归口因此改变:少染烫、降吹风温度、洗后吹干别自然干(湿发毛鳞片张开最脆弱)、硬水地区考虑过滤——归护发,不归"补黑色素"。

## 七、顺序

1. **把那四项血抽了**,抽血前停生物素类补剂
2. **每天防晒 + 睡眠**——这是气色里唯一不依赖化验结果的部分,现在就能开始
3. **拿到结果再谈用药**,尤其螺内酯那条

能做的是从现在推到自己的上限,不是换一张脸。
