# 近视手术的三个决策层——度数决定该不该做、散光与干眼指向相反的术式

挑术式之前先过这三层。跳过第一层直接比设备,是最常见的顺序错误。

## 一、"能不能做"和"该不该做"往相反方向走

度数低的时候,这两个答案是分开的,而且方向相反:

| | 度数低时 |
|---|---|
| **能不能做** | ✅ 变好——切削量少、角膜安全余量大、术后精准度高、回退率低 |
| **该不该做** | ⚠️ 变差——见下 |

手术的收益是**摆脱矫正工具**。而低度近视(-3.00D 以内)裸眼在多数日常场景本来就能应付:看路、看人脸、室内活动。

**但风险是固定的**——干眼、夜间眩光星芒、不可逆——它不随度数下降。

**收益随度数下降,风险不变,所以风险收益比随度数下降而变差。**[推论] 真正从手术里获益最大的是 -6.00D 以上、没眼镜寸步难行的人。

这条和直觉相反:多数人的想法是"我度数低,做起来更划算";准确的说法是"我度数低,所以更不必做"。

⚠️ **但这不是禁忌,是一道必须明着过的关。** 低度数照样可以是正当的手术理由——**只要理由是"矫正工具本身让我难受"**(隐形干涩不耐受、框架影响运动和户外),而不是"不戴眼镜看起来更好"。后一个理由撑不起一台不可逆手术,因为它有一个零风险的替代方案。

**还有一条常被误解的:手术矫正的是屈光度,不改变眼轴已经拉长这个事实。** 视网膜脱离、青光眼、近视性视网膜病变的风险不因手术下降,术后照样要定期查眼底。做完 ≠ 近视治好了。

## 二、散光矫正和干眼防护指向相反的术式

散光占比高、又有干眼倾向的人,这两个特征会把术式选择拉向两个方向。这是真实冲突,不是信息过载。

### 散光这一边 → 偏向半飞秒

人躺下时眼球会发生旋转(cyclotorsion),**散光轴位越接近水平,旋转带来的误差影响越大。**

- **SMILE(全飞秒)缺少静态旋转补偿和自动中心定位**,这被视为它的主要短板;散光矫正不足的主因之一就是术中缺乏旋转控制。[事实,已联网核查]
- 一项随机对照研究中,**残余散光 <0.25D 的比例:LASIK 组 81.8%,SMILE 组 50%**。[事实,已联网核查]
- **但结论并不一致**——也有研究发现在高度散光(≥2.00D)上三种术式效果相当,在轻中度近视的某些队列里 SMILE 反而更好。[事实,已联网核查]
- **手动旋转补偿 + 列线图(nomogram)修正,可以把 SMILE 的散光精准度提到与其他术式相当。**[事实,已联网核查]

最后这条是关键:**短板可以被术者的操作规范补上。所以问题不是"SMILE 行不行",是"这家做不做这个修正"。**

### 干眼这一边 → 偏向全飞秒或全激光

机制:LASIK 要切一个角膜瓣,这会切断大量角膜神经 → 泪液反射减少 → 干眼。

- **SMILE 无瓣、切口小,对角膜神经的破坏小得多;SMILE 与 ICL 术后干燥远少于 FS-LASIK。**[事实,已联网核查]
- **FS-LASIK 视力恢复最快,但角膜神经恢复最慢。**[事实,已联网核查]
- TransPRK 同样不切瓣。

### 所以不要自己选,把冲突原样交给医生

进诊室问这两句:

> **我散光占比高、轴位接近水平,同时戴隐形容易干。**
> **做 SMILE 的话,你们做不做旋转补偿和 nomogram 修正?实际的散光残余数据是多少?**
> **做半飞秒的话,以我的干眼倾向,术后风险怎么评估?**

**能正面回答这两个问题的医生,和只会说"我们设备最先进"的,当场就分得出来。** 这两句本身就是一次筛选。

**TransPRK 值得一并问**:不切瓣(干眼优势)、有旋转补偿,代价是恢复慢、术后几天疼、视力完全稳定要 1–3 个月。对不赶时间的人是被低估的选项。

## 三、周期由两个前置条件决定,不由排期决定

顺利的话约 **3–5 周**:

| 阶段 | 时长 | 要点 |
|---|---|---|
| 停戴隐形 | 1–2 周 | 不能省——隐形改变角膜形态,天数不够则地形图与验光数据失真,方案会算错 |
| 术前检查 | 半天 | 要散瞳,之后 4–6 小时视力模糊畏光,当天别安排开车 |
| 出结果定方案 | 当天或次日 | |
| 等排期 | 3 天–2 周 | 术前 3 天通常点抗生素眼药水 |
| 手术 | 在院 2–3 小时 | 激光部分每眼仅 20–30 秒 |
| 恢复 | 半飞秒次日即可用;全飞秒 1–3 天;TransPRK 3–7 天上皮愈合期会疼会糊 | |

**真正决定周期长短的是这两件,它们都在排期之前:**

**① 干眼。** 检查发现干眼必须先治好,通常 2 周到 2 个月。这不是拖延——带着干眼手术,术后干眼会明显更重,而干眼本来就是这类手术最常见的术后问题。

**② 度数稳定性的证明。** 要求年变化 ≤50 度、稳定 1–2 年。生理上 25 岁通常已稳定,但医院要的是**证据**:
- 有旧验光记录 → 对比后当场过
- 没有旧记录 → 部分医院接受自述,**也有医院要求隔 3–6 个月再验一次做对比**

**没有旧记录这一条,能把周期从一个月拉到半年。** 所以决定之后第一件事不是约手术,是**这两件并行**:翻旧验光记录(免费),做眼表检查(BUT + 裂隙灯 + 泪液分泌,几十到一两百块)。

旧记录的可能出处:手机相册、眼镜店小票、体检报告、学校视力档案。

## 术式之间还有一条可逆性差异

**ICL 是植入晶体,可以取出;激光类切削角膜,不可逆。**[[Concepts/可逆性|可逆性]]这一项在决策权重里不低,尤其当"该不该做"那一层本来就没有压倒性答案的时候——**方案的可撤销性,可以替代一部分确定性。**

ICL 另有散光版(TICL),也适合角膜偏薄、度数偏高的人,代价是价格显著更高、属于内眼手术。

## 术后限制(排时间窗要按这个算)

- **1 周内**:不能化妆、不能游泳、不揉眼、尽量不进水
- **1 个月内**:避免游泳、剧烈运动、多尘环境;户外强光戴墨镜
- 常爬山、常在户外的人,至少空出术后两周

干燥环境(北方暖气房)会加重术后干眼,湿润气候更友好。

## 费用量级(截至 2026 年 9 月,地区与医院差异很大,未核实)

| 术式 | 大致区间 |
|---|---|
| 全激光 TransPRK | ¥8,000–15,000 |
| 半飞秒 FS-LASIK | ¥10,000–18,000 |
| 全飞秒 SMILE | ¥15,000–25,000 |
| 散光 ICL(TICL) | ¥30,000–40,000 |
