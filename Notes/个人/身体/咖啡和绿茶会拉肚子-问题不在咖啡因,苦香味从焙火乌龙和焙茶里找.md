# 咖啡和绿茶会拉肚子:问题不在咖啡因,苦香味从焙火乌龙和焙茶里找

**主张:触发腹泻的是咖啡本身和儿茶素多的茶,不是咖啡因、温度或奶;想留住早餐里"苦的、香的"那一口,要么改咖啡的喝法,要么从自己不拉的乌龙里找焙火香。**

## 自己试出来的规律

"我发现我特别容易拉肚子,我喝一点咖啡或者是茶或者是冰的东西,我就会拉肚子。"

细分下来:"纯茶也会拉,热的也会拉,乌龙茶好像不拉,冰的还好,得看是什么咖啡,基本都拉。""绿茶会拉,低因也会拉。"

| | 会不会拉 | 能排除什么 |
|---|---|---|
| 咖啡 | 基本都会,**低因的也会** | 不是咖啡因 |
| 绿茶(热的也会) | 会 | 不是温度,纯茶没奶也不是乳糖 |
| 乌龙茶 | 基本不会 | — |
| 冰饮 | 还好 | 不是冷刺激 |

## 为什么是这两样

- **咖啡**:除了咖啡因,咖啡里还有别的成分会直接刺激结肠收缩,低因咖啡对一部分人照样起作用([事实],未联网核查)。所以对咖啡的反应和种类、咖啡因多少关系不大
- **绿茶 vs 乌龙**:最大的差别是儿茶素这类茶多酚。绿茶不发酵,儿茶素保留最多;乌龙半发酵,一部分已经转化,对肠胃温和;空腹时儿茶素的刺激更明显([推论])
- 几样不相干的东西都能触发,说明肠道本身偏敏感;最常见的解释是腹泻型肠易激,但要医生排除别的原因才能这么说

## 还想喝咖啡:改喝法

1. **找出不拉的那几种**——"得看是什么咖啡"说明有例外,看它们是深烘还是浅烘、美式还是拿铁、大杯还是小杯,只喝那种
2. **先吃面包再喝**,不空腹
3. **量减半**:小杯,或只一份浓缩
4. **可以试深烘**:烘得越深,一部分酸类(绿原酸)分解得越多,有人喝着舒服;对结肠的刺激有没有用不确定([推论])
5. **安排在出门前、在家喝**:喝完只是想去厕所、正常排便,不算坏事;要处理的是水样腹泻,或路上、公司里憋得难受

## 想要苦香又不拉:替代

| 替代 | 味道 | 适配 |
|---|---|---|
| **岩茶(大红袍、肉桂)、炭焙铁观音** | 焙火香、微苦、回甘,乌龙里最接近咖啡"烤过的香" | ⭐ 首选,乌龙已经试过不拉 |
| **焙茶 / 焙茶拿铁** | 烤米、烤坚果香,微苦 | 烘焙后儿茶素和咖啡因都大幅降低,大概率不拉;拿铁用无乳糖奶 |
| **大麦茶** | 烘焙谷物香,无咖啡因 | 不是茶叶,没有儿茶素;香味淡 |
| 博士茶 | 甜、蜜香,无咖啡因 | 没有儿茶素;不苦,配面包差一点 |
| 红茶 | — | 全发酵,儿茶素多已转化,不确定,少量试 |
| **避开** | 绿茶、**玄米茶(里面有绿茶)**、抹茶;菊苣"咖啡"(味道最像咖啡,但菊粉对敏感肠道容易胀气腹泻) | |

焙茶、博士茶怎么挑见 Notes/个人/日常/低咖啡因又好喝的茶怎么选-焙茶博士茶与看链接的判据.md——那篇是按低咖啡因选的,推荐的几样恰好也是儿茶素少或没有的,结论照用,理由换了。

## 益生菌:可以试,别指望它解决这件事

腹泻是被饮品直接触发的,避开咖啡和绿茶比吃益生菌直接得多。

- **效果看菌株,不看"益生菌"三个字**:对肠道敏感的人,有些菌株能稍微减轻腹胀、腹痛、排便不规律,幅度不大;指南态度不一,有的倾向不常规推荐,有的认为可以试 12 周、没用就停。证据较硬的是吃抗生素期间预防腹泻(布拉氏酵母菌、鼠李糖乳杆菌 LGG)。对健康人一般安全,常见的是头几天胀气([事实],未联网核查)
- **真要试**:
  1. 选包装写明具体菌株编号的(如鼠李糖乳杆菌 LGG、植物乳杆菌 299v、布拉氏酵母菌),不选只写"多种益生菌"的
  2. 看配料,**避开加了菊粉、低聚果糖的**——这类"益生元"对敏感肠道反而容易胀气腹泻
  3. 一次只吃一种,连续 4–8 周,同时记排便;没明显改善就停
  4. 和达英-35 不冲突([推论])
- **比益生菌更值得先做的**:避开触发饮品;拉肚子期间优先燕麦、香蕉、熟土豆、苹果泥这类可溶性纤维,让大便成形,粗粮、菜梗这类不溶性纤维先少一点;平时吃的植物种类越多越好([[Concepts/膳食纤维|膳食纤维]]);熬夜和紧张都会让肠道更敏感

## 兜底

- **吃着达英-35 时**:吃药后三四个小时内严重腹泻或呕吐,药可能没吸收,按漏服处理,具体以说明书和医生为准
- **去消化科的信号**:便血或黑便、体重无故下降、半夜被拉醒、发烧或剧痛、避开这些饮品还常拉或持续超过一个月;不到这一步,影响上班出门也值得看一次
- 多囊早餐那篇写的是"不空腹、不喝咖啡":不空腹对肠胃同样成立;不喝咖啡是为多囊写的,理由没展开,跟饭喝小杯的折中要不要做,看妇科时问一句
