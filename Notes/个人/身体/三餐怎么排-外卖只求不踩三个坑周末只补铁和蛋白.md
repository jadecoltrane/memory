# 三餐怎么排——外卖只求不踩三个坑,周末只补铁和蛋白

早餐那一顿已经有完整方案,这篇只管其余两顿、外卖场景和周末采购。

**两句话的设计目标**:外卖不追求营养最优,只追求**不踩三个结构性的坑**;周末做菜不追求花样,只追求**补上外卖永远给不了的那两样**。

## 一、外卖的三个结构性缺陷

不是"点错了菜",是这个品类本身的问题:

- **坑一 · 裸碳水。** 默认结构是"一大碗主食 + 一点浇头"——盖浇饭、拌面、黄焖鸡。一份下来碳水 80g+、蛋白不到 15g。这是餐后犯困和血糖过山车的直接来源。
- **坑二 · 轻食沙拉的反向坑。** 为了健康点一份沙拉,蛋白 12g、热量 300 大卡,下午四点饿,晚上加倍补回来。**吃太少比吃错更危险**,理由在第六节。
- **坑三 · 铁几乎为零。** 外卖体系里基本没有红肉、动物血、贝类的有效摄入。而铁是气色和头发共同的上游(见 [[Notes/个人/身体/气色和头发共用一条可测上游-先排铁甲状腺雄激素再谈生发|气色和头发那一篇]])。

**这三个坑决定了三条点单规则和一张采购清单。**

## 二、三条点单硬规则

1. **主食减半,蛋白加一份。** 平台基本都能备注"米饭半份",多数店能加一份肉或蛋。加的那一份是全部意义所在:一个卤蛋 + 一份豆干,就能把 15g 拉到 28g
2. **先菜、后肉蛋、最后主食。** 外卖反而比在家好执行:把那半碗饭放到最后。机制靠 [[Concepts/膳食纤维]] 的物理阻挡
3. **汤汁不泡饭。** 外卖的油和盐九成在汁里

## 三、工作日午餐,按三个档点

**A 档 · 最省心**:石锅拌饭类,或日式定食(烤鱼定食、生姜烧)。**结构天生就对**——饭 + 菜 + 蛋 + 肉,备注少饭,加一份牛肉或蛋。

**B 档 · 想吃辣(这一档最重要)**:麻辣烫/冒菜按食材单点,是**外卖里唯一能把铁吃够的品类**。

> 鸭血一份 + 虾滑 + 豆皮 + 鹌鹑蛋 + 毛肚 + 绿叶菜两样 + **半份**宽粉
> 汤底选清汤或番茄,麻酱换成蒜泥 + 少量辣油

**鸭血是这条的核心**:100g 鸭血含铁约 30mg,而且是吸收率远高于植物铁的血红素铁。一周午餐吃上两三次,铁这一项基本不用再操心。[事实,未联网核查]

⚠️ 要克制的是主食那栏:宽粉、方便面、年糕、油条别同时放三样,那就变回坑一。

**C 档 · 加班/没胃口**:便利店关东煮(别只拿萝卜和魔芋,拿蛋、厚豆腐、鸡肉丸)+ 一盒即食鸡胸或毛豆 + 无糖豆浆。

## 四、晚餐:要控的是油,不是辣

推荐品类:烤鱼/清蒸鱼、云南菜(汽锅鸡、菌子)、潮汕牛肉锅、湘菜川菜挑**小炒和蒸菜**(小炒黄牛肉 + 一个绿叶菜 + 半碗饭,而不是辣椒炒肉配两碗饭)。

**辣椒素本身不是痘的主因**——痤疮关联证据比较明确的是高血糖负荷饮食和乳制品。川湘外卖的问题出在油量和配着下饭的那两碗白米饭。[推论,未联网核查]

这个区分是执行层面的关键:**一个禁辣的方案对爱吃辣的人活不过三天**,而"点小炒不点干锅、饭减半、汁不泡饭"是同样的效果、能坚持的形式。

**夜宵条款(必须有,否则方案第三天就破)**:熬到一两点那个饿是真的,要给它一个不算破功的出口——无糖豆浆 + 一个卤蛋;或希腊酸奶一小盒 + 几颗坚果;或紫菜虾皮汤一碗。要避开的只有奶茶、饼干面包、泡面:**液体糖 + 精制碳水在深夜**,正好是第二天早上满脸油的那条线。

## 五、周末盒马:目标不是做一桌菜,是备料

采购按"外卖缺什么"来,不按菜谱来:

| 类别 | 买什么 |
| --- | --- |
| **铁**(外卖最缺) | 鸭血、蛏子/花蛤、牛腱或牛肉粒、猪肝一小盒 |
| **蛋白** | 冷冻虾仁、三文鱼或巴沙鱼块、**鸡腿肉**(比鸡胸好做且不柴)、老豆腐、五香豆干、鸡蛋 |
| **omega-3** | 三文鱼,或油浸沙丁鱼罐头 |
| **类胡萝卜素** | 胡萝卜、南瓜、番茄、菠菜、西兰花——**买免洗系列** |
| **碳水** | 红薯、糙米、整粒燕麦(别买即食片) |

⚠️ **猪肝每周最多一次。** 猪肝维生素 A 密度极高,长期过量本身就是脱发的诱因之一——正好撞在头发这个目标上。

**周末两小时做的是备菜,不是做菜**,四个动作:煮一锅蛋冷藏;蒸一锅红薯冷藏;炖一锅"万能肉"(牛腱或鸡腿 + 洋葱 + 番茄)分装冷冻,工作日微波三分钟就是一顿的浇头;绿叶菜洗好沥干装盒。

前两样正好接上早餐那篇模板 A 的"周末一次性煮蛋 + 蒸红薯,早上只做加热"。**买免洗菜省下的洗菜那一步,决定这套能不能活过两周。**

## 六、十五分钟内的简单菜

1. **番茄虾仁滑蛋**——番茄下锅出汁 → 冷冻虾仁 → 打三个蛋推散 → 盐。配半碗糙米饭,蛋白 30g+
2. **鸭血豆腐汤**(补铁那一顿)——鸭血 + 嫩豆腐 + 一把菠菜 + 白胡椒,7 分钟
3. **辣炒花蛤 / 蛏子炒蛋**——爱吃辣、补铁、10 分钟,三件事一起办
4. **蒜蓉蒸鱼块或蒸虾**——现成的,蒸锅 8 分钟,零技术
5. **一锅端**——冷冻的万能肉 + 免洗菠菜 + 一个红薯,微波

## 七、两个完整的一日三餐

**工作日(外卖为主)**

| | 内容 | 蛋白 |
| --- | --- | --- |
| 早 | 早餐那篇模板 A:2 个水煮蛋 + 无糖豆浆 250ml + 蒸红薯 + 免洗菠菜微波 | ~21g(加一盒希腊酸奶到 28g) |
| 午 | 麻辣烫清汤底:鸭血 + 虾滑 + 豆皮 + 鹌鹑蛋 + 青菜两样 + 半份宽粉 | ~30g,铁这一天就够了 |
| 晚 | 小炒黄牛肉 + 清炒时蔬 + 半碗饭,汁不泡饭 | ~30g |
| 夜(熬到 1 点才加) | 无糖豆浆 + 一个卤蛋 | ~14g |

**周末(做饭)**

| | 内容 |
| --- | --- |
| 早 | 早餐那篇模板 B:咸口燕麦粥(整粒燕麦 + 蛋 + 冷冻虾仁 + 青菜) |
| 午 | 番茄虾仁滑蛋 + 半碗糙米饭 + 一根黄瓜 |
| 下午 | 希腊酸奶 + 坚果罐子(配方在早餐那篇) |
| 晚 | 蒜蓉蒸鱼块 + 蒜蓉西兰花 + 蒸南瓜 |

配的喝的沿用早餐那篇:茎焙茶,热的、低咖啡因。**吃饭和喝茶咖啡错开半小时**——茶里的单宁压制铁吸收,在补铁的前提下这条比平时更值钱。

## 八、加工果蔬汁怎么判:一个可复用的算法

冷压果蔬汁这类产品的宣传点通常落在"加了 X 油""HPP 冷杀菌""果蔬含量 98%"上。判它有没有用只要两步。

![盒马亚麻籽油胡萝卜复合果蔬汁的营养成分表与配料表](assets/2026-09-22-盒马亚麻籽油胡萝卜复合果蔬汁营养成分表.png)

**第一步:把每 100ml 乘成整瓶。** 上图那款 300ml 的实际是:146 kcal、蛋白 2.1g(约等于零)、脂肪 3.0g、**碳水 27.3g**。

**第二步:拿碳水浓度跟含糖饮料比。** 9.1g/100ml——**可乐约 10.6g/100ml,橙汁约 10g/100ml**。它没有额外加糖,糖全来自胡萝卜和苹果,但榨汁已经把细胞壁打碎、纤维滤掉了,进血的速度和加糖的没有本质区别。**"液体糖"看的是形式,不看来源。**

**关于"加了亚麻籽油所以补 omega-3"**:该问的不是能不能吸收(脂肪吸收不是瓶颈),是**转化**。亚麻籽油给的是 ALA,人体要用的是 EPA/DHA,转化率只有 5–10%、DHA 更低。整瓶 3g 亚麻籽油 ≈ 1.6g ALA ≈ 80–130mg EPA 当量,而一罐油浸沙丁鱼约 1.4g EPA+DHA——**要喝十几瓶才抵得上一罐沙丁鱼**,一罐十几块,十几瓶一百四。[事实,未联网核查]

**它唯一真正成立的地方**:一根半胡萝卜的 β-胡萝卜素确实可观,而且**特意配 3g 油这个设计是对的**,类胡萝卜素是脂溶性的,没有脂肪同吃吸收率会低很多。产品逻辑没毛病——只是同一件事,一根半胡萝卜用油炒或烤,成本几毛钱,渣还在。

⚠️ **还有一个反向的坑**:β-胡萝卜素长期过量会得**胡萝卜素血症**,手掌、脚掌、鼻唇沟发黄,常被引用的阈值是每天 20–30mg 持续数周,而一瓶就落在这个区间。"提高类胡萝卜素摄入会让肤色被评为更健康好看"和"吃到发黄"是**同一条剂量曲线的两端**,追"透亮白皙"的人尤其要知道有这一头。[事实,未联网核查]

**裁决**:偶尔喝没问题,别当健康投资。真要喝就别空腹、别当水喝,放进正餐里跟着蛋白和纤维一起下去。

## 九、四条边界

1. **不要在这套上面制造热量缺口。** 低能量可用性本身是应激源(早餐那篇 HPA 那一节),而且**快速减重和长期低热量是休止期脱发最常见的诱因之一**。"增肌线条 + 降体脂"要靠吃够 + 练,不是靠少吃——这是气色、头发、身材三个目标唯一会互相打架的地方
2. **亚型没确认前,碳水放中档**(早餐那篇的结论,不改)
3. **有一条库内内容容易被误用**:"熬夜后早餐或午餐高蛋白低碳水"是**熬夜后当天的急性处理**,目的是压当天的困意,不是日常吃法。见 Notes/个人/身体/熬夜后如何快速恢复(该篇自己也标了这条边界)
4. **乳清蛋白粉 + 在长痘** → 换成分离乳清或大豆/豌豆蛋白试 8 周。这是成本几乎为零的一次"排除—再引入"
