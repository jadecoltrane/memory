# 皮肤怎么管

**皮肤问题分三层管:上游在内分泌和睡眠,日常护肤只负责托底和一种活性,医美按问题挑、排在痘控住之后。** 每一层管不了另一层的事。归口错了,钱和力气会砸在一项根本推不动的指标上;而且每一步单看都在"护肤",看不出问题在哪。

## 一、先归口:每个问题由什么决定

「通透、贴骨、有光泽、没瑕疵」听起来是一个目标,其实是四件事:

| 词 | 真正由什么决定 | 谁能动它 |
| --- | --- | --- |
| **贴骨** | 面部脂肪量 + 骨相 + 皮肤紧致度 | 体脂、年龄、紧致类医美。**护肤品贡献接近零** |
| **光泽** | 镜面反射:表面够平 + 一层完整的水脂膜 | 质地类项目 + 屏障养护 |
| **通透** | 角质层含水 + 肤色均匀 | 保湿、遮挡、色素类项目 |
| **无瑕** | 痘的控制 + 痕的消退 | 内分泌 + 外用 + 光电 |

具体到 2026 年 10 月的皮肤状态,十几个问题归成四组,有先后:

| 组 | 包括 | 什么时候处理 |
| --- | --- | --- |
| 痘 | 爆痘、额头闭口、黑头、鼻子略油 | 现在,排第一 |
| 屏障 | 略起皮、脸颊泛红 | 和痘一起,用保湿托住活性 |
| 痕和质地 | 棕色痘印、毛孔粗大、唇周泛黄 | 痘控住 2~3 个月后 |
| 结构和纹路 | 法令纹、泪沟、抬头纹、眼周泛红泛黄、黑眼圈 | 面诊再定,不影响前三组 |

脂肪粒单独处理:找皮肤科挑,不自己挤。

几条归口上容易错的:

- **"贴骨"有反向代价**:面部脂肪掉太多会显凹、显老;有多囊时体脂降太低对激素和月经也不友好,目标区间不能照搬健身网红的数字。
- **肤色不均要再拆三种**——红(炎症后红斑)、褐(炎症后色沉)、暗黄——解法互不通用,当一件事处理必然有两种白做。
- **油皮要的是控平,不是控干。** 平整表面上的油光被读成光泽,带着毛孔和痘印的油光才被读成油。控油控到哑光既拿不到光泽,还会顺手把屏障做坏。
- **有一块根本不在皮肤上**:光、镜头、后期、底妆、上镜前打的水光针。拿修过的图当基线,差的那一截有相当部分不在脸上。[推论]
- **毛孔大小、皮脂腺活跃度、真皮厚度、肤色深浅有基因上限**:能做的是推到自己的上限,不是换一张脸。

## 二、上游:内分泌和睡眠

### 出油和痘的上游在内分泌

皮脂腺是 [[Concepts/雄激素]] 驱动的器官。洗完脸一两小时满脸油 + 反复长痘 + 多囊,这个组合指向高雄激素或胰岛素驱动的痤疮,外用成分作用在表层,压不动腺体本身的产量。开中药控油自觉无效,也符合这个方向。

**该查的清单**:性激素六项(含总睾酮、游离睾酮、SHBG,月经第 2–5 天抽)、空腹血糖 + 空腹胰岛素(算 HOMA-IR)、DHEA-S(区分雄激素来自卵巢还是肾上腺)、25-羟基维生素 D、hs-CRP。判读见 Notes/个人/身体/瘦多囊未必是胰岛素抵抗也可能是肾上腺压力型或炎症型,机制见 [[Concepts/胰岛素抵抗]]。唇周泛黄也值得在面诊时提一句——胰岛素抵抗有时表现为局部皮肤发暗。[推论]

**查完之后才谈得上的那一步**(用不用、用哪个由皮科/妇科面诊决定):

- **短效口服避孕药**:2023 年国际 PCOS 指南把它作为高雄表现的一线;含醋酸环丙孕酮的那类因血栓风险不作一线。美国皮肤科学会(AAD)2024 年痤疮指南给有条件推荐。[联网检索,二手摘要]
- **螺内酯**:临床常用,AAD 有条件推荐;但 2017 年系统综述把它治成年女性痤疮的证据评为低到极低质量。常用 ≠ 证据强。[联网检索]
- **二甲双胍**:确认有胰岛素抵抗时才谈。[模型回忆]
- **口服异维 A 酸**:唯一真能让皮脂腺缩小的药,AAD 对重度、留疤或常规治疗无效的痤疮强推荐;有严格避孕和监测要求。[联网检索]

**这一层不解决,外用和光电的效果会一直被按回去。**

### 睡眠

一项 60 名 30~49 岁女性的研究(Oyetakin-White 等,*Clinical and Experimental Dermatology* 2015,雅诗兰黛委托):睡得差的人经皮水分流失更高,胶带剥离后 72 小时屏障恢复约差 30%,紫外线晒后红斑消退更慢。这是横断面关联、样本小;另一项人体研究发现单纯短期缺觉对屏障没有显著影响。**"熬夜伤皮肤"方向成立,但不能说成"熬夜让痘印消不掉"**——实验测的是晒伤红斑,不是痘印,两者都是炎症后红斑消退,只是推论上相近。[联网检索]

睡眠为什么停不下来、怎么排优先级,在 Notes/个人/身体/熬夜不是自制力问题-白天自主性、皮肤屏障与破局优先级。

## 三、日常护肤:先减后加,一次只动一个变量

**用的东西越多,越分不清是谁在添乱。** 泛红、起皮、爆痘、眼周泛红同时发生时,先减到三四样看清基线,稳住后一次只加一样。

**但正在爆痘时不能把活性全停**——痘可能更重。该做的是只留一种、降频、用保湿托底。

### 第 0 阶段:减到三样,重启一种活性(约 2~4 周)

**早上**:洗面奶(或清水)→ B5 保湿凝胶 2~3 滴 → 面霜 → 平时伞帽遮挡,长时间户外用防晒

**晚上**:用过防晒或化妆先卸妆 → 洗面奶 → 等脸完全干 → 壬二酸 → B5 保湿凝胶 → 面霜

**壬二酸怎么重启**:

- 第 1~2 周每周 2~3 晚,第 3~4 周不红不起皮就改隔晚,之后按说明书再加
- 黄豆大小薄涂,长痘和有痘印的地方都涂到,避开眼周、嘴角、鼻翼
- 脸湿时涂更刺;刺痛就先涂面霜再涂壬二酸
- 轻微刺痒几分钟就退一般正常;灼痛、肿、越用越红就停几天再降频
- 痘约 1~2 个月见变化,棕色痘印约 3 个月

**不用水会干**:保湿凝胶和保湿水做的是同一件事(补一层吸水的保湿成分),二选一,够了就不叠。洗完脸马上紧绷是洗面奶的问题,换洗面奶比加水管用。

**眼周测试**:停用含香精的眼霜两周,看眼周泛红有没有退——这是排查眼周泛红最便宜的一步。

活性已经基本停用了,脸颊仍然起皮泛红,说明这两样**至少不全是活性叠出来的**,原因留给面诊判断。

### 第 1 阶段:一样一样加回来

**开始条件**:连续 2 周不刺痛、不发红、不起皮,痘没有变多。**规则**:一次只加一样,观察 1~2 周再加下一样。

| 顺序 | 加什么 | 用法 |
| --- | --- | --- |
| 1 | 烟酰胺 + 锌 | 早上,涂鼻子和额头,管油和暗沉 |
| 2 | 果酸 | 每周 1~2 晚,不和壬二酸同一晚 |
| 3 | 熊果苷 | 早上,想加强淡棕色痘印时 |
| 可选 | 原来的眼霜 | 眼周测试证明不是它才加回来 |

医生开了阿达帕林就按医生排,果酸多半用不上。

**早 C 晚 A 不是必需。** 对长痘的皮肤,最该用的「A」是阿达帕林这类外用维 A——AAD 强推荐,同时管痘、闭口、质地和痘印,起效 3~6 个月,从每周 2 次建立耐受;它和壬二酸怎么排由医生定,不自己先加视黄醇面霜。「C」(高浓度维 C)偏酸,泛红期易刺痛,稳定后可以和烟酰胺锌二选一放在早上。

### 第 2 阶段:长期精简版

| 步骤 | 用什么 |
| --- | --- |
| 洁面 | 洗完不紧绷就继续用原来的,否则换氨基酸洁面 |
| 保湿 | B5 保湿凝胶 + 面霜(闭口多换清爽的,两颊干换滋润的,只涂干处) |
| 防晒 | 有色、含氧化铁的矿物防晒,兼当粉底 |
| 晚上活性 | 只一种:壬二酸,或医生开的阿达帕林 |
| 早上活性(可选) | 只一种:烟酰胺锌或维 C |

**每加一样之前问一句:它在解决我现在哪个具体问题?答不出就不加。**

**遮挡是痕的那一半**:褐色痘印不挡光等于白修,光老化也归它管。紫外线之外,可见光也会加重色沉,能挡可见光的是有色防晒里的氧化铁;伞帽之下仍有散射和反射,玻璃挡不住 UVA。不爱涂防晒的话,有色矿物防晒可以直接替代粉底,不算多一步。

**同样的钱,效果排序是:医美 > 有效成分 > 贵妇面霜**(见 Notes/个人/日常/什么值得买贵的-功能、耐用保值、纯信号三类差距)。保湿和修护类的核心原料,大牌和平价款差别远小于价差;大牌常为"体验感"加香精和精油,对泛红皮肤反而减分。

| 兰蔻小黑瓶眼霜 | 停,用完不回购 | 第三方成分库显示含香精、香叶醇、香茅醇,还含果酸类成分 |
| 娇韵诗双萃 | 停,用完不回购 | 第三方成分库显示含香精,定位偏抗老 |
| 香奈儿山茶花微精华 | 停,用完不回购 | 多份成分表含香精;B5 凝胶到手前可作过渡 |
| The Ordinary 果酸、烟酰胺锌 | 停,第 1 阶段按顺序加回 | — |
| 熊果苷 | 停,用完不回购 | 只有机制和色斑小研究,没找到针对痘印的试验;欧盟评估脸部 2% 以内安全 |
| 积雪苷霜 | 先放着,面诊时问 | 是药品(主药积雪草总苷,促伤口愈合),研究多是疤痕和联合治疗的小样本,不当日常面霜 |

**要买的**:修丽可 B5 保湿凝胶(透明质酸 + B5,无油)。修丽可的另两款水都不合适:植萃精华喷雾含香精和芳樟醇等致敏香料,平衡爽肤水含羟基酸、零售商标注不适合敏感泛红皮肤。

**无香精无酒精的大牌保湿水**,备选(按海外标价粗算,科颜氏每天最省、SK-II 最贵):倩碧水磁场保湿精华水(不含油,对闭口友好)、科颜氏高保湿水(含少量植物油,闭口多选 Oil-Free 版)、SK-II 神仙水(成分短,有发酵味,含尼泊金酯)。雅诗兰黛原生液标"合成香精少于 1%",不算无香精。

**暂时不买**:YSL 夜皇后(其实是含 3.4% 甘醇酸的双层刷酸精华,和手上的果酸重复,稳定后可替换果酸)、海蓝之谜(第三方成分库显示含香精、多种致敏香料和变性酒精,无无香版)、赫莲娜黑绷带(没找到官方完整成分表)。想试就等稳定后买小样。

## 五、医美:按问题排,排在痘控住之后

**一条硬原则:痘还在活动期不做强项目。** 先把痘压住再修痕,否则是花钱买更深的印。AAD 2024 年指南也明说,化学焕肤、激光光电、微针治痘本身的证据不足以写进推荐。

| 问题 | 对得上的项目 | 现实预期 |
| --- | --- | --- |
| 红痘印、血管型泛红 | 脉冲染料激光 / 强脉冲光 | 证据最多的是这两种,但研究都偏小;很多红痘印会自己消,激光是加速。通常几次、间隔约一月 |
| 褐痘印 | 外用 + 遮挡为主,急了再上皮秒 | 强项目在活动痘期反而加重色沉 |
| 毛孔、质地 | 非剥脱点阵、射频微针 | 需 3–5 次,间隔一个月起 |
| 上镜光泽 | 水光针 | 立竿见影,试验多只随访 2~3 个月,"维持半年以上"多是厂商说法;当消耗品 |
| 动态纹(抬头纹) | 肉毒素 | 维持 3–6 个月;25 岁做不做都行 |
| 法令纹、泪沟 | 填充 | 多是结构性的,只有填充能动,不急 |
| 紧致 | 射频 / 超声 | "贴骨"唯一能买到的部分;系统综述里医生评估改善率高,患者自评只有 42%~53%,缺长期随访;**20 多岁做预防没有试验支持** |
| 出油 | 微滴肉毒 | 证据弱,治本仍在第二节 |

**排期**:

| 时间 | 做什么 |
| --- | --- |
| 现在 | 皮肤科面诊 + 妇科内分泌检查;粉刺清理、挑脂肪粒 |
| 痘控住约 3 个月后(秋冬恢复更好管) | 泛红若是血管型做光电;褐痘印先外用,不够再皮秒 |
| 再往后 | 毛孔:点阵或射频微针 |
| 重要场合前 | 水光针 |
| 这一年不做 | 热玛吉、超声炮;肉毒控油 |

**黑眼圈和眼周先分型再花钱**:色素型(外用 + 色素类激光)、血管型(改善睡眠和循环,美白项目无效)、结构型(泪沟 + 皮肤薄,靠填充)。一项 65 人研究里 78% 是混合型,所以单一项目的套餐很容易买错。眼周泛红泛黄和黑眼圈不是一回事,面诊时一起让医生分。[联网检索]

**每次做医美**:术前问医生壬二酸、果酸提前停几天;术后 1~2 周只用洗面奶、B5 凝胶、面霜,遮挡做严,不用任何活性;恢复后回到当时所在的阶段。预算医美优先,护肤品只买真正在用的那几样。

## 六、时间尺度

外用维 A 看变化 3–6 个月;壬二酸对痘 1~2 个月、对棕痘印约 3 个月;痘印半年起;痘坑只能靠点阵慢慢磨。**最省力的起点只有两个动作:把那套检查做了,把遮挡做到位。** 这两件落地之后,后面所有项目的回报率才是真的。

## 待验

- 产品成分来自第三方成分库和零售页,配方会改版,以瓶身为准
- 阶段时长、壬二酸加量节奏、医美时间点都是推论,没有面诊背书
- 起皮和泛红的原因没查清,等面诊判断
- 眼周泛红是不是眼霜引起,看停用两周的结果
- 二甲双胍、微滴肉毒、点阵次数等未联网核查的条目,以面诊为准
