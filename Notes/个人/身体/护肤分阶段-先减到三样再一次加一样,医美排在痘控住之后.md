# 护肤分阶段

**皮肤同时出好几种问题时,先把用品减到三四样,稳住之后一次只加一样;医美排在痘控住之后,按问题挑一个做。** 用的东西越多,越分不清是谁在添乱——泛红、起皮、爆痘、眼周泛红同时发生时,十几样产品叠着用,任何一样都可能是原因,也可能都不是。减到最少才看得见基线,一次只动一个变量才知道每一样的作用。

十四个皮肤问题其实是四件事,有先后:

| 组 | 包括 | 什么时候处理 |
| --- | --- | --- |
| 痘 | 爆痘、额头闭口、黑头、鼻子略油 | 现在,排第一 |
| 屏障 | 略起皮、脸颊泛红 | 和痘一起,用保湿托住活性 |
| 痕和质地 | 棕色痘印、毛孔粗大、唇周泛黄 | 痘控住 2~3 个月后 |
| 结构和纹路 | 法令纹、泪沟、抬头纹、眼周泛红泛黄、黑眼圈 | 面诊再定,不影响前三组 |

脂肪粒单独处理:找皮肤科挑,不自己挤。

## 一、第 0 阶段:减到三样,重启一种活性(约 2~4 周)

**早上**:洗面奶(或清水)→ B5 保湿凝胶 2~3 滴 → 面霜 → 平时伞帽遮挡,长时间户外用防晒

**晚上**:用过防晒或化妆先卸妆 → 洗面奶 → 等脸完全干 → 壬二酸 → B5 保湿凝胶 → 面霜

**壬二酸怎么重启**:

- 第 1~2 周每周 2~3 晚,第 3~4 周不红不起皮就改隔晚,之后按说明书再加
- 黄豆大小薄涂,长痘和有痘印的地方都涂到,避开眼周、嘴角、鼻翼
- 脸湿时涂更刺;刺痛就先涂面霜再涂壬二酸
- 轻微刺痒几分钟就退一般正常;灼痛、肿、越用越红就停几天再降频
- 痘约 1~2 个月见变化,棕色痘印约 3 个月

**全停活性不对**:正在爆痘时把活性全停,痘可能更重。该做的是只留一种、降频、用保湿托底。

**不用水会干**:保湿凝胶和保湿水做的是同一件事(补一层吸水的保湿成分),二选一,够了就不叠。洗完脸马上紧绷是洗面奶的问题,换洗面奶比加水管用。

**眼周测试**:停用含香精的眼霜两周,看眼周泛红有没有退——这是排查眼周泛红最便宜的一步。

## 二、第 1 阶段:一样一样加回来

**开始条件**:连续 2 周不刺痛、不发红、不起皮,痘没有变多。**规则**:一次只加一样,观察 1~2 周再加下一样。

| 顺序 | 加什么 | 用法 |
| --- | --- | --- |
| 1 | 烟酰胺 + 锌 | 早上,涂鼻子和额头,管油和暗沉 |
| 2 | 果酸 | 每周 1~2 晚,不和壬二酸同一晚 |
| 3 | 熊果苷 | 早上,想加强淡棕色痘印时 |
| 可选 | 原来的眼霜 | 眼周测试证明不是它才加回来 |

医生开了阿达帕林就按医生排,果酸多半用不上。早 C 晚 A 不是必需:对长痘的皮肤,最该用的「A」是阿达帕林这类药,由医生决定和壬二酸怎么排;「C」(高浓度维 C)偏酸,泛红期易刺痛,稳定后可以和烟酰胺锌二选一放在早上。

## 三、第 2 阶段:长期精简版

| 步骤 | 用什么 |
| --- | --- |
| 洁面 | 洗完不紧绷就继续用原来的,否则换氨基酸洁面 |
| 保湿 | B5 保湿凝胶 + 面霜(闭口多换清爽的,两颊干换滋润的,只涂干处) |
| 防晒 | 有色、含氧化铁的矿物防晒,兼当粉底 |
| 晚上活性 | 只一种:壬二酸,或医生开的阿达帕林 |
| 早上活性(可选) | 只一种:烟酰胺锌或维 C |

**每加一样之前问一句:它在解决我现在哪个具体问题?答不出就不加。**

## 四、手上产品的去留(截至 2026 年 10 月)

| 产品 | 去留 | 依据 |
| --- | --- | --- |
| 喜辽妥 20% 壬二酸 | 留,主力 | 痘、红痘印、棕痘印都有证据 |
| 修丽可 AGE 面霜(新版) | 留 | 新版是否含香精没查清,看盒子成分表找 Parfum |
| 黑 BA 洗面奶、植村秀卸妆油 | 留 | 未查;洗完紧绷换洁面,额头闭口不好就把卸妆油换成卸妆膏或卸妆乳试试 |
| 资生堂蓝胖子(新艳阳夏水动力) | 留,户外用 | 物化结合、清爽哑光;含不含酒精说法不一,"不闷痘"只有商家宣传 |
| 兰蔻小黑瓶眼霜 | 停,用完不回购 | 第三方成分库显示含香精、香叶醇、香茅醇,还含果酸类成分 |
| 娇韵诗双萃 | 停,用完不回购 | 第三方成分库显示含香精,定位偏抗老 |
| 香奈儿山茶花微精华 | 停,用完不回购 | 多份成分表含香精;B5 凝胶到手前可作过渡 |
| The Ordinary 果酸、烟酰胺锌 | 停,第 1 阶段按顺序加回 | — |
| 熊果苷 | 停,用完不回购 | 只有机制和色斑小研究,没找到针对痘印的试验;欧盟评估脸部 2% 以内安全 |
| 积雪苷霜 | 先放着,面诊时问 | 是药品(主药积雪草总苷,促伤口愈合),研究多是疤痕和联合治疗的小样本,不当日常面霜 |

**要买的**:修丽可 B5 保湿凝胶(透明质酸 + B5,无油)。修丽可的另两款水都不合适:植萃精华喷雾含香精和芳樟醇等致敏香料,平衡爽肤水含羟基酸、零售商标注不适合敏感泛红皮肤。

**无香精无酒精的大牌保湿水**,备选(按海外标价粗算,科颜氏每天最省、SK-II 最贵):倩碧水磁场保湿精华水(不含油,对闭口友好)、科颜氏高保湿水(含少量植物油,闭口多选 Oil-Free 版)、SK-II 神仙水(成分短,有发酵味,含尼泊金酯)。雅诗兰黛原生液标"合成香精少于 1%",不算无香精。

**暂时不买**:YSL 夜皇后(其实是含 3.4% 甘醇酸的双层刷酸精华,和手上的果酸重复,稳定后可替换果酸)、海蓝之谜(第三方成分库显示含香精、多种致敏香料和变性酒精,无无香版)、赫莲娜黑绷带(没找到官方完整成分表)。想试就等稳定后买小样。

## 五、医美怎么排

| 时间 | 做什么 |
| --- | --- |
| 现在 | 皮肤科面诊 + 妇科内分泌检查;粉刺清理、挑脂肪粒 |
| 痘控住约 3 个月后(秋冬恢复更好管) | 泛红若是血管型:强脉冲光或脉冲染料激光,通常几次、间隔约一月 |
| 同上 | 棕色痘印:先壬二酸 + 遮挡,不够再上皮秒 |
| 再往后 | 毛孔:点阵或射频微针 |
| 重要场合前 | 水光针,当消耗品 |
| 面诊时问 | 抬头纹(肉毒素,做不做都行);法令纹和泪沟(结构性,只有填充能动,不急);眼周泛红泛黄和黑眼圈(先分型);唇周泛黄(有 PCOS 而胰岛素没查过,提一句) |
| 这一年不做 | 热玛吉、超声炮(25 岁做预防没有证据);肉毒控油(证据弱) |

**每次做医美**:术前问医生壬二酸、果酸提前停几天;术后 1~2 周只用洗面奶、B5 凝胶、面霜,遮挡做严,不用任何活性;恢复后回到当时所在的阶段。预算医美优先,护肤品只买真正在用的那几样。

## 六、查过的证据和它们有多硬

- **痤疮指南**:美国皮肤科学会 2024 年指南强推荐过氧化苯甲酰、外用维 A(阿达帕林等);壬二酸、水杨酸、口服避孕药、螺内酯是有条件推荐;**化学焕肤、激光光电、微针治痘证据不足,没写进推荐**。[指南二手摘要](https://dermatologytimes.com/view/aad-releases-updated-guidelines-for-the-management-of-acne-vulgaris)
- **[[Concepts/雄激素]]那一层**:螺内酯在临床上常用,但 2017 年系统综述把它治成年女性痤疮的证据评为低到极低质量。2023 年国际 PCOS 指南把短效口服避孕药作为高雄表现的一线;含醋酸环丙孕酮的那类因血栓风险不作一线。用不用、用哪个由医生定。
- **红痘印**:脉冲染料激光证据最多、强脉冲光次之,研究都偏小,很多红痘印会自己消。[系统综述](https://pubmed.ncbi.nlm.nih.gov/35076997/)
- **棕痘印**:先治痘;壬二酸有随机试验支持;含氧化铁的有色防晒能挡可见光,专家共识推荐用于色沉,但直接证据多来自黄褐斑。
- **壬二酸 + 果酸**:20% 壬二酸加果酸治痘,一项随机试验显示效果不比维 A 酸差、刺激更小。[PubMed](https://pubmed.ncbi.nlm.nih.gov/9737831/)
- **超声紧致**:系统综述显示医生评估改善率高,患者自评只有 42%~53%,缺长期随访;20 多岁做预防没有试验支持。[综述](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9861614/)
- **水光针**:试验多随访 2~3 个月,"维持半年以上"多是厂商说法。
- **黑眼圈**:一项 65 人研究里 78% 是混合型,单一项目套餐容易买错。
- **熬夜与皮肤**:常被引用的"睡得差屏障修复慢 30%"来自雅诗兰黛资助的研究,对象 30~49 岁,测的是晒伤和胶带剥离后的恢复,只找到新闻稿;另一项人体研究发现单纯短期缺觉对屏障没有显著影响。"熬夜伤皮肤"方向成立,"30%"和"所以痘印消得慢"说重了。

## 待验

- 产品成分来自第三方成分库和零售页,配方会改版,以瓶身为准
- 阶段时长、壬二酸加量节奏、医美时间点都是推论,没有面诊背书
- 起皮和泛红的原因没查清(活性已基本停用,不是叠出来的),等面诊判断
- 眼周泛红是不是眼霜引起,看停用两周的结果
