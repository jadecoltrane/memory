# 没验证的框架能不能自己用——当先验用可以,当真理用不行

## 一、原话

> **「那我这个框架没有验证也能自己给自己用吗」**

问的是那个四格拆法(幅度/阈值/恢复/解释),但**这个问题的真实范围比一个框架大得多**——见第三节。

## 二、能。因为验证和使用的门槛本来就不同

| | 科学主张 | 个人工具 |
| :--- | :--- | :--- |
| 主张的是 | "这个关系在人群中普遍成立" | "这个拆法帮我看清该动哪一格" |
| 推广到 | 你没见过的人 | 只有自己 |
| 错了谁承担 | 所有拿去用的人 | 自己 |
| 靠什么检验 | 群体统计 | **n=1 的直接反馈** |

**关键在最后一行:研究者要靠群体统计逼近因果,是因为他们进不了任何一个人的生活。个人可以直接测结果。**

不需要知道"恢复速度对痛苦的贡献在人群中是否显著",只需要知道:**我睡够、没反刍的那几天,是不是明显好过。**

**而且框架在个人使用时,功能不是"陈述真相",是"改变注意力分配"。** "敏感是一整块" vs "敏感有四格、三格可动"——后者不需要为真才有用,**它只需要指出一个没试过的动作,然后那个动作的结果会反过来告诉你它对不对。**

## 三、这不是一个框架的问题,是整个库的问题

`claim_audit.py` 实测,**截至 2026 年 9 月**(98 篇):

| 来源 | 篇数 | 占比 |
| :--- | ---: | ---: |
| **AI 转述** | 66 | **67%** |
| 未标来源 | 21 | 21% |
| 用户手写 | 4 | 4% |
| **外部一手** | 4 | **4%** |

引用状主张 89 条,只有 35 条明确写了未核实,**26 条落在 🧠 核心层**。

**所以"这一个框架能不能用"其实是"这整个库能不能用"。** 而 `CLAUDE.md` 反信息茧房第 2 条早就给了答案:

> **「记忆是先验不是真理:每条都是过去某一刻的判断,用之前先想它现在还成不成立,拿不准先验证。」**

`Meta/RESOLVER.md` 的分层判据是同一件事:**"这条如果三年后被证伪,损失的是一个事实还是我的一段想法?"** 核心层记的本来就是"我当时怎么想"——**它从一开始就没自称是真理。**

## 四、[[Concepts/先验|先验]]是什么意思

中文的"先验"翻译了两个不同的英文词,**这里用的是第二个**:

- **哲学的 a priori**:不依赖经验就能知道的知识(数学、逻辑),对立面是经验的(a posteriori)。这是这个词的原始出处,**和这里说的基本无关**。
- **贝叶斯的 prior**:**在看到新证据之前,你对一件事的初始判断。** 看到证据后更新,得到**后验**(posterior)。

> **先验 →(证据)→ 后验**

三条性质:

- **先验不是真理,是起点**,它就是准备被证据修改的
- **先验不可能为零**。人没法从"完全无知"开始判断,总得有个起点——**所以带着先验不是缺点,是必需品**
- **先验越强,推翻它需要的证据越多**。好的先验让人少走弯路,坏的先验让人把证据往里塞

**所以"当先验用"和"当真理用"的区别是:**

| | 当先验用 | 当真理用 |
| :--- | :--- | :--- |
| 一条画像条目 | 这次可能也是,**先看一眼** | 这次就是,不用看了 |
| 四格拆法 | 先假设恢复那格能动,**去试** | 我就是幅度高,没救了 |

`CLAUDE.md` 里「不许拿画像标签当解释」那条用的就是这个词:**画像条目是待检验的先验,不是可以直接代入的前提。**

**判据(和第六节是同一个动作):什么样的证据会让你改变它?** 答不出来 → **你在当真理用。**

### 好先验 / 坏先验:差别主要在强度,不在位置

一个先验同时带两个量:**位置**(一开始猜哪儿)和**强度**(有多确信)。

**"少走弯路"的机制:先验的真实功能是分配搜索顺序。** 对任何一件事,可能的解释有无数条,不可能一条条试——**先验决定先试哪几条**,所以好先验 = 一个好的搜索排序。

| | 先验 | 后果 |
| :--- | :--- | :--- |
| ✅ | "群里不说话,**可能**是技能问题也**可能**是气质问题" | 先试技能那条(便宜、两周出数据)→ 有结果 |
| ❌ | "我就是内向,没救" | **搜索空间塌成一条**,而且那条通向"不动" |

**"把证据往里塞"是强度问题,而且有精确解释。** 坏先验分两种,只有第二种可怕:

- **位置错但还能动** → 只是慢,证据最终会把人拉回来。不可怕。
- **强度过高(接近 1 或 0)** → 后验 ∝ 先验 × 似然,**先验为 0 时,无论证据多强后验永远是 0(0 乘任何数都是 0)**。这条叫 **Cromwell's rule**:除非逻辑上不可能,永远别把先验设成 0 或 1。[事实,未联网核查]

**心理层面为什么是"塞"而不是"被推翻"**:先验很强而证据相反时,改先验贵(要承认之前错了),改对证据的解释便宜——所以默认走第二条。形式是只看支持的、把反例解释成特例、给反面证据打折、举证责任不对称。

> **最狠的一步:一个足够强的先验会把反例也变成支持它的材料。**
> "我不讨人喜欢"够强时:别人对你好 → "他有目的";别人冷淡 → "你看吧"。**两个方向都成了支持,它已经不可证伪了。**

**所以好先验最重要的性质不是对,是可动:**

| | 位置对 | 位置错 |
| :--- | :--- | :--- |
| **可动** | 最好 | **几轮证据后会走到对的地方** |
| **锁死(强度=1)** | 今天对,明天世界变了就错,而且改不动 | 最坏 |

**右上角比左下角值钱**——前者会自我修正,后者只是暂时侥幸。**先验的质量主要在更新能力,不在当下准确度。**

**检测自己某个先验强度过高的三个问题**(第三个最灵):

1. 反例出现时,第一反应是"更新"还是"解释"?解释 → 过高
2. 能不能说出一个具体的、会让你改变它的观察?说不出 → 强度已经是 1
3. **正反两个方向的证据,是不是都被读成了支持?** 是 → 已经不可证伪

⚠️ **太弱是对称的毛病**:强度接近 0 = 每条新证据都能把人翻过来 = 被最后一个说话的人说服。**目标不是"没有先验",是中等强度 + 明确的更新规则。** 用户自述 **"我总是接受别人给我的框架"** 属于这一侧的样本,原样并列,不替她判定。

### 先验强度从哪来——六条成因,每条对应不同的动作

自述 **"我就是先验太弱诶 是什么导致了我这种倾向"**。⚠️ **这个问句本身就答了一半**:能被有意义地回答"什么导致了它"的东西,不在气质层(判据见 Notes/个人/动机与改变/天生的倾向是偏置不是剧本-遗传度的误读与倾向的三层拆法 第三节)。**先验强度是学来的,所以可以重新学。**

1. **局部知识稀薄——而且这时候先验弱是理性的。** 强度部分来自"我在这件事上见过多少";在没有积累的领域照收专家框架**是对的**。**判据:在有积累的领域也照收吗?** 只在某些领域弱 → 知识问题,不是人格问题。
2. **判断从来没被结果检验过——推测权重最大的一条。** 强度靠「判断过 → 对了/错了」累积。长期没做过**有结果反馈的判断**,就没有校准的原料。**不是不敢有判断,是缺少"判断→结果"这个循环。**
3. **坚持先验 = 可能要说"我不同意"。** 分歧的社交成本估得高时,照收是最省事的策略。**这是关系策略不是认知问题。判据:一个人在家想的时候有没有立场?**
4. **把"说得有条理"误当成"正确"。** 结构清晰的框架天然更容易被接受,和对错无关。对应现实技能清单第一位那条缺口(见 Notes/个人/动机与改变/从心理学爱好者到专业与现实-一份自我发展路线备忘)。
5. **发展史:如果"有自己的判断"曾被反复惩罚**,弱先验是学来的适应。⚠️ **没有数据,不做推断,列在这里待她自己判断。**
6. **可能不是先验弱,是先验没被表达出来。** 有判断但不说 ≠ 没判断;而不说 → 判断不被检验 → 判断真的变弱(用进废退)。

> **②和⑥合起来是一个闭环:不输出 → 判断不被检验 → 先验无法校准 → 更依赖别人的框架 → 更不敢输出。**
> **这个闭环只有一个入口:输出。**

### ⚠️ 待验假设:不是"先验弱",是两头不对称

自述只捡了"太弱"那一半,但同一场对话里还有 **"我就是一个很敏感很爱焦虑的人""这世界欠我太多了""我明明比他们优秀"**——**那些是很强的先验。** 所以更可能的图景是:

| 关于什么的先验 | 强度 |
| :--- | :--- |
| 世界、别人怎么运作 | **弱**——照收 |
| 我自己是谁 | **强**——锁死 |

**统一的解释:判断权都在外面。** 对世界的判断交给别人;对自己的判断,是别人过去给的评价被固化下来了。

⚠️ **这是假设不是结论。** 验法:拿上面那三个检测问题去跑"我不讨人喜欢""我卡在收尾"这类句子——**正反证据都被读成支持的那一条,就是锁死的。**

⚠️ **另记一条当场观察:拿到"先验强度"这个框架后三十秒内,它就被用成了一个标签("我就是先验太弱"),句式还是"我就是一个 X 的人"。** 这正是下一节风险②的实时演示。正面用法是把标签换成可测的问题:**在哪些领域弱?什么场合弱?一个人的时候还弱吗?** 上面六条各对应一个不同的答案和一个不同的动作。

## 五、三条真实风险

**① 自证陷阱——最大的一个。** 框架一旦被采纳,人只会注意符合它的证据。**四格拆法尤其危险,因为它总能事后解释任何一次经历**("这次是恢复慢""这次是解释错了")。

> **一个什么都能解释的框架,等于什么都没解释。**

**② 用来解释,不用来行动。** 框架最常见的失败不是错,是变成一套更精致的自我描述——能非常准确地说出"我这是幅度高恢复慢",然后什么都不做。

> **判据:这个框架这周让我做了什么我原本不会做的事?** 答不出来 → 它现在是装饰品。

**③ 别带出去当科学。** 自己用可以;说"研究表明性格分四格"是造假。声明见 [[天生的倾向是偏置不是剧本-遗传度的误读与倾向的三层拆法|天生的倾向是偏置不是剧本]] 第七节——**这一篇就是那条声明的配套动作。**

## 六、"个人层面验证过"长什么样

比论文低得多,但不是零。三样缺一不可:

1. **一个可证伪的预测。** 不是"我要变好",是"**如果恢复速度这格成立,连续一周睡够 7 小时后,同样的事让我难受的时长应该明显变短**"。
2. **记录,不靠回忆。** 回忆会被当下情绪重写——这一半有实证:[[展示不是暴露上限-把表演和输出分开,事后反刍在重写记忆|展示不是暴露上限]] 第三节的"事后反刍在重写记忆"(那篇的事后反刍、聚光灯效应两条**标了已联网核查**)。**当天记,别月底回想。**
3. **一个最低限度的对照。** 不需要 RCT,但至少"做了 X 的那几天"和"没做的那几天"能比。

### 最小版本:每天一行,两个数,记两周

- ① 今天最难受的那一次,**从峰值到平复用了多久**
- ② 昨晚睡了几小时

**这就够看出"恢复速度"那一格对不对。** 而且一次做成三件事:验证框架、练"证据评估能力"(那条排在 Notes/个人/动机与改变/从心理学爱好者到专业与现实-一份自我发展路线备忘 现实技能清单第一位)、**给专业评估提供一份医生十分钟内读得懂的数据**——比"我最近很焦虑"有用得多。

## 七、判据不是真假,是产出率——但这不是相对主义

所有自我理解框架都一样(精神分析、CBT、五行、MBTI、大五),在个人使用时的功能都是**给经验一个结构,让它可操作**。区别不在"哪个是真的",在**哪个能生成做得到的下一步**:

- MBTI 生成**标签**("我是 INFP")→ 不生成动作 → 差工具
- 四格生成"**这一格今天能动**" → 好工具

⚠️ **但这不是"怎么说都行":**

> **能生成动作的框架,会在动作的结果里被检验;只生成标签的框架,永远不会。**

所以"好不好用"最终仍然回到"真不真"——**只是路径是通过自己的数据,不是通过论文。** 而这条路今天就能开始,论文那条要两到四年。
