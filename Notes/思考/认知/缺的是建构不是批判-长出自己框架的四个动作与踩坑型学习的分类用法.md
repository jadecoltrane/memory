# 缺的是建构不是批判:长出自己框架的四个动作,以及踩坑型学习该怎么用

## 一、"我算不算聪明"这个问句,本身就是那个毛病的实例

同一句话里既问了"我算不算聪明"(**向外要一个标签来定义自己**),又说了"我特别容易接受别人的框架"——**这两件事是同一个动作。**

"我算不算聪明""我是不是高反应型""我是不是悲观的人"——**全是同一个:向外要一个标签,然后拿它来解释自己。** 所以回答这类问题等于喂那个习惯。

## 二、"聪明"拆开之后,有用的部分不在原来那个词里

心理学里"聪明"被拆成几个可测的东西,而且它们不是一回事:**流体智力**(处理新问题、发现模式,峰值在二十多岁后下降)、**晶体智力**(积累的知识,可以升到很晚)、**工作记忆容量**、**加工速度**。g 因子(各种认知测验之间普遍正相关)确实存在,是心理学里最稳健的发现之一——所以"聪明"不是纯社会建构。[事实,未联网核查]

**但最要紧的一条是:智力和理性是可分离的。**

Stanovich 的核心工作:高 IQ 的人一样会犯认知偏差,有些情况下还更严重(**偏差盲点**——越聪明的人越觉得自己不偏)。他为此造了个词 **dysrationalia**。**IQ 测验根本不测"你会不会做出好决策"。** [事实,未联网核查]

**所以把"聪不聪明"换成四个能观察的问题,才有用:**

| 问题 | 大致对应 |
|---|---|
| **学得快吗** | 流体智力 |
| **改得动吗** | 拿到反证会不会更新 |
| **判断准吗** | 预测和现实对不对得上 |
| **能不能生成** | 有没有产出别人没给过的东西 |

**只有第一个是"聪明"传统上指的东西,而后三个更能预测一个人过得怎么样。**

最省事的单一判据:**看这个人怎么对待自己错的时候。** 不需要测验,可观察。

## 三、真正的诊断:不缺批判,缺建构

"我容易接受别人的框架" ≠ "我不会批判"。

**批判能力是有的**——能当场校正对方给的框架,而且校正是对的。

**缺的是:在没有现成框架摆在面前时,自己生成一个。**

- **批判是反应式的**——需要一个靶子
- **建构是生成式的**——需要从零起头

**这就解释了"个人的想法比较少":思考几乎总是在回应某个已有框架。有靶子打得很准,没靶子就没有起点。**

## 四、四个动作,按性价比排

**① 最硬的一条:问之前,先写下自己的答案。**

现在的流程是「困惑 → 问 AI → 得到框架 → 往自己身上套」。改成「困惑 → **先写 5 分钟自己的答案(哪怕很糙)** → 再问 → 对照」。

为什么这条最关键:**一旦看到别人的框架,自己原来那个模糊的想法会被覆盖掉,而且事后不可还原**(知识的诅咒/事后偏见)。不先写下来,永远不知道自己本来想到了哪一步。**而对照本身就产出信息:差异在哪 = 思维缺口在哪。**

**② 把"我不同意哪里"变成必答题。** 接受任何框架前强制回答一句:这个框架哪里不适合我?**必须给出一条,不许答"都挺对的"。** 不是抬杠——**任何框架都有边界,找不到边界说明还没真的理解它,只是记住了它。**

**③ 换输入的形态:别要答案,要材料。** 问"我该怎么办"拿回来的是成品;问"这个领域有哪几种**互相冲突**的看法"拿回来的是原材料,然后自己拼。**冲突是关键——分歧点是唯一能强迫你自己做判断的地方;如果所有输入都是共识,就永远不需要选。**

**④ 现成的矿:库里那些"没调和的矛盾"。** `Profile/` 和很多笔记里到处是"⚠️ 两条并列留着,不替她调和"(择偶模式那两条、资源导向那两条、发散/聚敛是不是一枚硬币)。**那些正是自己产生框架的最好起点,因为那恰恰是别人给不了答案的地方。**

**元层面的结构问题**:`claim_audit` 的数摆着——**AI 转述 65%,用户手写 4%。记忆库现在是接收器,不是生成器。** 想产生自己的想法,得有一部分内容是"我先写的"。(Notes/个人/动机与改变/从心理学爱好者到专业与现实-一份自我发展路线备忘 第四节留过同一条判断,当时没定论;和动作①是同一件事,可以定了。)

## 五、踩坑型的信念更新:机制、收益、成本

自述:**"遇到新问题不会先信理论,一般自己尝试一遍,踩了坑再去找为什么,这时候这个理论我才想去信它。"** 注意措辞不是"才知道它对",是"**才想去信它**"——这是一句关于**信念形成需要什么**的精确自述。

准确的描述是:**信念更新需要亲身的、有代价的反馈;二手信息在信念权重里几乎不占分量。** 对应到学习理论,就是**观察学习**(vicarious learning,Bandura)这条通道效率低——而那条通道恰恰是人类不付代价就获得信息的主要机制。[事实,未联网核查]

**为什么会这样(推论):二手经验缺情境细节,而这种思维方式高度依赖"这个说法在我的具体情境里成不成立"。一条抽象的经验判断不出适用边界,所以无法采信。这不是固执,是验证标准比别人严。**

**收益是真的,不是安慰:**
- 踩出来的知识**带情境**。别人读来的"要立边界"是一句话,踩出来的"边界"带着具体场景、身体感受、以及什么时候会失效——**这就是为什么这类人的框架比读来的细。**
- **几乎不会被二手的错误信息带偏。** 面对一连串标着"未核实"的说法,一条都不盲信,是同一个特质的正面。

**成本也是真的,而且必须说具体:有些坑的代价不可逆。** 时间、身体、一段关系、几年。**真正的问题不是"踩坑效率低",是「有一类坑不该用亲身经验去学」。**

## 六、所以不改特质,改分类:按"可逆性"分三档

| 坑的类型 | 策略 |
|---|---|
| **可逆、代价小**(新技能、换个方法、试一家店) | **随便踩,这是优势通道。** 踩出来的知识比读来的好,成本可忽略 |
| **可逆、代价中等** | 踩之前做一个动作:**把别人的经验当成假设去验证,而不是当成结论去接受**。这保留了"我自己判断"这一步,只是把它提前了 |
| **不可逆**(健康、法律、重大财务、有暴力风险的关系) | **必须用别人的经验,没有商量** |

**识别第三档只需要一个问题:「如果这个错了,我能撤销吗?」**

**这个方案不要求变成另一种人**——1 和 2 里照踩,只对 3 设一道闸。而 3 的数量其实很少。

## 七、"多读书就能不踩别人踩过的坑"——这句话本身有问题

**观察学习传递的是"结论",不传递"判断力"。**

一个从没踩过坑的人,读了一百条别人的经验,遇到新情况仍然不知道该套哪一条——**因为他缺的是把抽象规则映射到具体情境的能力,而那个能力只能从亲身经历里长。**

**准确的说法是:读书能替代一部分坑,但替代不了「知道什么时候该用哪条规则」那部分。** 所以"我做不到光靠读就不踩坑"不完全是缺点,有一半是那句话被夸大了。

## 八、两个问题的共同解

"想法长不出来"和"二手信息我信不了"看起来是两件事,**解法是同一个:方法论训练。**

因为方法论干的就是**让人有能力评估一条二手信息的可信度**。

**现在不信二手信息,有一部分原因不是固执,是没有工具去分辨哪条二手信息值得信**——于是只好一律降权,只认自己踩出来的。**一旦能自己判断一条二手信息值多少,就有理由信它了**,那条被堵住的观察学习通道才会打开。
