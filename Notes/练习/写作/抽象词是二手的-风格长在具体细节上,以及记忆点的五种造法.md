# 抽象词是二手的——风格长在具体细节上,以及记忆点的五种造法

起点是一条已经写好、还没发出去的小红书评论,问的是"普通人看到能看懂吗 有没有自己的观点 有没有表达清楚 逻辑如何"。

![小红书评论原文](assets/2026-09-01-小红书评论原文-小众套娃.webp)

原文转录(全文无标点,只用空格断句):

> 虽然说这篇文章正是追求小众 看似看透一切返璞归真的套娃 但其中也不乏一些真理 如果只是为了寻求一个身份标签去做这些事那可以对号入座 也有人是真正热爱 或者说就是他的生活本身 另外一点是整体社会环境 物以稀为贵 当这些氛围 消费符号变的唾手可得时 它将受到批判 转而去寻求另一种更高级的说法

## 一、诊断:判断是自己的,词是借来的

这段有两层观点,后一层比前一层好:动机区分(为标签 vs 真热爱)是对原文的补充;**稀缺性机制**(少的时候被追捧,唾手可得就被贬低,于是人转去找更"高级"的说法)才是真的洞察——它顺带解释了开头那个"套娃"为什么会无限循环。但这个呼应没被点破,最亮的一处埋在倒数第二行。

三个具体问题:

1. 全篇没标点,只用空格断句,读者要自己重组一遍。
2. 第一句主谓混乱:"这篇文章正是追求小众……的套娃"——分不清是"文章在追求小众",还是"文章批判小众却自己也落进去了"。
3. "另外一点"把第三段降级成并列补充,但它其实是全文的解释核心,该递进不该并列。

**总的毛病不是没想法,是想法的排序和交付。** 所以练法要针对排序和交付,不是泛泛地"多写"。

## 二、落地:抽象判断的下一句,给一个具体的人、事或场景

### 先说机制:抽象词是指针,不是内容

追问过一次:**「你说抽象词是表达链的半成品我要如何理解?很多时候我觉得我用抽象词就能表达完整啊。」**

**"完整"那个感觉是真的,因为你的仓库里有货。** 抽象词指向一堆具体经验——

- 读者脑子里有那堆经验 → 解引用成功 → 表达确实完整
- 读者脑子里没有 → **指针指向空**。他读到了词,但什么都没接收到,**而且他不知道自己没接收到**,因为那个词他认识

> **所以"半成品"的准确意思是:它的完成度不在你这边,在读者那边。你以为交付了内容,实际交付的是一张提货单。**

**判据(换词测试):把那个抽象词换成另一个抽象词,句子还成不成立?**
"这体现了一种消费符号" → 换成"这体现了一种身份焦虑" → 也成立 → **两个都成立,说明这句没排除任何东西,也就没说任何东西。**

### 完整的形状是三段,不是两段

| 顺序 | 读者拿到什么 |
| :--- | :--- |
| **具体** | 接住了(有画面) |
| **抽象** | 哦,这是一类 |
| **另一个具体** | 这一类还包括这个 |

**抽象词单独出现是半成品,夹在两个具体之间就是成品。** 而且**顺序不能反**:先抽象后具体,读者听第一句时无处安放、只能干等;先具体后抽象,第二句是"原来如此"。

| 抽象 | 落地 |
| :--- | :--- |
| "物以稀为贵,当这些消费符号变得唾手可得时,它将受到批判" | "前几年精酿还是小圈子的东西,现在便利店都摆着,喝精酿就成了'装'" |
| "如果只是为了寻求一个身份标签去做这些事" | "就是那种买了黑胶唱机、但只在朋友来的时候放一张的人" |

三个抓手:

- **补一个具体名词。** 写到"这些氛围""消费符号"时停一下,问自己脑子里想的到底是什么——露营?citywalk?某家咖啡店?
- **补一个动作。** "追求身份标签"是判断,"发朋友圈时把 logo 露出来"是动作。人能想象动作,想象不了判断。
- **补一个时间对比。** 稀缺性这类话题天然适合"以前……现在……",已经在说变化,只是没把两头填上。

练法:找旧评论,每写一句抽象判断就强行在下面加一句"比如……",写完再把"比如"删掉。二三十次之后变本能。

⚠️ **不是每句抽象都要落地。** 一段里有一两个具体锚点就够,全是例子会变成流水账;挑最核心那句配一个例子,其余留着抽象。

**抽象词就是正解的四种场合**:对方已经有那堆经验(同行、内部沟通);在做分类、索引、标题;需要短;**已经给过具体了、现在收口**。

## 三、风格不在抽象那一侧

原话:**"我比较喜欢那种意识流啊或者王小波 带点幽默的 我还比较喜欢李如一他播客那种小装逼一点 文学性高的 我想要有自己的风格。"**

举的这几个参照,全都特别会落地。[事实,未联网核查]

- **王小波**写权力和荒诞,不用"权力结构""异化"这种词,写的是一只特立独行的猪、是在云南插队的具体遭遇、是引一句罗素再接一句自己的胡话。**幽默建立在具体上——抽象的东西没法好笑。** 意识流看着散,但每一跳都落在一个能看见的画面上,所以读者跟得住。
- **李如一**那种"装"的质感来自他知道的具体细节比你多——某个软件设计、某句翻译、某个版本号,不是来自句子抽象。

所以落地和风格不对立。**真正的风格差异发生在"选哪个具体细节"和"以什么节奏抛出来"。** 全用抽象词恰恰是最没有辨识度的写法:抽象词是公共的,谁写都一样;具体细节是私有的,只有你会那么举例。回到那句"当这些氛围、消费符号变得唾手可得时"——"氛围""消费符号"任何人都能写;换成一个自己观察到、别人没注意的东西,那句话就只能是你写的了。

还有一层:**问题不是"看不懂",是"不想再读一遍"。** 评论区不是书,没人会为你回头。现在的形式在筛掉一半读者,而且筛掉的不是笨的那一半,是没耐心的那一半。

⚠️ **散和乱是两回事。** 王小波的句子在语法上极其规整,野的是内容不是句子。先把标点加上、句子写清楚,再谈风格。

## 四、抽象词能不能当成风格

原话:**"我好像就是喜欢拽这些抽象词 能成为我的风格吗。"**

### 先拆一个等号:抽象能力 ≠ 抽象词汇量

后来提过一个反驳:**「我怀疑有的人可能不会用精准的词、抽象词来写,或者是压根不知道有这种可以描述抽象的词语。」**

**这个反驳指出了一个真实的区分,而那个区分把"抽象词是二手的"这句话救活了,没推翻它。**

| | 是什么 | 稀不稀缺 |
| :--- | :--- | :--- |
| **抽象能力** | 看出一个模式,把一堆不同的东西归成一类 | **真稀缺** |
| **抽象词** | 说得出"消费符号"这四个字 | **是检索,不是发现** |

**两种脱钩都常见:**

- **有能力没词**:没读过社会学的人也能说"他买东西不是为了用,是为了让别人看见他买得起"——**这是一次完整的抽象,只是没用那四个字**,而且比"消费符号"好看,因为它是新鲜的。
- **有词没能力**:从库存里调一个词扣上去。**那个词是别人造的、别人验证过的**,消费的是别人那次抽象。

> **准确版本:抽象词是别人抽象完的结果。用它,省掉的正是做那次抽象的功课。**
> **而"不会用抽象词"不等于"不会抽象"**——那个等号不成立。真正稀缺的是从具体到抽象那一跳,而那一跳的产物写下来时,可以一个抽象词都不带。

**还有一层动态**:抽象词的价值随流通量递减。一个词刚被造出来时承载真实信息,流通之后变成谁都能贴的标签,**而且贴上之后思考就停了**。所以"知不知道这个词"这个门槛会趋近于零,"能不能自己做那一跳"不会。

### 所以能不能当风格

能,但门槛比想象的高,而且高在两个条件之一:要么对这些概念的理解比读者深得多,能拆开、重组、指出别人没看到的关系;要么这些抽象是**自己拧出来的**,不是现成借来的。

**"消费符号""物以稀为贵""身份标签"不是抽象概念,是流通词。** 它们在小红书、播客、豆瓣里已经被用烂,用它们不显得深,显得像在复述一套通用话术。真正的抽象写作反而是:发现现有的词都不够用,于是自己造一个说法。

陷阱在于**抽象词省掉了思考中最难的那一步**。写"消费符号唾手可得",比写清楚"到底什么东西、对谁、在什么时候变得唾手可得"轻松太多。脑子里本来有具体画面,那个词让你不必把它掏出来。久了会钝——**不是表达能力钝,是观察能力钝,因为不再需要仔细看了。**

所以不是"别用抽象词",而是:**保留对抽象的偏好,但要求每个抽象词背后都有具体支撑,哪怕不写出来。** 写完随便指一个词,问"我说的到底是什么",答不上来就是借来的,删掉。

## 五、记忆点的五种造法

大脑记不住"正确",记得住**摩擦**。[[Concepts/记忆点]] 的造法就这么几种:

- **落差**——两个不该放在一起的词凑在一起。"沉默的大多数""一只特立独行的猪":猪和特立独行不搭,所以记住了。
- **压缩**——一个复杂判断压成一句短句。长度本身是记忆的敌人;短句像结论,而结论有权威感。
- **可复述**——别人能原样转给第三个人。**这一条最狠:真正的传播不是被听见,是被转述。** 需要听者自己重组才能转达的话,死在原地。
- **命名**——给一个大家有感觉但没词的东西起名字,命名者顺带拿到这件事的解释权。
- **具体的画面**——抽象判断记不住,一个能看见的场景记得住。

拿这五条照原文:"当这些氛围、消费符号变得唾手可得时"——没有落差、没有压缩、不可复述、词是借的。所以哪怕判断是对的也不会留下。压成 **"少的时候是品位,多起来就是姿态"**,这句才能被人转述。

**练一个动作就够:每写完一段,挑出核心判断,压成十五字以内、别人能原样转给第三个人的一句话。压不动,说明还没想透——压缩是检验思考的工具,不只是修辞。**

配一个位置检查:**写完问一句"我最想让人记住哪句",然后看它在第几行。** 原评论里最好的那句(稀缺性)在倒数第二行。习惯是把它提到前三分之一,或者放在最后当收尾,别夹在中间。

## 六、领导力:记忆点是话的属性,它是人在时间上的属性

单次表达再漂亮也造不出跟随。起作用的是四条:

- **先于别人下判断,并且承担后果。** 大部分人不敢在信息不全时表态,敢的人自动上位。前提是错了要认,不然只剩虚张声势。
- **一致性。** 说过的话半年后还成立,做的事和说的话对得上。**跟随本质上是一种预测**——别人跟你,是因为能预测你。
- **给别人位置。** 最常被忽略的一条:听众要觉得自己在这套叙述里有角色、有事可做。**只让人佩服的人拿不到跟随,只能拿到围观。**
- **承担而不是索取。** 把风险揽过来,把功劳分出去。这是行为不是话术,但它会反过来让每句话都更重。

两者的关系:**记忆点让你被听见,一致性让你被跟随。** 只有记忆点没有一致性是网红;只有一致性没有记忆点,是靠谱但没人转述你。目前的短板在记忆点这一侧,症结同上——判断是自己的,词是借的,借来的词没有摩擦,记不住也转述不了。

## 七、为什么有的人说话让人簇拥,有的人被说无聊

原话:**"为啥有的人说话很有诱导性 带有 pua 那种味道的 就是大家有意无意会簇拥他 听信他 有的人说话却被定义为无聊。"** 这是两个问题,答案不一样。

**让人簇拥的几条,全是中性技术**——好的老师和骗子都在用:

- **给确定性。** 大部分人在大部分事上是懵的,谁能给一个干脆的判断("就是因为 X"),谁就接管了别人的不确定。犹豫和"我觉得也许"在场面上永远吃亏,哪怕它更接近真相。
- **制造区分,然后把你放进"里面"。** "大部分人不懂,但你懂"——这个结构同时给了优越感和归属感。原评论里的"套娃"说的正是这件事:批判追求小众的人,本身就是一次区分。
- **命名、具体和身体感、节奏与停顿。** 前两条同第五节;停顿是说话时敢停,不慌不忙,给人"我不需要你的认可"的信号,而这个信号本身就会招来认可。

**被说无聊不是因为温和**,是因为:没有判断只有信息或复述;全是抽象和正确的话,不提供任何具体的新东西;没有立场,四平八稳到没有摩擦面;不冒任何风险,不可能被反驳,所以也不值得被记住。

**最后一条最要紧:有意思的话都带风险。** 它可能是错的、可能得罪人、可能显得偏激,愿意承担这个,话才有棱角。而"消费符号""物以稀为贵"这类流通词恰恰把棱角磨掉了——不是因为温和,是因为这些词太安全太公共,读起来像谁都能说。

所以要变得"有意思"不需要学 PUA 那套,往前一步就够:**给出更硬的判断,用更具体的说法,并且接受它可能被人反驳。** PUA 的分界线不在这些技术上,而在多出来的那层权力结构,判据见下篇第八节。

## 八、系统提升的三个阶段

**第一阶段:句子(1–2 个月)。** 目标是句子在语法上立得住,只做两件:

- **抄写**:每天手抄或打字 300 字,不许改。抄的时候盯他在哪断句、哪里用逗号而不是句号。**抄写比阅读有效,因为它逼你逐字过一遍句子结构。**
- **改旧文**:找写过的评论,只加标点、拆长句,不改内容,一周三条。

另外两个针对"排序和交付"的小练习,和抄写并行:

- **删连接词。** 把"另外一点""还有就是""其次"全删掉重读。句子之间还通顺,说明本来就是并列,没损失;读着断了,说明是因果或递进,那就用"所以""正因为如此"补回去,而不是用并列词糊过去。**原评论就是把递进伪装成了并列。**
- **同一段写两遍。** 第一遍随便写;第二遍限制在原字数的 70%,不许丢观点。压缩会逼你发现哪些是废话、哪些句子结构臃肿。

**第二阶段:段落和结构(2–4 个月)。** 仿写+对照:同一话题自己先写一版,再读原文,对比"他先说什么后说什么、哪句是核心判断、核心放在了哪"。同时开始定期输出——**频率比长度重要**,每周两条 300 字左右,固定发出去(哪怕发给自己),"会被看到"这个压力会自动抬高标准。

**第三阶段:素材和风格(持续)。** 开一个素材本,记三类:自己观察到的具体细节(听到的话、看到的场景)、好的比喻和句子(注明是谁写的)、自己的判断和结论。**风格来自素材库的独特性**——读一样的书、用一样的词,写出来一定像。

书单(写议论和评论,读理论书不如读随笔):王小波杂文(《我的精神家园》《沉默的大多数》)、阿城《闲话闲说》、木心《文学回忆录》,加一本工具书《文心》(夏丏尊、叶圣陶)。[事实,未联网核查]

**检验标准**:每写完一篇隔一天再读,如果自己都要回头读第二遍才明白某句在说什么,那句就得改。

## 九、谦逊、有力量、客观:分配到不同位置,不要每句话都想兼顾

每句话都试图三样兼顾,就是稀释的来源。分开放:

- **判断句要硬。** 核心那句写干净,不加"我觉得可能大概"。**力量来自这里。**
- **不确定单独说。** 判断说完之后,单独一句交代边界:"这个解释在消费品上比较成立,对技术类的东西我没想清楚。"**谦逊来自这里**,而且是精确的谦逊,比裹在每句话里的模糊限定词更让人信服。
- **露出推理过程。** 说明是怎么得出这个结论的——看到了什么、跳过了哪步。**客观来自这里**,别人能沿着路径走一遍,也能自己找出哪儿薄。

| 稀释型 | 改成 |
| :--- | :--- |
| "我觉得可能是因为稀缺性吧" | "我认为是稀缺性。" |
| "这个事情比较复杂,要看情况" | "在 A 情况下是 X,B 情况下不是,分界在于……" |
| "当然每个人看法不同" | (删掉,这句永远是废话) |
| "不一定对啊你们随便看看" | "我不确定的是……" |

第三行最值得警惕:它听起来谦虚,实际是在提前撤回刚说的话——既没给读者信息,又让判断打了折。

**检验方式**:写完把所有软化词(可能、大概、也许、我觉得、不一定、当然)全删掉重读。如果读起来太冲,需要的不是软化词,是**限定条件**——把"在什么范围内成立"写清楚,比加"可能"有用一百倍,而且不损失力量。
