# 小红书写作定位:半知识型,从冲突开始而不是从观点开始

起点问题:想把自己的思考发到小红书,和写日记要怎么区分,才能既是观众想看的、也是我想写的。

## 日记和公开写作的分界不是"要不要迎合",是视角

- **日记视角**:「我发生了什么。」——"今天突然想到,我好像一直在分析自己的情绪。"读者的反应是"嗯,这是你的经历"。
- **公开视角**:「我们很多人是不是都这样?」——"我发现很多时候,我们不是不会处理情绪,而是不允许自己拥有情绪。"读者的反应是"等等,我也是"。

转换公式:**我的经历 → 提炼共同困惑 → 给出一个新的观察角度**。核心不是迎合,是**保留自己的思考核心,把私人体验翻译成别人也能进入的语言**。

## 一种很通顺的文风是怎么搭出来的:三条可复用、两条不能学

原话:"为什么你的文风非常通顺,很有逻辑,你是有什么模板吗"。可复用的部分,和下篇 [[非线性联想型思维如何转译成线性文章]] 高度重合(一段只解决一个问题、承接词当路标、不要太早下结论),这里只记那篇没有的两条:

- **不从句子开始,先搭思维骨架**:把对方的问题先拆成表层(写作速度慢)/中层(修改机制提前介入)/深层(对表达质量和思想深度要求高),回答结构自然就成了"现象 → 为什么 → 机制 → 怎么调整"。逻辑感是骨架带来的,不是句子带来的。
- **写之前的三个问题**:① 我真正想说的矛盾是什么(不是主题,是矛盾)② 我的变化是什么(以前怎么想 → 现在怎么想)③ 我希望读者带走哪个问题(不是答案,是一个值得继续想的问题)。

⚠️ **不能学的那部分**:AI 写出来的文字"比较完整",因为它的任务是整理和解释;而真正有个人魅力的写作者会**故意保留跳跃、矛盾、突然的比喻、不完全解释**——那是人的痕迹。
