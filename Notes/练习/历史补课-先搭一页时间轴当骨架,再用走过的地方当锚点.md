# 历史补课:先搭一页时间轴当骨架,再用走过的地方当锚点

**主张:历史零散,问题不在记得少,在没有骨架。补课的顺序是先搭一页时间轴,再读一本通史当地图,碎片(人物、地点、事件)随后挂上去;不背年份,从自己最感兴趣的一段读起。**

## 四步

1. **一页纸的时间轴。** 只记大节点:夏商周 → 春秋战国 → 秦汉 → 魏晋南北朝 → 隋唐 → 宋元 → 明清 → 近代 → 现代。每一段只写一两句话,比如「魏晋南北朝:分裂,佛教兴盛,南京是六朝都城」。
2. **读一本通史当地图。** 先挑薄的、读得下去的,别上来读大部头;同时只读一本。可考虑的入门选择(书目为模型回忆,买前先翻一翻):黄仁宇《中国大历史》、蒋廷黻《中国近代史》(薄,专讲近代)、吕思勉或钱穆的通史小册子。
3. **用走过的地方当锚点。** 到过的地方在时间轴上各标一个点,下次再看到相关的人和事就能自然想起来。以天津、南京、武汉为例:李鸿章与洋务、静园与下野人物 → 辛亥革命与武昌起义 → 南京的明初与民国。
4. **每读一段,用自己的话写三行**:发生了什么、为什么发生、和我有什么关系。

## 优先补哪一段

从兴趣最集中的一段开始(这里是清末到民国),再往前补明、宋、唐。**别硬背朝代表和年份**,背完也留不住;也别同时读多本。

## 和对话学习的关系

读通史是画地图,碰到想深挖的点再拿出来对话,这是「书当地图,对话当隧道」的用法,见 [[挖洞式对话学习的三个缺陷和两个锚-书当地图对话当隧道]]。
