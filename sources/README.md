# sources/ — 导出原文的映射表

**这个目录不进索引、不进图谱、不参与 GC 的手写笔记整理、不被 lint 检查。** 平时不用读,只在两种时候打开:怀疑某次记录漏了东西、或者要给一份新导出建映射。

## 为什么只存映射表,不(必)存原文

2026-08-02 的教训:7-31 那次记录从一份 26 轮的导出里漏掉了整整四块内容,而这件事**能被发现纯属侥幸**——用户手机里恰好还留着一张截图。事后逐行重读 5682 行原文才把漏的都找出来。

从这次得到两条:

- **只存哈希没用。** 哈希只回答"文件变没变过",回答不了"我从里面漏了什么"。
- **真正该存的是中间那层。** 一份导出 → 一张对照表:每一轮讲了什么、进了哪篇笔记、还是根本没进。26 轮 ≈ 30 行,比 5682 行原文便宜两个数量级,而且把"我记了什么、丢了什么"从**可重查**变成**可查询**——下次一眼就看得出哪几行是空的,不用重读原文。

## token 成本

约等于 0。**仓库里躺着但没人打开的文件,token 成本是 0**;成本发生在"被读"的那一刻。所以这个目录唯一要守住的纪律就是别让它混进日常读取路径:

| 会烧 token                      | 现状                                                       |
| ----------------------------- | -------------------------------------------------------- |
| 进 `meta/index.md`(开工必读)       | ✅ 已排除(`build_memory_index.py` 只扫 profile/concepts/notes) |
| 被每周 GC 第 3a 步当成手写笔记去整理        | ✅ 已在 `meta/GC.md` 显式排除                                   |
| 被 `lint_memory.py` 当 notes 检查 | ✅ 已排除(只走 notes/concepts/profile)                         |

## 原文入不入库:**入**(2026-08-02 改)

原来的默认是「不入库,只存映射表 + 哈希 + 原文位置」,理由是隐私。**用户当天推翻了这条**,理由更硬:

> 原文还是得入库,因为我可能会把原文删了。

这一句说到点子上了。映射表写着「第 19 轮漏了」——**但没有原文,这句话就永远无法复核,也无法把漏掉的内容捞回来**。今天能把四块漏记补齐,唯一的原因是那几份导出还躺在会话的上传目录里;那个目录会话一结束就清空。**防线依赖一个几小时后就消失的副本,等于没有防线。**

所以现在:原文一律进 `sources/raw/`,文件名与映射表同名。

### 但入库前必须扫一遍(这一步不能省)

原始导出是**完全没过滤**的,而这个仓库因为默认公开泄露过一次(见 profile/职业 的补救记录)。入库前逐项扫:

- 薪资、金额、offer
- 公司名、项目代号、内部文档
- 手机号、邮箱、身份证、住址
- 能定位到具体人的称呼

**扫完把结论写进当次的告知里**(命中了什么、是不是误报),不要只说"扫过了"。2026-08-02 第一批两份的扫描结论:命中全是误报——「理想的大脑工作状态」不是车企、「200k / 15 万」是在聊 token 上限、「明天工资也不会涨」是引用的哲学原文。

真有敏感内容:删掉那几行再入库,并在映射表里注明「第 N 轮已脱敏」——**不要因为有一段敏感就整份不存**。

### 关于体积

一份 26 轮的导出约 120 KB。存一百份也就 12 MB,git 完全无感。**别为了省这点体积牺牲可追溯性。**

### Obsidian 里嫌吵

`sources/raw/` 里是几千行的原始对话,会污染搜索和快速切换。在 Obsidian 设置 → 关于 → 已排除的文件里加上 `sources/raw` 即可,不影响 git 和 AI 检索。

## 命名与格式

`sources/YYYY-MM-DD-简述.md`,frontmatter:

```yaml
type: source
来源: ChatGPT / Gemini / Claude ...
对话日期: 2026-07-30 ~ 2026-07-31
轮次: 26
sha256: <原文哈希>
原文入库: true(路径 `sources/raw/同名文件`)
审计日期: 2026-08-02
```

正文一张表,一轮一行:`时间 | 一句话主题 | 去向`。去向三选一:

- ✅ 进了哪篇笔记(写路径)
- ⚠️ 半记(记了一部分,注明哪部分没记)
- ❌ 没记(注明当时为什么判断不用记,或"漏了")
