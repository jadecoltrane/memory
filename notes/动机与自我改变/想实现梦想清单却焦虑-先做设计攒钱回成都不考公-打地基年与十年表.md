# 想实现梦想清单却焦虑——先做设计、攒钱、回成都,不考公

背景:[[notes/动机与自我改变/我想要的东西|我想要的东西(我的梦想清单)]] 是一张"想要的生活"清单(环境/人/工作/生活四块)。这次谈的是"我要怎么做才能实现",一路谈成了一次方向决定。

## 我自己的心声(原样保留)

- "我一手好牌打得很烂":没对象、还是外包、身体憔悴、时间荒废、没读几本书、没存下钱一直在消费、家条件一般。
- "长得还不错,但被我自己造得不太好,很憔悴"。
- 反复问:这些目标"什么年龄能实现"。
- 底层动机:想**没那么焦虑**、有时间实现梦想、要**稳定**(怕被裁)。

## 我当场做的决定与立场

- **方向**:先继续做设计 → 然后回成都(家乡),前提是能在成都找到好工作。
- **对设计**:"不是多喜欢,但也不讨厌"——务实,不是热爱驱动。以后不必用"我不够热爱"为难自己。
- **排除考公**:考公对我唯一的好处是稳定;但我不喜欢那份工作本身,所以否掉。
- **城市**:杭州(干净精致+交互岗多,但卷) vs 成都(松弛+家人+低成本,但不够精致、交互岗少)。一度冒出"那我只能回成都考公了吗"(典型 [[concepts/非黑即白思维|非黑即白思维]] 的塌缩)。
- 曾动过"转自媒体 / 裸辞做独立设计师"的念头,最后收敛为"**边打工边私下做设计**"的搭桥路径。

## 谈出来的框架(以后复用)

1. **清单是目的地,不是路线图**。用 [[concepts/控制二分法|控制二分法]] 切三层:①直接可控(技能/健身/护肤/边界/整理,决定即开始)②需要钱和时间才能兑现(房子/自由/盈余)③只能提高概率、不能设 KPI(贵人/知己/伴侣)。
2. **真正的瓶颈只有 2–3 张骨牌**:第二层几乎全汇到"钱 + 时间自由 + 底气",最近一张是职业。别想"如何实现全部",挑最近一张,把"完成"定义小。
3. **我的软肋是"卡在收尾"**:危险不是不够想要,是想要太多、铺太开——那正是"一手好牌打烂"这种感觉的来源。
4. **考公 ≠ 抗被裁最优解**:真正抗被裁的是**存款**,不是编制。而且公务员禁止兼职取酬,**考公和"私下接单做设计"基本互斥**,两个愿望不能同时占。
5. **存钱机制**(兜底优先,别靠意志力):发工资当天先转固定比例(20–30%)进一个不看不动的账户,再花剩下的;不是月底看剩多少。存款数字也正好是我需要的"看得见的结果"正反馈。
6. **今年 = 打地基年**:只建两样底气 —— ①存款(抗裁的真兜底)②一个能带走、能在成都复制的设计成果(让"能在成都找到好工作"这个前提真的成立)。其余清单(对象/读书/语言/彻底改造身体)**今年主动放弃**,只留一条身体地板(不熬夜或每周动两次),且不拿它给自己打分。
7. **十年表(安心用,不是 KPI)**:我 25 岁,不是晚是早。清单里的东西大多是 30–35 岁、正常速度就能兑现的中上生活,不是富豪幻想。"家条件一般"= 没人替我兜底,所以存款是我自己织的安全网,不是判死刑。
8. **气色是最快的正反馈**:憔悴主要是熬夜 + 焦虑(皮质醇)堆出来的,几周到几个月可逆,几乎全归我自己管;先把自己养回来,它还会反过来把焦虑往下压。→ 最小的第一步:好好睡一觉。
9. **成都有精致的地方**:天府新区麓湖 / 兴隆湖、高新南区(金融城/大源/桐梓林)、铁像寺水街一带;麓湖最接近"干净精致有留白有呼吸感"。成都低成本让"存钱"和"过得去的生活"更容易兼得——回成都和攒钱是互相成全,不是二选一。

"被裁 / 不稳定"的痛,和"这辈子不能再以设计为业"的痛,哪个更不能忍?——答案基本决定考不考公。(这次已倾向后者更难忍 → 不考公。)

## 五阶段执行计划(2026-08-09 补)

**贯穿铁律:每个阶段只盯 1–2 个焦点,绝不铺开——软肋是收尾不是启动,窄而深。**

- **阶段 0 · 止血(现在–3 个月,25 岁)**:养回气色(睡够、别熬夜)+ 装上存钱机制(发薪先转 20–30% 进不动的账户)。不辞职 / 不搬家 / 不定终身赛道。✅ 完成 = 连续 3 个月做到"先存 + 作息稳"。
- **阶段 1 · 打地基年(3 个月–1 年,25–26 岁)**:攒到 3–6 个月生活费的雏形 + 完整收尾"**一个**"设计成果(作品集案例投得出去,或接完一个私活单)。✅ 完成 = 一笔看得见的存款 + 一个做完、能拿出手的东西(**破收尾诅咒,最关键**)。
- **阶段 2 · 搭桥验证(1–2 年,26–27 岁)**:在职的同时私下接 1–2 个真实项目,验证能否靠设计养活自己。✅ 完成 = 私活能覆盖成都生活成本的一部分 + 亲身验证过"我能交付"。
- **阶段 3 · 回成都落地(2–3 年,27–28 岁)**:带存款 + 能力 + 作品回成都,选精致区域(麓湖 / 高新南区),生活里直接可控项上马(健身 / 护肤 / 宠物 / 植物 / 有序的家)。✅ 完成 = 人在成都、收入稳、成本降、有余钱和时间。
- **阶段 4 · 点亮清单(3–5 年+,28–30+ 岁)**:需要资源那层(精致的家、旅行、盈余、更自由的节奏 / 上四休三)逐步兑现;靠概率那层(知己、伴侣)在活舒展后自然改善、不设 deadline;语言等锦上添花放这里。

**三条护栏**:①两条地板永不进考核 = 发薪先存 + 睡够;②这是地图不是 KPI 表;③计划是先验不是圣旨,现实变了就改。

底层逻辑:**前两年攒"底气"(钱 + 手艺 + 气色),后面才花底气兑现生活。** 顺序错了(现在就急着买大房子、找伴侣)只会更焦虑;顺序对了就是水到渠成。

## 贯穿线:日常的优雅(不必等到有钱有闲,2026-08-09 补)

优雅不是阶段 4 才解锁的奖励,是走完整条路的**姿态**,大部分现在、免费、马上可得,属"直接可控"层(具体做法见 [[优雅的秘诀|优雅的秘诀]]):

- **有序的空间**:再小、再是租的,也保持整洁、留白、有呼吸感(清单第一条,不花钱)
- **从容不慌**:优雅的内核是从容,不是精致外壳;而从容有一半来自底气(存款)——所以优雅和这个计划**互相成全**,计划给底气,优雅给姿态
- **少而好的消费**:优雅不是买买买,是精选,恰好和存钱同向(见 notes/生活方式/胶囊衣橱·衣物清单与消耗策略)
- **有边界地说话**:不讨好、不慌张地表达——顺手治"怕被负评 / 爱讨好"(见 profile/行为准则)
- **养好气色**(阶段 0 已在做)、**持续的知性输入**(本来就爱思考)——现成的优雅

> ⚠️ 建在"焦虑 + 月光"上的优雅是表演,撑不久;真正的优雅需要底下那层底气撑着。所以:**现在就练日常的优雅(它还反过来降焦虑),同时把底气一步步攒起来,让优雅从"装出来"变成"本来就是"。**

## 清单具体化:技能类几条从状态描述变成可验证清单(2026-08-15 补)

背景:[[notes/动机与自我改变/我想要的东西|我想要的东西]] 清单里语言、防身术、健身几条只是状态描述("我希望能……"),这次对话逐条拆成"具体是什么/当前水平/目标水平/验证方式"四问。**都已确认是终点目标,不是今年任务**——和上面"阶段 4·点亮清单"里"语言等锦上添花放这里"不冲突,不算违反"打地基年只留两样底气"的护栏,记录在案免得以后自己分不清哪条是近期哪条是远期。

- **增肌/体脂**:目标线条更明显、体脂率下降,不是围度或力量举级别。⚠️ 有 PCOS 史(profile/健康.md),体脂降太低对激素和月经周期不友好,目标区间和速度建议找妇科/营养师一起定,不照搬健身网红的极限数字。验证:定期测体脂率+记录线条变化照片。
- **游泳**:目标学会蝶泳(标准动作,能连续游一段)和抬头蛙泳(悠闲游一段不用低头换气)。当前水平待补。验证:教练评估或对照标准动作录像自查。
